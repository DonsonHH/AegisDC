# 全设施低阶模型：实现勘察

日期2026-11-04。只读核对现有`state-equations.md`、郑州casebook及官方物性接口；未修改仓库、运行仿真/训练。以下配置和数例均为研究设定，郑州冷媒、库存、保护范围等仍是缺值。

## 1. 推荐的第一版闭合

保留完整八域，以共享资产ID连接四类关系。每步先计算可用电力/实际负载、水力工点和所有界面热流，再用**同一份热流、相反符号**同时更新两侧库存；之后处理到点的切换、维修和保护事件。事件落在步内时拆步，不能先供一整步电再把负储能截成0。

- 电：功率/效率、馈线容量、受保负载矩阵；备用能量与接管模式有限。维护中的备用设备不能被控制器调用。
- 水热：湖水边界—泵/过滤—板换—内循环冷热容积—冷凝/冷板；各介质质量账分开，停流时传热/端口公式有明确分支。
- IT：热源使用**实际被供电并执行的功率**。请求需求/未完成作业继续存在，不能因降载而删除评价分母。计算/网络/存储共同服务时，用容量约束及服务缺额，不把重复路径损失相加。
- 控制：本地测量、采样期、延迟、滞回和保护模式显式配置；数值步长不冒充物理控制延迟。巡检调度只读已到达证据，不能读真值。

每步审计质量残差kg及能量残差J：端口输入＋电/热源−边界输出−储能变化。误差阈值结合绝对量和相对通量，并做步长收敛；仅凭温度看起来合理不算守恒。

泵电功率须分配到流体/机房热账；水力功的最终耗散与电机损耗不能重复加入同一项。

## 2. 相变优先采用M/U均相平衡模型

建议以**具名参考纯工质EOS**建立数值基准，例如CoolProp支持的R134a；标为热力学替身，不认定是郑州冷媒或工程材料选型。库版本、参考态、介质名、物性表及SHA冻结。可离线生成声明域内的表，以避免每步外部查询。ρ、u、h、T_sat必须来自同一物性源，不能分别拍常数。

控制体取“槽体＋蒸汽通道＋冷凝器冷媒侧”，固定V，独立状态M、U；无不可凝气体、单组分、近热平衡。两相时令v=V/M，质量干度

`x(p)=(v−v_l(p))/(v_v(p)−v_l(p))`

求根`(1−x)u_l(p)+x u_v(p)=U/M`，再取T=T_sat(p)、M_v=xM、M_l=(1−x)M。物性接口至少返回T、ρ_l/v、u_l/v、h_l/v、有效域。先验证所用压力区间的根可括定；近临界分母趋0应退出该模型域。

总质量只随补液、泄漏/排汽改变；内部蒸发和回液不改变M。`U_dot=Q_IT→r−Q_cond−Q_amb+Σṁh_in−Σṁh_out`，不再加入一份内部汽化潜热。若把冷凝器另切成控制体，则改记蒸汽/回液焓流，避免同时重复计Q_cond。

初值由同一p₀及合法液/汽容积构造M₀、U₀，检查0≤x≤1及几何余量。离开两相区后切单相EOS或明确停止该工况；不能把x硬截为0/1仍沿旧方程走。未知混合冷媒须增加组分/汽液平衡；有空气须增加其质量与分压。

若先采用固定压潜热近似，应另设模型变体：明确调压/可变容积或开式质量边界，用相应焓/功边界。固定p与固定V不可在加热相变时同时无条件强加；此变体不预测真实汽相压力。

## 4. 全范围与数值边界

电网可用功率/效率与离散切换代替电磁暂态；泵阀准稳态工点代替水锤；集中热容代替CFD；IT容量/队列代替逐指令；人员用位置、资质、工具、占用、持续时间代替LLM；房间以温湿度/漏液/访问条件代替三维几何。每一域都须在某个受控工况下改变物理输出、服务或动作可行性，只有名称的节点不计覆盖。

单相网络至少解`Δp_pump(n,q)=Kq|q|+ρgΔz`；并联泵不能无条件把单泵流量乘台数。后备路径要同时满足供电、流量与容量，N+1设备数不等于可用率。时间积分先用有界步长/守恒更新，限制单步温度、质量和储能变化；违规状态要报告残差/工况，不用静默裁剪隐藏问题。
