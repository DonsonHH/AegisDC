# 39c状态判定：原六个资格运行

固定源码3e81e7fa，Slurm133274，5项测试、6次设施进入全部返回，12秒原生轨迹、18个返回决策；4项通过，1项预期值断言失败。原terminal仍为FAILED，不因后续纠正改名或重跑。注册研究维持180次。

正常、无人工隐态隔离、跨阈值误差区间及未建模根因四项通过。无人工故障机会仍为1并记漏确认1；相同公开帧在正常与故障世界完全相同；未建模根因的真值及适用率保持未知/null。

错误需求模型场景的实际网络可用容量为0.5，原断言误写为铭牌容量0.75。独立解析关系见plant.py的容量约束：网络可用容量取铭牌限制与实际电功率/名义电功率的较小值；实际需求0.5将执行功率限制为名义值的一半，因此min(0.75,0.5)=0.5。它满足真实需求0.5，公开规则却使用1，故正常事件被判异常，重复判断只计一个误判事件。原协议中“准确0.75读数”这一描述错误，原件保留；需另冻保存结果核验，验证后续尚未执行的断言，不再调用设施。

完整输入、轨迹及公开帧留在现有私有服务器，哈希见[私有原件索引](07-state-diagnostic-qualification/private-raw-index.json)。本目录保留完整失败、六份业务摘要、源清单和作业回执。原5项测试结果不等同六个独立研究样本，也不接受整项39c。
