# 会后设施与风险原型：合成算例快照

来源提交为`6896f4b10503ce36d52b38114de1d3fac7db823f`。本包保存真实执行的CLI输出、输入/源码SHA和本地验收摘要，便于复算；参数及设施连接是明确的合成假设，未标定现场风险。

|文件|内容|
|---|---|
|[structure.json](structure.json)|14个功能区、29个资产/服务对象、36条候选服务依赖、9条假设通行边和待补参数|
|[result.json](result.json)|两个有限决策算例，包含分支概率、后验、行动选择、成本和假设|
|[status.json](status.json)|当前研究定义：按问题触发、允许稀疏测点、智能体/RSI后置|
|[receipt.json](receipt.json)|执行命令、源提交、SHA、本地142项测试及340份冻结原件核对摘要|

合成例1：24小时窗口下，最佳无检查成本2000元；检查并据结果选择处置后，期望总成本805元，净检查价值1195元。合成例2的最佳无检查行动已经是处置，再检查的净价值为−200元。它们说明方法如何计算，不是两座真实设施的经济收益。

默认没有输入固定测点观测；结构中的两处测点只是可选假设。已有观测与下一次检查的联合模型必须显式声明，详见[方法契约](../../docs/FOUNDATION.md)。

本地完整验收执行142项、零跳过。GitHub最小环境不安装Torch，允许跳过两项可选神经模型检查；这与本地完整验收分开记录。历史私有冻结权重闭环未重放，新训练、模型调用和注册实验尝试均为0。
