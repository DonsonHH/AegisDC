运行 `python scripts/verify_evidence.py`，或加 `--output evidence/report.json` 保存小收据。
脚本只用Python标准库，支持 `verify(root: Path) -> dict`。它检查原件身份、分组、保存的系数预测、统计和负结果，也将历史模型原始输出与已评估规则、C1→C2父子身份交叉核对；不拟合模型、不访问集群路径、不运行巡检或调用LLM。

**验收通过只表示证据完整、算术一致。科研增益仍为 `NOT_ESTABLISHED`。** 最新数据全部来自已看过的开发种子，24个决策点全是热巡检。13个成本正例每次只少走1.6米，现有岭模型未可靠识别；没有在线学习调度、独立新确认或RSI增量结论。

完整156条原始轨迹、旧源码与更早阶段留在历史快照，本目录不声称重新重放这些轨迹。原件中的集群绝对路径只用于来源定位，不是本命令的运行依赖；历史神经模型闭环仍依赖原冻结权重和全量物理数据。详尽原报告可由快照中的原路径读取。

`qwen_history/C2-proposal.json`原名是生成阶段的`Q3-proposal.json`，实际候选编号为C2；`call-02`对应实际C1。完整提示、反馈与367KB的历史链归档由provenance中的原路径定位，未重复复制。这里证明保存的生成、父子身份和实评结果相互一致，不把相同于Tour的结果写成自改进收益，也不声称重新验证了完整提示输入。
