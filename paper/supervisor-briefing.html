1. 配电、液冷与自控如何耦合

设备温度由发热和排热共同决定。 供电决定IT设备与冷却泵可获得的功率；泵送流量和换热能力影响排热；本地控制根据温度调整泵、塔风机和IT限功率。这样，一次供电扰动就能沿冷却链传到多个机柜。

CDU指冷却液分配与换热单元。一次回路连接设施冷源，二次回路连接机柜冷板，两侧通过CDU交换热量。El Capitan和Cray EX官方资料提供了这类架构参照。LLNL工程说明、HPE设备资料。

计算环节 当前模型采用的关系
机柜温度 热容×温升速率＝送达IT功率−液冷换热−环境散热
CDU换热 换热有效度×较小热容流率×二次回液与一次供液温差
辅助供电影响 二次泵有效速度包含“控制指令×√辅助供电可用性”，再决定流量
本地控制 温度驱动的比例目标，经20秒一阶指令滞后调节泵、风机和限功率

模型现有128个机柜、16个设备组、176项专业检查和18名虚拟巡检员。每组8柜，共有161个集中温度状态：128个设备、16个二次供液、16个电气接触点和1个共享一次供液温度。名义IT额定功率为128×250 kW＝32 MW。

设备自控负责调节物理运行；巡检负责补充量测并确认异常。二者通过“物理状态—公开观测—检查结果”衔接。

模型说明：本研究采用合成集中参数模型：电气以容量、效率和损耗表示，流量按准稳态计算，控制使用比例目标与指令滞后。现场参数标定、标准条款和大型设施扩展的具体安排见第6节；功率、每秒浮点运算次数（FLOP/s）及模型规模分别记录。

2. 从32个测温点得到风险热点

名义估计是“按已知设备参数预测，再用新量测校正”的透明基线。系统为128个机柜各保留一个温度估计，每5秒推进一次；32个固定测温点提供持续校正，其余96柜在完成移动测量时校正。

原理框①：先做热平衡预测，再用量测校正

T̂−i,k+1 = T̂i,k + (Δt/C)[Pi − Ui(T̂i,k − Ts,p) − Ua(T̂i,k − Ta)]

Ui = 12[max(q̂i,0)/6]0.8；收到机柜i的新测温yi时，T̂i ← yi

Δt＝5秒，C＝800 kJ/K；P为公开送达IT功率（kW），Ts,p为所属组供液温度，Ta＝28°C，Ua＝0.12 kW/K。q̂为每柜估计流量（kg/s），U为冷板换热导纳（kW/K）。

各柜从50°C初始化。组流量优先采用最近的固定遥测或巡检测量；尚无流量量测的组按泵指令与额定流量估计，再平均分到8柜。固定温度点每步校正，完成的专业热测量随后校正对应柜；未测柜继续递推。

因此，热点图结合了温度采样、公开功率、供液温度、泵指令和流量历史。热平衡提供未测位置随时间变化的预测，后续量测持续修正它。

原理框②：热风险由温度越界和功率缺口组成

ri = min{4, max(T̂i − 65, 0)/20 + 0.25[1 − Pdel,i/max(Preq,i, ε)]}

第一项表示估计温度超过65°C的程度；第二项表示送达功率相对请求功率的缺口。ε＝10−12 kW用于分母保护，总分上限为4。分数越高，表示当前公开信息中的综合严重度越高。

后文机柜10与8的0.0081、0.0656就是程序保存的热风险总分。日志保留了当时总分；下一版记录将同时保存温度项和功率缺口项，便于逐项追算。

3. 保护例行巡检，再按FIFO安排加查

FIFO（First In, First Out，先入先出）的核心操作是：在原巡检循环仍能按期完成的前提下，对本人负责的合规风险请求按出现时间先后处理。 每名执行者完成上一项检查后重新选择，正在移动和服务的任务持续执行。

两本账怎样配合

例行账保留原循环的下一项；风险账在某项公开风险从0变正时登记请求。程序先检查资格、所属、预约、时间与额外访问预算，再从合法请求中取最早的一项；没有合法风险请求时继续例行任务。相同入队时间才按风险分和任务编号打破并列。

专业完成检查后得到什么人数每次服务最大重访间隔
热检查该机柜代表温度1210秒300秒
电气检查该组电气接触温度220秒600秒
制冷检查该组冷却液流量220秒600秒
自控检查传感读数误差（完成校验后）215秒600秒

一次合格测量可以同时履行例行检查和风险确认义务。额外加查完成后，例行指针仍指向原任务；完成原定下一项后，指针才推进。

原理框③：加查后，原循环的每一项仍赶得上截止时间

t + τ(p,x) + τ(x,r) ≤ Lr + Dr；τ(a,b) = 5⌈[d(a,b)/v + sb]/5⌉

对完整返回循环逐项检查：Fj ≤ L′j + Dj；最小时间余量 = minj(L′j + Dj − Fj) ≥ 0

t是当前时间，p是当前位置，x为额外加查对象，r为原定下一项（此式取x与r不同的情况）。τ包含行走和目的任务服务，并向上取整到5秒；v＝1 m/s。L是上次完成时刻，首次未检任务按L＝0起算；D是最大重访间隔，F是预计完成时刻，L′随预计访问更新。

程序同时核查加查对象本身、返回后的完整所属循环及循环周期。这份逐项核算记录称为返回证书。每次实际完成后重算，因此可以连续批准多项加查。

风险确认机制带来了多少收益

相对固定巡回，FIFO新增45段确认、丢失3段，净增42段；平均每过程净增3.50段，探索性95%自举区间为[2.42, 4.50]。11个过程净增、1个持平。时序调整既能赶上新的异常，也会使个别原有测量错过窗口，附例保留了完整对照。

九条规则改了什么，为什么没有超过FIFO

本轮比较的是预登记的响应／暂缓规则：先由FIFO选出最早的合法事件，再决定现在加查，还是先执行例行下一项。规则改变这一步二选一的门槛，事件队列继续保留。

令R为风险总分÷4，A为请求等待秒数÷120，E为“加查与例行的预计完成时差”÷300，S为两者完整循环最小余量之差÷600。每条规则计算z＝b＋wRR＋wAA＋wEE＋wSS；z≥0响应，z<0先执行例行任务。下图直接列出九个得分式及结果。

第一类原因已经能从记录中直接说明：风险门槛过高，压掉了有效加查。 规则01的得分为4R−1，也就是“原风险分−1”。其229次二选一状态中的最高风险分只有0.7604，因而全部暂缓，额外访问为0；12条执行轨迹与固定巡回逐项相同，确认量也同为28段。

第二类取舍是等待门槛改变了测量时机。 规则06要求等待至少15秒，确认60段。一个实际过程里，两条轨迹从260秒首次分叉；FIFO随后在300秒派出机柜4的例行检查、320秒完成告警测量，赶上310—335秒的异常段。等待规则315秒选择先查例行任务，340秒再派机柜4，365秒测量时已恢复正常。

相对FIFO，规则06新增2段、丢失12段；这12段内均没有完成对应检查，区间后的首次测量均为正常。它在另一个过程新增机柜76的确认，同时丢失机柜74，体现了具体时序的得失。弱风险提示仍可能对应短时异常，额外等待会重新分配检查机会；下一轮要检验能否结合完成时间和可用检查机会选择暂缓。

RSI（Recursive Self-Improvement，自改进）指让模型根据执行反馈修改规则，再通过独立评价保留有效修改。本轮九条规则用于诊断可改进空间，模型调用和训练均为0；后续先建立有区分力的同任务基线，再单独评价模型反馈的作用。

诊断范围：九条规则使用同12个已见过程，属于开发结果。图中是两条实际完整轨迹的时序对照；“等待门槛影响短窗口确认”将通过后续逐项消融检验。具体规则、动作和源文件身份记录随报告保留。

5. 原VAE论文怎样评价先进性

VAE（变分自编码器）负责从部分观测重建重要度图；DRL（深度强化学习）根据观测选择巡检动作。原论文分别检验估计质量、巡检收益和计算效率，再通过估计器与调度器交叉组合解释贡献。原论文。

评价层 指标与方向 要回答的问题
估计 RMSE、重要度加权RMSE越低越好；R²越高越好 重建图是否准确，重要区域是否准确
巡检 重要度加权idleness分数越低越好 重要位置多久没有重新采样
效率 同硬件、同规模下的模型计算秒数越低越好 计算能否跟上决策频率

idleness表示“距上次采样多久”。原文对它按决策步增加、采样后清零并归一；目标包含各节点的“闲置度×重要度”之和。论文以100个未参与训练的场景比较DRL、Greedy贪心策略及VRP循环，并用VAE和Myopic估计交叉消融。

图为原文表8／9的终值均值和95%区间。“约快30%”描述巡检分数更早下降。当前机房研究已回答“事件机制相对固定巡回的确认收益”，下一阶段沿用原文的分层比较方法，将估计器和调度器放进共同机房任务，报告确认、等待、年龄评分和计算代价。

比较口径：原文预测对象是水域重要度，本项目预测设备温度并评价专业确认；两类指标各自在本任务内解释。原文Average分数的归一分母仍需随复现对齐。当前历史PPO／CVAE材料按既有实现记录，VAE-UNet与原共享DDQL的同任务适配列入下一节。

标准映射将怎样改变现有控制公式

当前泵目标为u*＝clip[0.85＋0.035(Tmax−58), 0.75, 1.2]，实际指令按20秒滞后追随目标。标准映射先把温度、流量、压差和保护要求变成明确的测量量、约束和测试，再选择反馈结构。

拟评估的温度／压差反馈结构为u*＝sat[u0＋KT(T−Tset)＋Kp(Δpset−Δp)]，配合正常、降额和停机模式。增加压差观测后测试稳定性与饱和行为；设定值、增益、露点裕量和联锁动作依据正式条款与设备资料确定。这是待评估的设计结构，现有仿真实现仍采用前式。

两项标准已定位：GB/T 48023-2026于2026-07-30发布、2027-02-01实施；GB/T 48097-2026于2026-08-28发布、2027-03-01实施。现有核查取得官方元数据，工作包将补齐正式条款到控制与测试的映射。

基线怎样做到同任务、同权限

先固定同一观测轨迹比较名义估计与VAE-UNet的温度误差，再将二者分别接入在线调度。调度统一使用“原定下一项＋本人的合法风险请求”动作空间；Greedy按公开风险与完成耗时选择，DRL在同一合法动作掩码内学习。不同方法的实际观察时机可以随动作变化，人员、专业、服务时间、行走模型与权限保持相同。

确认量保留现有定义；拟增加的年龄评分为Aj(t)＝min[(t−Lj)/Dj,1]，对固定任务重要度wj加权，再在同一回合内求时间平均。权重和归一方式在新评价前登记，形成“有效确认＋重要度加权idleness”双指标，同时报告成本和硬重访。

新机制评价沿用探索性决策门槛：全部预登记主过程（含零异常过程）平均净增至少1段，95%自举区间下界大于0，且至少8个主过程出现评价异常；平均移动增加≤5%，完成量下降≤2%，资格、预约和硬重访违规为0。新故障与规模测试的参数、训练预算和样本数在执行前另行封存。
