# 耦合设施巡检论文写作工作区

当前可以进入论文结构与正文写作。已有证据支持事件确认机制及风险位置干预在预定合成热—冷耦合过程中的任务价值；真实后果反馈是唯一尚待推进的主动实验问题。

本目录采用中文工作稿、英文工作标题，暂不绑定投稿模板。作者、单位、基金与目标刊会在确定后补入。主稿保持可编辑文本，预览版提供公式和图表的离线阅读。

## 先读这三份

1. [研究问题与贡献表](research-map.md)：一页式定位、RQ1—RQ3、证据状态及投稿主张分支。
2. [论文正文工作稿](manuscript_zh.md)：8章结构；第3、4、6、7章已有实质正文，第5章明确保留为研究设计。
3. [可阅读预览](manuscript_zh.html)：由正文生成，公式转为MathML，不依赖在线公式服务。

本轮优化的逐项完成情况见[审阅落实记录](revision-review.md)。主稿、模型附录和补充材料分别有独立HTML预览。

最新开发搜索已停止，下一步两种成稿路线的具体改动及证据缺口见[导师讨论提要](decision-brief.md)；当前主稿尚未自动变更研究中心。

## 章节安排

|章节|要回答的问题|本版完成程度|继续写作的触发条件|
|---|---|---|---|
|1 引言|覆盖合格后为什么仍需要独立事件确认？|已有论证、研究问题与现有贡献|按目标刊会调整长度|
|2 相关工作|与持续监测、约束执行及反馈改进怎样衔接？|已完成针对性比较初稿|补最接近工作的逐节比较和最终对照选择|
|3 问题定义|什么算风险、异常、确认和重访？|完整工作稿，含符号与指标|随最终RQ3协议补充规则空间|
|4 受约束事件确认|如何记账、插入并保留可行巡回？|完整工作稿，含伪代码和条件性可行性命题|方法经导师复核后定稿|
|5 反馈驱动流程改进|运行后果能否改善响应／暂缓？|接口已实现，反馈增量未验证|当前S包停止，需明确下一研究路线|
|6 实验|RQ1—RQ2效果、成本及位置干预怎样？|主结果、图表及6.7开发搜索负结果|RQ3仍需模型与新确认结果|
|7 分析与适用范围|丢失确认、事件生命周期和外推边界是什么？|完整工作稿|加入RQ3的正或负结果|
|8 结论|现有证据回答了哪些问题？|已有RQ1—RQ2版本|最终答复RQ3后改摘要与结论|

## 写作收束条件

这版主稿已能用于导师讨论。[RQ3补强包](../docs/RQ3_SPEC.md)已实现接口并冻结方案，同权限S搜索的9条不同规则未找到开发改进，按预定分支停止，未调用模型或执行新确认。下一步需明确是收束当前机制与负结果稿，还是为自改进另立新假设／协议；不能把本结果写成反馈已经无效。提交前还需要完成或移出中心RQ3，补齐R9全文约束核验和最终比较，由导师确认贡献定位，确定作者和目标刊会。工作稿状态与录用竞争力分别判断。
