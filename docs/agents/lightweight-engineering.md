# 轻量工程切片

用户2026-11-10指令覆盖此前39c过细的交付惯例。适用于后续工程补丁与reader／comparison／CLI资格；正式研究注册、原始结果和失败保留规则不变。

每个行为默认只交付：

1. 一个在既定公共接口上的测试（需要新实现时保留red→green）。
2. 一个result.json，合并源码／输入／工具／命令／预算／实际计数／状态／失败及远端原件定位和哈希。
3. 当前ticket一行证据记录，指向该result。

完整日志、快照、轨迹和检查点留在私有服务器；本地只留必要结果、图表和摘要。一个批次可覆盖同一接口的多个明确边界，分别列入同一结果；不为每个断言新建协议、source-pin和多份完整输入副本。durable文件角色先定义，缓存不作证据。

失败保留原状态与预算，不改标、不覆盖、不自动重试。修订在同一轻量结果中新增清晰的版本／独立尝试条目和唯一远端目录；不得变更封存研究的条件、阈值、结果。是否科学有效仍由研究对照决定，测试／CI不代替研究完成。

当前执行控制：长期目标暂停，纠正包交用户审查后，仅按其单步指令推进。
