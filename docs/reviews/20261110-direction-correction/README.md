## 对评阅中两处事实的校正

现有风险工作并非只有risk.py的111行原型。仓库另有risk_scenarios.py、action_value.py及full-facility-risk-scenarios-v1.json八问题目录；真正缺口是覆盖、时标和可用基线没有连成可审查交付。此修订复用它们，避免重造。

180次运行不只有两个实验臂：六种参照方法参与开发和确认，主配对为one_observation_lookahead与evidence_consistent_contingent。其候选空间仅两个预设任务实例，未评价全场问题触发价值或全场风险基线，不能据此回答会议R1／R4。

“验证关闭未入环”限定了适用范围。没有匹配对照证明启用核验后收益必然增加，因此不把原结果称为收益下界。

## 风险基线的真实覆盖

FEMA提供危险源识别、情景刻画、资产盘点、损失分析的过程。本项目将其改编为设施情景目录；设备概率、条件后果与检查价值仍由本研究自行声明和验证，不是FEMA设备评分。[FEMA过程](https://emilms.fema.gov/is_0559/groups/22.html)、[资产盘点](https://emilms.fema.gov/is_0559/groups/25.html)、[后果分析](https://emilms.fema.gov/is_0559/groups/28.html)。

默认V6是600秒窗口、30秒作业、60／120秒路径、30秒柴油启动；既有风险／价值算例却是2秒预测窗，检查总时长0.625秒。它是条件算术参照，不是已对齐的现场时间模型。新基线将阻止自动派工并把时间对齐列为缺口。

本包不宣称补齐六域概率、现场校准或全场检查增益；这些需要下一轮由用户选择对象、时间窗和参数依据。当前修正的目标是把这笔债放回主线前面，并使其可运行、可审查。
