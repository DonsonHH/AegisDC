# 固定研究主线：完整设施中的风险驱动检查与处置

确认日期：2026-11-04。依据用户对完整设施方案及五点修正的认可，并明确要求设立目标、按一条主线持续研究。此页是后续工作目标的唯一入口。

## 总目标

**在一个完整、可复算的算力设施场景中，研究如何结合跨系统依赖、多源证据及专业能力约束，联合安排核查与处置，在有限运维资源下改善关键服务保障；用独立对照明确各机制的作用，再按证据决定智能体和RSI的增量。**

研究结论可以支持、限制或否定某种机制。目标是可追溯的完整研究闭环，不预设收益为正，也不因某个复杂模块出现就视为贡献成立。

## 固定研究对象

- 主工程参照：郑州核心节点／曙光8000。实际运行对象是命名、版本化的合成研究设施，不宣称复原真实郑州。
- 八个行为域：供配电；后备能源；设施冷却；设备冷却及房间环境；计算/网络/存储服务；自动控制与监控；空间与保障；异质人员、工具与作业。
- 四种关系：物理、电热/流体接口；功能/容量/冗余依赖；控制与证据；人员访问。共用实体身份，语义分开。
- 可用信息：设计/资产、历史/维护、稀疏固定测点、控制记录、人工报告和工单、现场专业检查与手持测量，以及外生作业需求/环境资料。主场景包含固定传感器，其覆盖与可用性有限；未覆盖位置不自动产生观测。
- 两种状态：设施真实状态与决策者依证据形成的认识。当地自动保护可使用本地仪表，调度者使用决策时已可用的记录。
- 研究设定须给SI单位、来源性质、有效范围及一致性约束。零值只能表示明确的零，不能代替缺失。

八域进入场景意味着有实际状态/规则、输入输出、检查或作业接口，并能通过声明的路径影响服务或执行可行性。目录和静态图只算结构交付；重复资产可以聚合，关键共享瓶颈、备用与访问限制单独保留。

## 科学约束与比较

1. 首选主结果为预先定义的关键服务缺额时间；需求保留为外生到达，停机/降载后的未服务需求仍计入，实际发热来自实际执行/供电功率。
2. 人员工时、行走、测量/处置成本、误报/漏报和约束违反分别报告。安全/资格/保护规则单列，不把不同量纲随意加总为分数。
3. 后备和并联能力按连接、容量、维护状态、切换及共同根因计算，不能只看有几条可达边或设备台数。
4. 检查只改变信息；处置改变设施状态；恢复后再核验关闭。不检查、直接处置和无收益情景均合法。
5. 每次机制比较固定物理规则、外生需求/扰动与资源。依赖知识消融只屏蔽决策者知识；改变真实管网/馈线属于另设场景的稳健性比较。
6. 合成工作点、校准数据、开发种子与封存确认条件分别登记。冻结后不拿确认结果挑规则；失败保留，重试规则写入新协议。
7. 人员异质性从第一版进入；多AI智能体是后续求解机制，RSI还需区分普通反馈与递归增量。
