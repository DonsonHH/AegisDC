# 第25项：检查与处置的文献基线选择

核查日期：2026-11-05（Asia/Shanghai）。对象是同一个八域合成设施，保留稀疏固定测点、历史/人工/工单与实际手持记录、异质人员和付费作业。本文只完成来源核查与适配建议；未执行策略评价、仿真、训练或推理，不接受第25项，也不提前启动第30项后的效果试验。

**建议采用两类对照：一次观测前瞻作为主要模型基线；将风险优先明确为“风险触发检查＋基于到达条件证据的维护＋对象优先”的文献适配版。** 无人工、周期与FIFO仍有诊断用途，但它们不能单独支撑方法先进性。下文的机制和公平性规则是本研究的设计建议；只有“来源事实”栏描述原文。

## 2. 建议B1：受约束的一次观测前瞻

建议实现名：`one_observation_lookahead`。报告名：“基于信息价值的一次观测前瞻适配基线”。它是S1/S3原则与本研究服务指标、人员约束的适配，不是完整POMDP或Fauriat–Zio的寿命周期求解器。

在时刻t，仅使用已到达公共帧F(t)、声明模型M、相同资源账R(t)。对每个可建模问题q比较：暂缓、直接执行一个命名处置、先做一次检查后按结果选择暂缓或处置。未来检查结果只存在于预期分支，不进入当前证据帧。

设J为同一有限时间窗内的**整项关键服务缺额时间**，保持外生需求不变。对于检查i，枚举声明的报告y；每个正概率分支都重新选择后续动作，而不是规定“阳性必修、阴性必不修”：

\[
Q_i=\sum_y p(y\mid F(t),i)\min_{a\in A_y^{\mathrm{declared}}}
\mathbb E_M[J\mid F(t),i,y,a].
\]

移动、等待、检查、报告延迟、维修期间容量和残余效果进入这条完整时间线。人员、工具、费用各有硬预算；不把秒、工具秒和货币直接相减成分数。可另报告“不检查最优行动的预测缺额－Q_i”，名称用“预测服务缺额减少”，不能把它冒称已实现收益或货币净VoI。

```text
每个公共决策时刻：
  读取同一个当前证据帧、声明模型和公开资源账
  枚举 defer、每个直接命名处置、每个一次检查的分支计划
  仅按公共能力/记录和声明预算评估计划
  对检查计划：每个正概率结果分支都比较 defer 与相容授权处置
  若某分支已知超预算，计划不可选；若可用性未知，保留未知原因
  用同一需求/时间窗/联合结果律计算每个完整计划的预测关键服务缺额
  选择最小预测缺额；预先固定同值时的工时、费用及身份排序
  只提交当前首动作；未来分支不是执行许可
  由相同真实执行器处理移动、占用、保护、取消与报告
  新记录真正到达后重新计算，不从预期分支复制“观察”
```

**禁止把各问题的减少量加起来挑组合。** 共享供电、冷却与服务结果可能重叠，一项服务损失不能因两个问题重复计分。跨问题排序只有在候选使用同一时间窗、需求、联合结果定义与一致后验时才可比较完整计划值；不满足时记为不可比较，不能用不同分母强行排名。当前一次只选首动作，也不能据此声称解决多任务全局调度。

## 3. 建议B2：RBI-CBM-CP的公共证据适配版

建议实现名：`risk_condition_priority_adapted`。S2原基线使用系统失效概率阈值触发检查，并按部件失效概率优先、按观测损伤状态选维护；阈值、维护映射和检查数量均作优化。[S2b §4.3] 本研究将其适配为：

```text
每个决策时刻：
  从当前公共证据推断声明风险；未建模问题保持unknown
  若声明系统风险超过固定阈值：
    按公开后验风险排序，取可安排的前k个检查候选
  到达的专业检查结果满足预先声明的条件时：
    依据固定条件→命名处置映射提出授权作业
  所有提议交给同一人员/工具/访问/保护执行器
  超预算、无合适专业、等待、未知与未选对象均记录原因
```

“固定阈值”指确认前固定，不是任意选个差阈值。未来第30项协议应给周期、风险阈值、k和条件映射相当的开发调参预算；开发选择完再封存确认。原文立即故障更换必须改为实际到达的故障/检查记录和付费工时，这一差异写入方法表。若没有定义可校验的“系统失效事件概率”，只能用预先声明的后果指标替代并改名为本研究风险阈值规则，不能仍称严格RBI-CBM-CP复现。

## 4. 与现有AegisDC模块的连接和缺口

本段是对基线起点提交`6481ab8379ef315f958974d5a552e78089a3d5c3`的源码检查，不是文献结论：

- [`action_value.py`](../../../src/aegis_dc/action_value.py)的`assess_action_value`已有暂缓、直接处置、检查后行动三类有限树；`minimum_service_deficit`可用于正、负报告分支。`_planning`在每个非零概率分支检查声明资源预算/窗口；未知不等于可执行。`_comparison`以预测缺额为首排序，成本维度分别保留。
- 该接口明确返回`SINGLE_NEXT_QUESTION_ALTERNATIVES_NOT_ADDITIVE_GLOBAL_GAIN`；它不是全设施物理预测器，也没有得到多问题同时作业的最优值。可复用其有限树计算，不能仅把输出标签改成新算法就宣称已完成滚动运行。
- [`full-facility-action-value-v1.json`](../../../configs/full-facility-action-value-v1.json)注明研究假设而非标定；当前示例只声明cooling问题、2秒有限模型和一名冷却人员。[`full-facility-risk-scenarios-v1.json`](../../../configs/full-facility-risk-scenarios-v1.json)还保留未建模问题。第25项要让这些未知参与统一候选/暂缓账，而不是把其他行为域删掉或设零收益。
- 需要显式绑定第22项检查和第23项命名动作：第20项的规划操作名不自动成为第23项授权操作。声明时序、资质、工具、单位和效果映射后，当前首动作才交给实际执行器。第24项关闭条件对所有策略一致，处置完成不额外获得恢复证据。
- 实现时应核对决策时钟t和模型相对窗[0,H]的映射、剩余预算扣减、相同外生需求、实际在途任务与结果到达。不能每次重算都重置工时/位置、跳过已发生的服务损失或把预测结果当观察。

若B1暂时仅支持已声明的有限问题，未建模问题须公开记录，采用各策略共同冻结的透明回退/升级规则；不能在结果中声称B1已对八域所有原因获得量化VoI。

## 5. 公平比较与计算账

以下是本研究拟冻结的比较契约，不是论文已经提供的保证。

|维度|各策略共同边界|需要额外报告的差异|
|---|---|---|
|信息|同一可用资产/历史/稀疏测点/人工/手持记录；同一观察、到达、有效期与同源处理|策略使用哪些字段、模型是否调用以及未建模问题数量|
|人员与动作|同一人员、资格、工具、位置、班次、授权、访问、保护和命名操作；包括无人工策略的本地自动保护|所选作业、实际移动/等待/工时、失败/中断及无操作理由|
|模型知识|向B1和候选方法提供同一版本化概率/观测/效果模型；简单策略可以不使用|B1多用模型是方法差异，不能是独占真值或未来标签|
|目标与约束|同一关键服务缺额定义；人员/工具/费用/安全分别报告；未服务外生需求仍计入|预测与实际结果分开，缺额不同时间窗不能直接混排|
|调参与计算|相同开发条件及预注册调参预算；确认条件不再选阈值|每次决策模型调用数、分支数、墙钟时间、总决策次数、调参运行数与失败数|

B1每个候选检查只枚举声明报告与兼容续行动，属于有界枚举；其实际分支数应从实现记账，不用“大致O(1)”掩盖模型开销。B2排序/阈值和B1枚举的计算不同，应分别报告，不要求故意让简单策略消耗同样时间。若设置统一在线时限，超时后的预定回退也必须进入账。

进入效果研究前至少具备这些鉴别性检查：同样证据而不同后台真值时提议相同；检查无信息价值或来不及送达时可直接处置/暂缓；残余无收益及错误先验可使模型基线变差；高风险但无可行动作不自动成为“值得检查”；至少出现多个不同可选首动作，否则无法解释排序差异。以上是待执行的工程/协议要求，本笔记未运行它们。

## 6. 不把更强文献算法伪装成已实现

S2的长期POMDP/DDMAC需要完整声明的状态、转移、观测、成本/约束模型以及训练/求解账；当前单树价值接口不能替代这些条件。它是后续方法定位和强对照讨论对象，不能在第25项引入未经独立评价的AI增量。[S2a][S2b]

S4的SMDP若要公平实现，需要另行声明本设施的联合/聚合状态、动作可执行概率、检查后的信息状态、随机维修核和停留时间，并与其他模型策略共享。没有真实数据并不禁止显式合成核，但新增核是研究建模决策，必须固定来源/假设和验证边界，不能从评估器读取实际状态补齐。本文的选择是先实现有明确定义的B1/B2适配版，记录S4当前未复现的具体条件；不据此推导优于S4或优于最优POMDP。[S4]
