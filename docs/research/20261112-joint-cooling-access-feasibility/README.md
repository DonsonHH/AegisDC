# 39r · 冷却取水与空间积水的两域联合可行性

用同一名人员、同一台仪表处理同时到达的两项检查。计算在给定通路、许可、截止与预算下哪些顺序可行，作为两域联合判据的算术见证。

| 项目 | 从 V6 和已归档时序表读取 |
|---|---|
| 共享资源 | `worker_cooling` 与 `tool_flow_meter` 同在 `loc_hx`；两项接口都要求 `qualified_cooling_inspection` 并预约该仪表。 |
| A：取水检查 | `inspect_facility_cooling` 的 `intake_pump`，位于 `loc_lake`。 |
| B：积水通行核查 | `inspect_space_access` 的 `it_access_gate`，在 `loc_control` 从安全侧核查。`loc_it` 不在路线中。仪表预约来自接口定义，不能据此认为它测量积水。 |
| 作业与通行 | `inspection_time` 为每项 30 秒；`a2` 步行 60 秒、`a3` 步行 120 秒，均双向。时序表每段通行检查 0.25 秒，班次结束为 3,600 秒。 |

来源：[V6 配置](../../../configs/full-facility-mainline-reserve-v6.json)、[第 29 项标称工作时序表](../../../evidence/mainline/engineering/29-uncertainty-domain/prepared-01/cases/nominal.json)。源文件及 SHA-256 写入[冻结协议](protocol.json)。

两任务均在 0 秒释放。人员、仪表在释放时可预留，`a2`、`a3` 已知可通行，人员携表至第二项完工。表中的截止、预算和各任务许可开放时间是声明的演示输入，许可指在已可达位置开始作业，独立于通行许可。到达时刻是上一项完工加本段步行及通行检查；开工取到达与许可开放时刻的较晚值，完成再加 30 秒。完成时刻等于截止仍算按时。人秒包括步行、通行检查、预留期间等许可和作业，互不重叠；工具在同一段时间内预留。这里截止指现场作业完工，反馈、返回及服务复检不计入。

## 可行性判据表

| 场景 | A→B：A 完成／B 完成；占用 | B→A：A 完成／B 完成；占用 | 判定 |
|---|---:|---:|---|
| 两项许可立即有效、各截止 420 秒；预算 500 人秒 | 150.25／360.75 秒；360.75 人秒 | 300.75／90.25 秒；300.75 人秒 | **两序可行** |
| 各截止收紧到 330 秒 | 150.25／360.75 秒；360.75 人秒 | 300.75／90.25 秒；300.75 人秒 | **仅 B→A**；先 A 会使 B 迟到。 |
| 各截止 420 秒；B 的作业许可 225 秒才开放 | 150.25／360.75 秒；360.75 人秒 | 465.50／255.00 秒；465.50 人秒 | **仅 A→B**；先 B 要预留等待 164.75 秒，使 A 迟到。 |
| 各截止 420 秒、许可立即有效；预算收紧到 280 人秒 | 150.25／360.75 秒；360.75 人秒 | 300.75／90.25 秒；300.75 人秒 | **均不可行**；两个双任务顺序都超预算，A 或 B 各自单做仍可行。 |
| 各截止 420 秒；B 的作业许可开放时间未知 | 150.25／未知；未知 | 未知／未知；未知 | **证据不足**；A 先做的完工时刻已知，两个完整顺序都不能判可行。 |

例如 A→B 无额外等待时，A 用 `120 + 0.25 + 30 = 150.25` 秒。从湖侧到控制侧经板换位置，B 还需 `120 + 60 + 2×0.25 + 30 = 210.50` 秒，因此在 360.75 秒完工。表内时刻是候选排程的计算值，超截止或超预算的候选没有被执行。

[完整结果](result.json)保留两序的路径、各任务到达／开工／完成、失效门与人秒分解。[复核记录](verification.json)用事先手算的结果检查了五组、十个顺序，以及预留不重叠、许可未知和单任务边界。计算只使用已归档配置、时序表与声明条件；没有运行设施、策略或注册试验。它证明该判据能处理一个两域共享资源问题，服务效果、实际处置和现场标定仍无此演示的证据。

## 复现

按[协议](protocol.json)从指定 Git 提交导出两个输入文件到 `input-root` 并保留字节。使用标准库 Python 3.12.7 在本目录运行：

```sh
python -B analyze.py input-root fresh-result.json
python -B verify.py fresh-result.json fresh-verification.json
```
