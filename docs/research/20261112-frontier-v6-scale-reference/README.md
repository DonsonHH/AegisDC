# 39r A2 · Frontier 与 V6 的功热量级参照

这份对照并列两份既有证据：Frontier 的一个实测日和 V6 的一个标称合成运行。先划定口径，再读数；数值落在一起或分开均如实报告，不设置跨站合格线。

## 先划出不可比项

| 指标 | 为什么这两份数据不能直接比 |
|---|---|
| 功率密度（W/m²、W/机架） | 缺少双方同口径的实际受载面积或机架分母；V6 的合成设备边界也不是已核实的现场机房。 |
| PUE | 需同一计量范围和时间窗内的全设施能耗与全 IT 能耗。[美国能源部计量指南](https://www.energy.gov/sites/default/files/2024-07/best-practice-guide-data-center-design.pdf)给出两者边界。Frontier 发布了 PUE；V6 的合成电力分项没有核成与它同口径的设施能耗。 |
| 绝对功率、单支路绝对流量 | 两设施规模和支路聚合方式不同；数值可作规模背景，不能以相近判定模型合格。单位换算不消除这个差异。 |
| 秒级响应 | 发布时点名义相隔 600 秒；V6 数值积分步长与现场观测粒度是不同概念。 |
| 服务缺额 | Frontier 表没有同窗的服务需求与交付。 |
| 功率波动系数 | `std(P)/mean(P)` 无量纲，但这里是一个实测日与一个短标称运行，缺少匹配的负载模式、稳定窗和观测频率。 |

## 参照边界与算式

| | Frontier | V6 |
|---|---|---|
| 取样 | [Figshare v4](https://doi.org/10.6084/m9.figshare.24391240.v4) 的 [2023-01-08 投影](../20261111-frontier-field-pilot/frontier-jan08.csv)，全部 144 个完整时点。 | [第 29 项已归档 nominal 轨迹](../../../evidence/mainline/engineering/29-uncertainty-domain/capture-01/nominal/run.json)，标称需量 1、4 秒、无外生扰动或作业。全部存档状态属于同一次合成运行。 |
| 水路 | [原论文](https://doi.org/10.1038/s41597-024-03913-w)二次环路的 1–3 号运行支路，50/50 水与乙二醇、1,060 kg/m³、3.50 kJ/(kg·K)。 | 内部水环路在板换的热侧；取内部泵实供流量、板换入口热池温度和出口温度。V6 用合成水近似 998 kg/m³、4.18 kJ/(kg·K)；取水侧和两相冷媒侧不混入。 |
| 功率 | 发布表 `compute_power_MW`；细分设备覆盖与计量点未配对。 | `actual_powers_W.compute` 为整流后实际计算负载；网络、存储和整流损耗在其它项。 |

三个 Frontier 支路先在**每个同一时点**求和：`ṁ = Σ(qᵢ × 0.003785411784 / 60 × ρ)`，其中 `qᵢ` 为美制 gal/min。再除以同一时点的计算功率（MW）。V6 用存档的内部水质量流量除以实供计算 MW。该比值的单位是 **kg/(s·MW)**；只有流量和功率按同一倍数变化时，比值才不变。各支路的 `ΔTᵢ = T回 − T供` 以 K 表示，数值等于摄氏温差；三路合计时用 `Σ(ṁᵢΔTᵢ)/Σṁᵢ`。温差仍随工况和换热策略变化。

排热比只作边界诊断：Frontier 用工作簿公布的三路计算余热，V6 用内部水经板换的热流，各除以本方计算功率。排热比是无量纲量，但等于 1 要求匹配能量边界并处理蓄热、其他热源与散热途径，不能从守恒直接得到。工作簿余热是同一组流量和温度派生的量，单独核对计算公式。

## 对照结果

Frontier 的区间为当天 144 条记录的最小–最大值，中位数在所列处单独标明。V6 的 403 个存档状态在下列量上各为一个固定值，不能当成 403 次独立工况。

| 量 | Frontier 单日实测或派生 | V6 标称合成运行 | 比较口径 |
|---|---:|---:|---|
| 计算功率，MW | 9.639–23.599（中位 15.9285） | 2.000 | 规模背景；电表覆盖未配对。 |
| 单支路体积流量，m³/s | 1 号 0.03177–0.06057；2 号 0.03356–0.06450；3 号 0.06155–0.11977 | 无对应单支路 | V6 报的是一条聚合内部水路。 |
| 合计体积流量，m³/s | 0.12688–0.24484 | 0.12000 | 并列规模；左侧按同一时点求和。 |
| 单位计算功率的质量流量，kg/(s·MW) | **8.14–22.66**（中位 **12.50**） | **59.88** | 功能相近水路的量级参照；V6 是当天上限的 **2.64 倍**、中位数的 **4.79 倍**。 |
| 支路供回液温差，K | 1 号 1.33–28.00；2 号 1.72–28.11；3 号 16.61–30.94 | 板换热侧温差 **4.23** | 数值落入 1、2 号单路范围，低于 3 号范围；测点和控制工况未配对。 |
| 三路质量流量加权温差，K | **8.84–28.96**（中位 **17.84**） | 同一板换热侧温差 **4.23** | 与汇总水路的量级对照；V6 低于该日加权范围。 |
| 排热／计算功率 | 0.3960–1.0167（中位 0.8312） | 1.0596 | 各自能量边界诊断。两个分子的测点与其他热量来源不同。 |

Frontier 的 432 个支路余热值按工作簿的换算与截断规则复算，最大绝对残差为 `3.55×10⁻¹⁵ MW`；这是派生列的算术核对。V6 的内部水质量流量与 `ρq` 一致，板换热侧的 `ṁcₚΔT` 与存档热流最大差约 `1.26×10⁻⁸ W`；全设施的归档能量余额残差为 `2.42×10⁻⁸ J`。它们分别核对计算关系和合成运行内的能量账，不是独立现场热量测量。

**这次对照支持的结论：**在指定的合成工作点与 Frontier 这个实测日之间，V6 的单位计算功率水量较高，汇总温差较低。前两条支路的温差重叠只是局部数值交集。数据没有给出足以判断差异成因的匹配边界、负载或控制条件，不能据此作整体量级合格判断。比较未涉及现场动力学、参数标定、服务缺额或检查收益；600 秒发布间隔也不给出物理响应时长的上限。
