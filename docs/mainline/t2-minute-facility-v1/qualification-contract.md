# T2　A 关冻结口径

本关在既有完整 V6 的真实工作、采样、转供、热保护及共同服务时钟上，将公共派工改为 0 至 3,600 秒的 61 个整分时点。保留已接受的 T1 结果。A 的输入生成器、参数、检验程序和独立预期先提交。随后远端只展开两份完整输入，冻结其哈希，才启动设施。A 出现不通过即停止后续研究，保留所有已运行材料和未执行位置。A 与基线／全知计算分别记账。[参数原件](timing.json) · [独立预期](qualification-expected.json) · [原一小时有限资格](../v6-joint-engineering-v1/README.md)

工程用同一热应力背景，测量均无设备写入。0 s、60 s、180 s 分别发三份真实工单作业。60 s 时检查第二份 C 作业被占用门拒绝，独立的 N 工作可以开始，75 s 可同时看到两套人员和工具各有不同且匹配的任务。120 s 再次拒绝 C，180 s 收到第一份 C 的终态后才可承接。三项预定“发行／完成／回执”为 0／155／170、60／95／110、180／215／230。人秒和工具秒分别为 225。注册条件还含一份复制报警、一份迟到且已过期的报警，另核原生付费读数在两个决策点之间过期。

每臂逐区间核对时间连续、能量和各物理库存的前后量与收支，另对全窗做独立服务与占用积分。两臂均须出现真实首次热保护及正损失。参照已见暖工程的 946 s、L=1667，单臂拒绝错场景的界取 [925,965] 秒及 [1550,1780] 秒。两步长间首次保护差≤1 个本地采样周期（1 s），L、U 各自绝对差≤全窗的 0.1%（3.6）。保持原生能量、质量允差。原 T01/T02、T05/T06 的 0.5 s 同轨失败保留。

基线定义在本关运行前登记。P 沿用自动保护且没有任何人工发行。周期巡检从 0 起每 900 秒按固定路线、固定资源顺序办理访问，人员／工具及费用实扣，有合格的到时结果和有效许可才办理处置与本人复检。报警响应在合格报警到达后的下一个派工点按固定公共优先顺序处理，依同一操作许可与复核约束。全知诊断独立于以上三组。B/C 若进入，先冻结四族的具体生成规则、种子、全体登记条件的输入身份、分层及付费观察额度，再执行四个真实试点；工程与研究不得转拨。预留的发生器种子为 2026112102（十进制）。每次科学跑使用独立状态，原有一次性启动授权和替身回放均不使用。
