# 39c-42：实际占用、准入包络与计算开销分列

首个成本行为沿用公开`simulate_scenario(...,business_program=...)`接口，新增私有`aegisdc-business-cost-evaluation-v1`。声明仅含schema、id、facility_id、basis=synthetic_assumption、time_unit=s和source_note；验证在物理运行前，结果仅在运行完成后产生。它不改变派工、预算或设施。

输出为`aegisdc-business-cost-result-v1`，区分以下来源与量纲。

- `actual`逐项引用设施积分后的人员移动、作业、等待、门禁、集合、排队和工具占用／工作量。每项带value、unit、记录状态；缺字段为null及未记录，不能补0。人员互斥总量只加移动＋作业＋等待，门禁／集合／排队是等待子项，不重复加；工具工作是占用子项，不与人员秒混加。等待分解及工具子项关系提供可核对的一致性状态。
- `admission`保留公共累计准入账，包括person_s／tool_s的全任务窗包络；它不是实际花费。`issue_fees`只表示被发出任务声明的合成费用，保留单位及“非实际货币支付”说明；没有派工准入账时记不适用。
- `computation`按已有独立审计记录累计公开选择器、条件评估、数学模型计数和其覆盖。风险／动作价值等数学评价与LLM、训练分别记录；内部嵌套调用仍未插桩。选择器及条件评估的wall-time使用ns，明确覆盖范围，不加入物理秒。缺计数或计时保持未知。米制路程、真实货币、令牌及能耗没有记录时保持null。
- 全部任务状态与未完成／拒绝／中止记录仍列在结果中，实际总量不排除失败。首版**不声称已经实现逐任务失败成本归属**，该能力和未完成／中止资格仍须后续切片；程序通过不意味着完整成本或39c接受。
