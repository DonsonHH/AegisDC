## Current implementation and final engineering boundary

The v3 selector adds a common cumulative admission budget, explicit task issue fees and the same public intervention declaration as execution. Each task permanently consumes its declared availability-to-deadline crew/tool envelope when issued; this deliberately conservative envelope is a scheduling constraint, not measured labor. Completed, rejected or aborted reports release concurrency but do not refund the spent envelope or fee. Actual person/tool occupation remains the independent plant balance account. All policies receive the same caps; new choices never reset them. A prospective inspection plan must afford its complete positive-support continuation envelopes together, not only each first task in isolation. Issue and continuation gates share exact fractions of the decoded public input numbers; rounded ledger values are display outputs and never decide affordability.

The five named policies are `no_human`, `fifo`, `periodic`, `risk_condition_priority_adapted` and `one_observation_lookahead`. The periodic reference chooses only its explicit due inspection list. Risk priority uses the declared per-question service consequence and a bounded arrived condition rule for maintenance; unknown risks have an explicit FIFO inspection fallback. It does not add overlapping question consequences or interpret them as a calibrated system failure probability. The lookahead adaptation compares single first-action plans under one catalog, joint outcome law, common demand and horizon; it does not sum separate question gains or claim lifecycle optimality. Positive and negative report branches choose minimum predicted service deficit. Already known work durations, report latency, actor/capability and reference report probabilities bind to the actual declaration. Numeric report thresholds and likelihoods remain explicit public model assumptions, not calibrated truths; travel/wait and residual response are likewise declared forecasts and must be reported beside actual execution. All participating methods can access the same versioned model inputs. A known grant expiring by forecast completion makes the plan unavailable.

`simulate_scenario(..., dispatch_program=...)` and `python -m aegis_dc simulate --dispatch-program FILE --model V6 --step .01` execute on one facility clock. Repeated declarations provide a finite periodic reference; no implicit full-facility Tour or extra workers appear. Same-instant protection and crew/effect/inspection ordering stays in the plant. Fixed channels sample the whitelisted actual signal at their exact binary64 epochs with the accepted observation law. Their raw realization and audit stay private; only arrived records enter the common decision frame. Explicit poll counters preserve decimal endpoint/prefix identity; disabled/missing data do not become zero. Task admission refusals use a declared positive-latency task-local report with a generic reason and no actual location/private refusal cause. Safety discoveries continue to require the original paid access/onsite path.

An optional v3 run lifecycle template consumes the same current frame and only actual arrived intervention feedback. Question closure can exclude a demand-driven candidate for that question; an explicit periodic inspection reference may continue. A completed effect alone stays pending verification. Other catalog questions stay unevaluated; no additional restoration records are fabricated. Decision model-call counts, branch counts, candidate counts and diagnostic wall time are separate from physical time and never fed back into selection.
