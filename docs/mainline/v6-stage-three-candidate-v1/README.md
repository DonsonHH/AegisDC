## 主问题与可证伪主张

在相同的公开风险假设、工单、到时证据获取机会、自动保护、具名许可与人工预算下，J 联合比较“先核查、直接处置、暂缓”的完整后续计划，能否相对 B 降低同一 critical_service 的全窗实际缺额？B 使用同一完整联合后果、资源排程和复检门；先选择严格改善公开预测缺额的最佳直接计划，否则才选能区分后继处置的合法检查。两者都可以暂缓、拒绝不可行工作或在取得新证据后转办另一问题。锁定版本使用本包修订后的终态、确定回执与真实占用口径。[联合选择契约](../v6-joint-cooling-network-v1/README.md) · [终态契约](../v6-joint-terminal-v1/terminal-contract.md)

配对单位为一个冻结的物理／外生背景和公开设计条件。每臂独立构造完整八域、四图和账本。主分母是 24 个预列 J–B 配对。逐条件列出优、平、劣、数值未决、不合规和未取得配对六类。面板服务支配须 24 对全部有效、无一劣于 B、至少一对严格改善，且 L 和 U 的独立评价均支持这一方向。在同服务行另检验分量式省资源及关闭保有；若要提出整板的“同服务省资源且保有关闭”主张，则全板均须同服务、每行三项实耗不增加、至少一行一项严格减少，并且保有 B 的合法关闭。保留行级条件价值及成本／服务／关闭取舍，单行改善不能满足整板命题。

## 公共选择、信息公平与预测适用域

- J/B 在每个公开刻最多发行一项工作。打开的问题、在途义务、人员／工具最后可信位置、非退款入场包络、强制本人复检和真实发放资格均从同一个已到公开前缀生成。预测每个允许将来的分支可以计算计划完成时刻；实际世界状态只由到达且身份相符的记录更新。工作、控制、测量及收费的身份在各臂内独立。
- 同一条件的策略输入只含相同设计知识及各自合法获得的记录。条件号、真实滤阻、真实供电、未来到达、私有热保护／评分和另一臂已经买到的读数均不送入策略。授权相同不等于每臂强制取得同一后继观测。冻结初始帧、通道覆盖、误差／时效、同源相关组和随机实现；本面板合成读取零噪声，保留原固定源码和已声明种子。不得向任一臂免费填补未知、超期或缺失。对两臂尚无信息或行动分歧的前缀核验同类公开字段；在合法分歧之后记录由哪一条到时信息／已发行选择造成不同历史。
- 主面板保留原有单张公开离散联合表。EX50 的两种解释是 F／正常网络和正常冷却／网络配置 .25，COZERO 和 EXZERO 保持同样的边缘概率而改变共同发生方式，N_EQ 允许相同低有效容量来自不同供电／配置。表的数值及观测关系用已有定义逐字锁定。F 对应常温、全开阀下的 m=4 流量签名；[8,12) 内“成功清滤完成加 2 秒允许计算”是合成排序律，不具备现场频率、真实热跳闸时刻或一小时可靠度标定。供电、网络与存储服务只计算一个共同后果。
- 缺测、错误身份、互相矛盾及零支持留下显式状态，依赖该推断的自选动作暂停，实际已承诺的义务仍须办理。C03/C04 专门包含表外组合。预测缺额、预测实际工时和已归一世界权重与实际轨迹分栏保存；禁止用观察到的研究输出重新拟合先验、恢复时延、资源权重或选取对 J 有利的条件。

## 最小机制对照

三个对照都以原 J 为参照，保留相同合法资料、权限、预算、服务目标、计费和本人复检。每个预定子集只改变一个可执行选择；原 J 的同一轨迹只归档一次，不把共享参照重复计入设施数。

| 处理 | 唯一变化 | 配对分母与能解释的机制 |
|---|---|---|
| J_OPEN | 自选菜单只纳入首个有合法开题的公开时刻当时已开的问题，之后到达的独立工单继续出现在公共材料和评价实例分母中。保留所有既有作业、强制复检及硬安全门。 | A05–A08 共 4 对。检验把迟到问题纳入选择的条件价值。不能据此归因到从私有状态自动发现故障。 |
| J_NO_PROBE | 删除自选初检 I 的分支，保留完整的直接处置、W、本人的付费复检 R 及所有授权。如果写许可要求本人的阳性初检，该行动继续受门控。 | A01–A08 加 C01/C02 共 10 对。估计拥有选择付费初检机会的总差异，包含花费、等待以及可取得的许可。 |
| J_ORDER | 对一个相同无序双处置集合，在同一信息支路内先枚举两种合法次序。仅一种可行时保留它；两种均可行时保留首项最早可发行、继而首项预计旅行／通行时间最短、最后按绑定实体与原始工单键破同分的次序。其余候选、初检选项、合法复检优先顺序及各向量的打分与 J 完全相同。 | B03/B04/B07/B08 共 4 对。这些条件能支付两项处置及复核。比较联合后果择序与透明作业顺序；若实际没有两个可行次序，或两臂选择始终同义，登记该机制在本子集不可区分。 |

比较机制时先列出进入候选分歧的公共根、两个可行替代、信息／资源和首个真实不同的决定，再列全窗差异。J 对 B 是整体方法比较；不能用其差值替代三项机制对照，也不把这些差值相加。本包未实现或资格验证这三个新处理。批准研究前，分别核验迟到开题前后、可以／不可以购买完整检查分支及两种有别且都合法的动作次序；每类至少一个触发差异的见证和一个同义或被门控的反例。不得从研究输出来选这些见证。终态收尾只执行公开接口和已保存轨迹，新增源码的原生在环交接仍需按拟用事件逐项证明。若某研究层依赖分时安全停止、写回执先到或新作业次序而缺少原生同型证据，先登记最小真实事件对及独立预期，另获工程额度；禁止把首个研究运行兼作迁移资格。

## 热工资格怎样承接

已接受的四分之一秒配对只覆盖 T03/T04。两臂共享 V6 清洁满载暖平衡初态、313.15 K 湖温、0 s 滤阻变为 100、全额供电、网络／存储配置 1、1 s 本地保护采样。动作分别为早期合法清滤并本人复检、全窗暂缓；清滤在 3.25 s 第一次实际改变参数。动作前 0 至 3 s 的共同 .25 s 时点、原生热状态与原允差通过。该事件族没有查后处置、网络修订、不同工单时序、并发干预或分时安全退出。T01/T02、T05/T06 的半秒步长在 3 s 的各五项差异仍保留；其中的单臂事实和遮蔽结果不能扩成半秒处置前同轨资格。[原热工报告与失败](../v6-joint-engineering-v1/README.md)

**每对先作首次物理作用前核验。** 先核对独立状态、初始库存、物性表、外生时序、需求和自动保护身份。评价端在各臂从动作／能量账定位最早真的改变物理量或负荷的人工事件，取两臂中较早者 t*；单纯申请、工单字段、回执或等值写入不能提前截断。若出现新的真实作业副作用，以更早的实际生效点为界。另设配对归因界 tΔ：两臂第一个不同的实际物理作用（时刻、目标、写前／写后值、物理副作用任一不同）。如果 t* 两臂实施了相同作用，在该时刻核对左右状态并继续，跨过其后每个相同作用核对轨迹，直至 tΔ 的左极限。所有物理作用全程相同则核验整窗，包括两臂全窗都没有有效写入的情况。例：2 s 共同恢复网络、8 s 才首次不同清滤，须核验到 8 s 前。保留各自完整积分网格，在全部共同物理／保护时点、t* 以及 tΔ 的作用前左极限比较水流、共同服务、计算保护、热库存及换热。同刻按原生事件顺序，记录首次实际分离；不把作用后的值当成左极限。对未重合网格列出事件、区间及可比依据；缺少可复核前缀或出现未取得资格的网格，保留 NUMERIC_UNRESOLVED／PENDING_TRANSFER。不能仅因终点相同而通过。

热量比较沿用原冻结口径：各臂自身须通过原质量／能量守恒。共同历元的两侧原生能量允差相加作为库存身份比较界，换热功率差乘两侧较小原生步长再比较；保留原生绝对／相对参数和精度。每个工况独立报告。不得用虚构任务、假观测或空参数写入去对齐网格，也不得因新结果修改阈值。

**最小迁移。** W01 即使物理初态相同，J/B 的两工单、真实初检、可能发生的网络行动和复检仍是新事件族；W02 另引入新的网络有效瓶颈：沿用网络配置 1 时 T03/T04 的同一暖平衡热库存，将 .25 写在两臂的场景初始网络配置中，在 0 s 首个原生采样前就生效。预热库存不按 .25 重算，也不添加一个人为调网格的 0 s 写事件。这个初始热库存与新网络负载的组合必须进入 W02 的独立迁移。冻结前以公开可行分支列出相对 T03/T04 新增的真实事件次序、最早生效时刻和积分断点。每个未覆盖且不能由相同原生路径身份承接的事件族，最少提出一对共享真初态／外生条件的工程见证，预写作用前、作用后、守恒、权限、共同服务及失败判据。可以用同一对覆盖多个实际到达的分支；未达到的分支继续列为缺口。无对照的单次运行不能补这一资格。任何新迁移运行须先取得独立授权和额度。当前暖层研究额度关闭。

暖层的 J/B 保留短窗公开排序律；m=100 的严重滤阻流量不在已声明的 F4 读取签名内，超出支持就保留未知。只有“固定短窗决策面对一小时后果的压力表现”可作为暖层问题。若拟让方法声称预测真实到跳闸时间或一小时收益，需要新公共预测模型的单独规格、工程资格及研究版本，本候选未采用该改变。

## 统一评价、预算与停止

1. 私有评价在策略循环外。分别从原生余额和全窗分段需求／交付回算 L、U，核对从 0 到 H 连续覆盖。定义差值为 B 减 J，正值表示 J 缺额较少。d 恒为 1 时二者数值重合，保留两个账口且不重复计证据。取原始二进制数的确切有理值累计，合并相同需求／交付的相邻区间，先核对各臂守恒、前缀资格、全窗覆盖及两种积分的原始回读：L、U 各自的余额与分段率差沿用工程绝对上限 1e-8，任何一臂未过时先记数值未决或相应资格失败。通过此门后，若两臂规范化的需求／交付分段曲线在整个共同窗完全相同，优先记平，同时保留原生余额分割产生的尾差。若曲线不同，则两种账的 L、U 全部精确零差时记平，两种账对两个端点均同向严格时记优／劣，零与非零混合或方向不一致记数值未决。另报原始差值；没有现场效用门槛、总体抽样或统计功效依据。
2. 对每个问题／处理列出人员真实旅行、工作、等候、人秒、工具秒、发行费、入场包络和每次预留／释放；任务级终态等待、每个逻辑通知及原始重复投递的延迟另记。记录提出、拒绝、行动失败、已执行、复核、未完成、到期与最终位置。三项资源差异按分量判定，混合方向列为取舍。
3. 枚举两个真实合法开题的完整实例分母，包括候选禁用的晚到问题。分别评价“证据支持无需处置”与“实施后本人复核通过”的首次、曾经达到及当前状态。短窗取 5、7.5、12 s；暖层取 5、7.5、10、2700、3600 s。超期、借用他人回执、仅有 APPLIED 或只收到过程通知均不能保有关闭。报告类型替换及失去的每个实例／检查点；严格的关闭保有主张要求 B 曾取得的具名类型与相应时点在 J 也成立。
4. 所有已计划位置记入日程账。物理不可行、合法拒绝、零支持、错过窗口、未取得关闭是结果，不能据此删除行。缺失原件、权限／预算越界、信息提前泄漏、源码／输入漂移、配对前缀不合格或评分无从复核者保留原始结果并标为不可比。首次硬边界错误停止受影响后缀；不揭露后继条件私有材料给策略。程序崩溃或超时保存失败和已消费计数，研究日程自动重试为 0。协议、预算或方法调整须另版交审。
5. 候选核心为 24 个条件、48 个主比较位置，加 18 个机制对照位置，共 **66 次设施、最多 3,234 个设施内公开决定**。每条件一个串行单 CPU、4 GiB、300 s 作业，核心总预留 7,200 CPU·s。暖层若独立通过迁移并另获授权，再有 2 对、4 次设施、88 个决定、2 个单 CPU／8 GiB／600 s 作业，另预留 1,200 CPU·s。两层若均批准，合计上限 70 次设施、3,322 个决定和 8,400 CPU·s。工程迁移、改进器、RSI、独立确认均无转拨额度。本次实际研究调用为零。

交审后须先决定主面板与条件性暖层的范围、是否接受三个单因素对照和上述有限判定。只有已达资格的运行器／独立评价器、展开版研究 manifest 及一次性研究授权同时就绪，才可开始相应研究。
