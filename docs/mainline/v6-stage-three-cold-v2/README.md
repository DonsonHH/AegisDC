## 配对评价怎样承接共同作用

原生读回在**既有积分历元**分开采集本刻离散事件前的左侧、人工写入前的状态、写入并稳定后的右侧。记录只交给私有评价器。本版保留原物理方程、积分步长选择、本地控制和干预效果。每臂独立从原生余额与分段需求／交付计算全窗 L、U，按任务和问题拆分人员旅行／工作／等候、工具占用、费用、入场包络和两类回执延迟。所有合法开题实例保留首次、曾经及 5／7.5／12 s 的具名关闭；类型替换、比较者首次时刻的损失均可追溯。[私有观测](../../../src/aegis_dc/cold_physical_audit.py) · [独立评价器](../../../scripts/cold3_evaluation.py)

- **先相同，后分歧。** L 两臂在 1.25 s 完成相同的真实网络修订，在 4.25 s 才首次发生不同作用。独立评价跨过共同写入的左右状态，覆盖 435 个原生历元、1,304 个状态面，直至 4.25 s 的左侧和人工写前状态。该时刻作用后的右侧可以分离。
- **作用全相同或只有等值写入。** O 的 J／J_NO_PROBE、X 的 J／J_ORDER、C 的 J／J_OPEN，以及 M、U 的比较均核对到 H=12。M 的真实 C 写前和写后均为 1；两臂的核查工时不同也不缩短物理核验前缀。
- **错误会被判出来。** 合成评价见证分别破坏或删除真正的左侧和人工前面，在共同作用之后制造漂移，保留等值写入后的晚期漂移、未重合网格、未知物理作用和不合规输入。缺资料返回未决。相同完整服务曲线、零差异、两种积分方向相反和关闭类型丢失分别按已冻结规则处理。24 行替身在缺回执时仍保留 24 个主比较及全部机制分母。
