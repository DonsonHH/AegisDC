# 39r · IT 网络不足的观测记录契约

适用对象是[网络容量子问题](39r-it-dependence-network-capacity.md)，不是“网络设备是否故障”或“以前的恢复动作有没有执行”。本页定义 `a`、`b`、`q_I` 可由什么记录填写；当前没有这组记录，三者仍为 `null`。

## 对齐实际状态与检查报告

先声明同一比较条件 `C`：`network` 和 `critical_service` 的身份、同期正需求 `d`、供电和配置上下文、观察窗、状态参考时刻及检查后的决策时刻。只有计算与存储没有更紧瓶颈时，才用本子问题的网络不足解释联合服务缺额。

- **状态 `X`：**用与被评估检查独立、同资产同参考时刻的合格容量依据标注。有效容量 `c<d` 为 `X=0`（不足），`c≥d` 为 `X=1`（足够）。不能用同一条检查报告给自己贴真值标签；参考状态不能确定或无法对齐就留未知，保留计数。独立参考只用于复核，不自动提供给调度者。
- **报告 `Y`：**按[到时证据口径](16-observation-contract.md)保留 `z`、误差上界 `e≥0`、来源／同源组、采样、到达与有效期。确认量纲、同期需求和时间适用性后，`z+e<d` 记“报不足” `+`，`z−e≥d` 记“报足够” `−`，其余记未解决 `?`。无报告、误差未知、尚未到达、已过期或公开证据不足以确认样本仍适用时，同样记 `?`，另留原因。若只是复核端发现参考状态错配，保留原报告并标记不可配对，不用私有真值改 `Y`。报不足并不定位配置故障或供电故障。
- **查后门 `g`：**仅对报不足的恢复分支，在该次处置决策时核对独立授权、资源和截止。`g=1` 表示允许且有依据在时限内尝试，不是事后完工或成功标签；授权拒绝不把已经有效的 `+` 改写成 `?`。

## 三个量的分母与成功条件

| 量 | 统计口径 | 何时仍不能填值 |
|---|---|---|
| `a=P(Y=+｜X=0,C,I)` | 同一策略 `I` 的不足机会中，决策时得到有效不足报告的比例；分母包括 `+`、`−`、`?`，包括未得到报告的机会。 | 不足参考状态未独立核实、样本未对齐或分母为空。 |
| `b=P(Y=+｜X=1,C,I)` | 同样口径下，足够机会中误报不足的比例；也不只取已解决报告。 | 足够参考状态或报告适用性不明。 |
| `q_I=P(S=1｜X=0,Y=+,g=1,C,I)` | 从查后门通过的机会入账，记录是否实际尝试及能否在截止前核验恢复。分母不只取已完工者：未发起、取消、失败和已观察到的超时都保留。 | 截止尚未观察到、复检缺失、结局删失或分母为空时，保留未知；不能把删失填成失败或成功。 |

若另外报告已解决样本上的灵敏度 `s` 和特异度 `t`，先分别记状态 `X=0,1` 的未解决比例 `u_0,u_1`，再得 `a=(1−u_0)s`、`b=(1−u_1)(1−t)`。现场记录若已经给出上述全机会口径的 `a,b`，不再扣一次未解决率。独立参考未知的行不并入两个状态分母，保留其数量和原因；据此只能描述有合格参考的样本范围。

**及时成功 `S=1`** 要有动作后实际容量和服务证据，核验时刻须早于预先声明的截止。若要用历史 `L_1=0` 代表整窗后果，还须在损失窗开始时已具备且在该窗内保持对应的足够工况。接口 `APPLIED`、配置写为 `1`、或窗口结束前某一刻达到需求，都不能单独证明整窗零缺额。窗中才恢复时要另有对应的条件损失，本结构不给它套上 `L_1`。

固定门下可用 `r_I=g·a·q_I`。如果授权、及时可尝试或后续行为随报告、状态或先验变动，记录联合路径 `P(Y=+,g=1,S=1｜X=0,C,I)`，不能把不同分母下的总体比例相乘。若作业统计只覆盖实际启动的尝试，还须补齐过门未启动的机会，才能使用上述 `q_I`。

## 一条记录应留哪些字段

| 记录段 | 最小可审阅内容 |
|---|---|
| 机会与背景 | 工单／机会 ID、资产和服务 ID、策略及是否发出检查、同期需求及其来源、配置和供电上下文、其他瓶颈、参考时刻、损失窗和截止。 |
| 独立参考 | 状态依据、参考容量、观测时戳、证据来源与同源组、`X` 或未知原因；标明与检查报告是否独立。 |
| 检查报告 | 命名信号、`z,e`、单位 `1`、来源和可用性、采样／到达／有效期、决策时刻、`Y` 与未解决原因。 |
| 许可与执行 | 独立许可的适用对象和时效、资源资格、查后门、是否尝试、开始／完工／拒绝或中止时戳。 |
| 功能结果 | 复检时戳、实际有效容量、同期需求与服务交付、累计缺额、是否在截止前核验、失败或删失原因；另外保留人秒与工具占用。 |

当前已保存的配对和只读回读没有这些联合记录。观测设计不提高有限工程资格；`a,b,q_I,q_R,d_R` 等仍为空，现场未就绪。本文没有启动新的设施运行或现场采集。
