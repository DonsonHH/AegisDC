# v3 留出确认协议

在揭示任何新种子前单选严格优效。主终点是 V** 对透明直接规则 B 的配对平均 L 差，其双侧 95% 重抽区间上界严格小于 0。上界等于或高于 0 均记主终点未成立；数据缺失或身份未决时报告不可判定。人员秒独立报告。主要定义只有这一种，结果公布后不得切换到非劣效口径。

未来确认的目标分母为六族各 24 条、共 144 条，各族两块十二档，沿用 v3 开发生成律。一次性角色配置、去重、完整轨迹与评分绑定冻结方法和规则；分母缺失不替换。V** 与 B 配对，另报 PA、真实 V**−probe、相对全知余量（Σ(L(V**)−L*) / Σ(L(P)−L*)，分母非正时未定义）及伦敦式、荷兰式。每条计 L、U、人员、工具、费用、首次有效关闭、900/1800/2700/3600 秒的 NA、PV。抽样单位与 10000 次分族配对重抽规则见开发协议。运行或方法失败照原样留账。

新留出种子由用户离线生成；本包登记规则哈希及新承诺状态，只有明确提供的 SHA-256 可入账。独立保管与执行授权均须另行核对。旧承诺 `73347bfb1fb120365e8f7f46ec2e342c63c3e464a3601e5c7312a987c8b4ea25` 为执行方生成、同账号可读，不用于确认。原 T3/T4a 记录继续保存。
