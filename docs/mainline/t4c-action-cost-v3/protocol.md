# T4c　行动代价、开发面板和方法比较

开发以已接受的 T4a 提交 `93a4e9b4` 为起点。旧 v2 面板中的 B 在 72/72 行达到合法服务最小值；0000 层 18/18 行均有发行和处置，服务缺额为零，B 对 P 没有服务较差行。由此可知，该面板没有留给付费核查进一步降低 B 服务损失的空间。现场信息价值和其他损失函数仍是分开的问题。v3 使用新的开发种子。原始资料、T4a V*、旧执行结果和失败均按原身份保存。[v2 原结果](../t4a-public-risk-v1/README.md)

## 事前设施规则

六族各 12 条。沿用 T3 各族的十二档背景、到达与失效时钟、外生需求、人员工具和相同粒度的原生设施。四个普通族对 C、N 两个主工单均开放合法处置，原来次要主体获得从 0 至主要写窗结束的许可；其他营运记录和次要工单原样使用。听得到工单或持有许可都不能证明设备故障。两个事故族沿用各自原许可。源文件在首次角色调用前绑定。[T3 生成规则](../t3-prior-information-v2/generator_v2.py)

每个族都有两种代价。第一种来自在运设备切换至有限维护支撑。原生已完工且写入被设施接受时，以动作前的实际本地目标判断其适应性。无适应性的操作进入维护支撑区间 [实际完工, 完工＋持续时间)，此时合成服务支撑上限为标称单位的 0.5；其余时间为 1，同既有各支撑取最小值，直接进入同一时间步的供需与原生积分。失败工单或被拒写入不触发该区间。重叠处置只联合约束共同服务。跨越业务时点、零需求或已有更严重瓶颈时以实际交付计量。

三种维护旁路条件的持续时间为 0、600、1200 秒，每族每十二档各四个名额，由独立、具名开发抽样子流打乱后分配，分配过程不看私有原因或运行结果。0 表示维护旁路可承载全服务。时长作为签发工单的公开维护条款，对所有角色可见。0.5 与时长是合成设计量级。既有容量不足和热缓冲来自原设施；事故公开资料不足以标定本组数字。

| 族 | 不必要操作的物理判别／维护解释 | 共用许可的作业 |
|---|---|---|
| 水侧与排热 | 未有滤阻时重新隔离服务中的滤支路；保留既有阻力与流量判据 | 滤支路维护、网络配置工作 |
| 网络与供电 | 当前网络本地配置已达标时再次进行配置切换；共同供电瓶颈另计 | 网络与冷却工作 |
| 有限备用 | 已达标的网络支撑在备用转换期间再操作，临时服务容量与原备用能源并列计入 | 网络与冷却工作 |
| 冷却与通行 | 可用支路被再次维护会占用外部支撑，可达性、冷热和真实取样沿用旧设施 | 冷却与网络工作 |
| 伦敦式 | 共享逻辑已修正时重复修订、备用触点已闭合时再操作、已有备用路径或机组不能承担辅助时预启动，均缺少本地作用条件 | 逻辑、路径与机组的变更 |
| 荷兰式 | 本组可由转供容量承载时仍重分组，或备冷已投运时仍申请复役。真正完成的锁存泵复位有本地适应性 | 重分组、泵与备冷的变更 |

第二种代价来自共同维护许可。一次 A 的派工从提交时独占全设施的变更名额，下一次 A 最早在前次计划完工加 180 秒时提交（等号放行）。工作人员仍按真实路径作业，收费、本人 R/X 和付费初检各按原义；被许可门拒绝的请求无发行、采样或收费。所有角色均经过同一公开执行门。旧 V* 原封接收原 v2 格式且看得到签发的工单；其建议与门的实际处置分别归档。带代价的新版本还在每个预测计划内部排这个许可。限额是共同变更窗口的合成假设。[原生工作、通行与具名许可](../t3-prior-information-v2/public_work.py) · [旧有限有损维护条件](../review-gated/R2/extensions/e1-e4-v2/README.md) · [有限电源与冷却机制](../t3-prior-information-v2/incident_facility.py)

每行用 P 和一份独立原生全知轨迹。v3 只增加非负支撑约束与写间隔。普通族额外可写的非目标参数在本族已为正常值，写入不会改善旧服务界（允许操作前移人员时，检查被优化的目标工具初位及既有界）。故旧物理下界仍构成松弛下界。全知的实际合法计划若达该界，就证明 v3 最小值；若未达到，保留未决并停止晋级，不用最好观测值代替下界。保留直接合法处置能达界的证据，审查直接最优的正余量条件与健康零余量分开。

## 方法、参照与停止规则

逐阶段先运行冻结 V*（T4a V3，λ=1）及其余冻结参照。随后运行一版带代价的 V_COST；该版作为 V**，不按板上胜负改选。B 为原透明直接规则，PA 为合并巡检与报警、共用资源的现状。B+ 按固定公开路由遍历所有可获准 A，办理本人复核，忽略诊断与价值，保留因互斥或窗口而未发行的操作。允许 B 与 B+ 同轨。P、周期巡检、报警及合法全知按原口径。两个 V 各有一版关闭自选初检的真实配对运行，共 11 臂、792 个位置；关闭初检后依当时可用的未购料、同一先验、到时免费信号和本人回执重算。对每个买过初检的条件和全板分别报告差异，事后按购买选出的子组仅作机制描述。

每个时间点以一份合法公共输入给独立决策进程。V_COST 沿用 V* 的后验与统一续决策表，只将各假设下的无适应性写入容量限制并入全窗预测，并在每个候选排程保留相同独占间隔。权重、价格、主动或复核费用、工单、等待规则、时间网格、评分与证据寿命沿用 T4a。两种消融仅关闭自选 I，保留必要的 R/X。首次开发运行前完成同公开历史异私有输入下的隔离见证。

P、全知、冻结旧 V*、V_COST、两版消融及四条运营参照和 B+ 均保留真实发行、到达、成本、关闭和被拒记录。三种工程旁路和许可边界预期独立列出，成功、失败原件均留存。开发每族一个 V* 试点。用最大完整墙时（含保存）乘 1.20 再加 8 秒作每位置投影，剩余组按每核顺序承担的位置数合并后向上取整至 Slurm 整分钟，再加每组 6 秒启动余量与固定作者／分析配额。总预留超过 144000 CPU 秒或 50 个作业即停止开发后缀，报告实际证据。工程额度 21600 CPU 秒、10 个作业另记。完整性集中列一份回执。

主报告 V 减 B；同时列 PA、周期、报警、B+ 与相应消融。各列统一在条件内配对，以六族为层、每族有放回取原条数，用相同的 10000 组抽样索引计算均差与 2.5／97.5 线性百分位。固定 PCG64，首 16 字节大端整数取自 SHA-256(UTF-8 的 AegisDC/T4c/paired/v1| 加范围键)。层编码沿用 a、b、c1、c2，以 P 的实际损失、已见证全知界和最晚启用时刻以及有权取得的信息机会判定。公开开发结果无独立确认效力。
