# 第27项：运行前的验证修订

2026-11-07。本修订发生在整场工程运行之前。原冻结提交 `9e4809aa`、第一版协议和输入仍保存；未执行第一版。第二版仍只允许一次10秒原运行及一次10秒同输入重放，失败即停，不自动重试。设施、扰动、调度规则、测量、概率、容量、预期决策、服务积分和关闭标准均不变。

预审指出三个需要核实的边界：

- 设施使用已冻结的八ULP时钟同刻规则。保存请求3.4秒，但处理点可能与该字面值相差几个浮点位。验收现在用原请求匹配实际外生事件，核实两者的时钟偏差，再查实际轨迹点。仍要求失电后保持保护，外生供电恢复与当地采样复位分开，且独立服务积分不变。八ULP不是物理量、守恒或证据到达的容差。
- 关闭必须显式包含两个规则角色，且支持记录恰好是两个时刻的四条实际记录。后验必须覆盖全部声明变体。保存检查绑定完整执行源码集、冻结请求、实际步长与每次启动账，不能以空集合或仅有部分来源身份通过。
- 输入的说明现在准确写明工单报告与实际手持流量报告的合成条件独立假设；功率测点仍采集和公开，但不是此冷却模型的因子。两处说明字段变化，原数值和数据路径不变，不宣称获得现场独立性证据。

此次只修订验证工具及来源说明，不调用设施或选择器，不扩大工程预算。正式效果试验、现场标定和完整第27项验收仍未完成。
