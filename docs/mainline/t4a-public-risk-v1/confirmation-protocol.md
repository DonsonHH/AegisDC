# V* 留出确认协议（执行前锁定）

T4a 只运行公开开发面板。待另行授权时，才由用户按 T3 的承诺程序揭示种子。在实现与参数完全锁定后，先核对承诺，再用 T3 v2 规则取六族各 24 个条件，共 144 条。保留已公布的族构造与四位实际分层，不得把本批 72 行重新标为留出。当前留出生成、访问、运行及结果回流均为零。同账号有限隔离的原边界继续适用。

**主终点。** 每行定义 d=L(V*)−L(PA)。在全部 144 个独立的条件配对上计算等权平均。依固定的六族配置，在每个族内有放回抽取 24 个条件，六族合并为一次重抽。取 10,000 次配对均差的双侧 95% 百分位区间，按排序后 (n−1)p 的相邻两点线性插值。主终点须同时满足区间上界严格小于 0 且平均人员秒(V*)≤平均人员秒(PA)。人员约束按原单位的配对点估计，不另设容忍界。上界恰为零或人员增加时，主终点为负结果；身份、合法性、分母或数值未决时登记未能判定。

**固定二级分析。** 相对原周期巡检、原报警响应及新透明直接 B，各自报告配对 L/U 差及同一重抽法的区间。报告三项资源及四个业务时点（900、1800、2700、3600 秒）的 NA、PV、曾达类型及完整实例分母。分别报告伦敦式、荷兰式及其余各族和实际层，必须单列 0000、1100。保留每个实际位置、拒绝、同轨和负结果。两个全知剩余比例的分子都是全行合计 L(V*)−L*，分母分别取全行合计 L(P)−L* 与 L(PA)−L*，主报告使用前者。分母为零则报告未定义；不删单行零分母。该比例不会把私有全知变成部署方法。二级量不挽救未成立的主判据。

**重抽实现。** 使用 NumPy PCG64。随机整数种子取 SHA-256 对 UTF-8 文本 `AegisDC/T4a/paired-bootstrap/v1|` 加范围键（全板 `overall`，单族 `family/<family>`，单层 `layer/<bits>`）所得首 16 字节的大端整数。按族名字典序，在每个族内按原条件登记顺序，用一次生成的 [10000,本族行数] 索引同时抽取所有方法和指标。族和层内部保留当前组成，小格区间如实退化。选择 V*、费用折合、λ、先验、公共门、PA/B 或重抽规则不依赖留出结果。缺少合法完整结果不得以更换条件、插值模拟或放宽置信区间替代。

V* 固定为第三版 λ=1，单费折合 30 人秒。其源码、公开依赖、分析程序和实际运行版本最终绑定在 V* 冻结文件中。本协议属于确认前的书面冻结。
