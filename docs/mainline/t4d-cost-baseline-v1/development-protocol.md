# T4d　公开比较及参数敏感性执行口径

本包使用 T4c 已公开的 72 条开发条件。B_cost 在原设置逐条各运行一次；同时，在每族按键序取前六条的 36 条共同条件上，分别运行 S1、S2、S0，每组为 V**、V**−probe、B、B_cost 和评价端全知。共 612 个新位置。首次运行之前绑定清单、算法与输入身份。[原设施及方法验收交付](../t4c-action-cost-v3/README.md) · [顺序确认协议](confirmation-protocol-v2.md)

## 固定规则及透明解释

B_cost 每分钟根据生效的工单、许可、公开默认路由、当前维护时长与公共写入间隔决策。人员、工具、路径、预算、真实本人执行和身份绑定复核沿用公共作业门。零维护时长在当前合法点立即进入排程。正时长遇到有效报警，或同一具名目标有实际本人失败回执时进入排程。报警首次合法到达的派工点即可使用。具名报警只对该工单生效，板级报警只对本板公开路由生效。授权、恢复供电通知、例行提示和固定表计均不作为故障信号。本人失败回执含同实例失败写入、终止的实际工单，或有效且异常的本人复核读数。回执仅归属自己的具名对象，每个对象沿用一次写入上限。

没有信号时，在现有已到证据、预算和资源位置下，沿公开时钟查询该工单合法的最后一个派工点；回执或占用变化后重新计算。不会预读未来报警、放行或私有事件。当前必须办理且已具备资格的本人复核 R 优先；再按写窗截止时间排现在可派的 A，最后办理适格的本人续核 X。初检 I、巡检、主动购买额外资料的次数为零。对同截止工单沿用签发顺序。如果两个当前候选按两种顺序均放不进彼此剩余的公开变更名额，则以公开默认路由选一个。这个冲突判别使用当前合法派工点、预计完工、许可恢复期，以及共用人员／工具的回执延迟；每次只实际发行第一步。选择器的输入不含固定表计与事前提示；标准化关闭状态由外部用已到公共证据记录。该规则一次冻结，不读取研究结果调整。

## 三个设置

| 设置 | 维护支撑上限 | 写操作完工后额外恢复期 | 维护时长 |
|---|---:|---:|---|
| 原 v3 | 0.50 | 180 秒 | 原工单 0／600／1200 秒 |
| S1 | 0.75 | 180 秒 | 同原工单 |
| S2 | 0.25 | 0 秒 | 同原工单 |
| S0 | 0.50 | 0 秒 | 全部为 0，容量上限无暴露机会 |

各角色每次从独立设施、证据、占用和回执开始。S0 仍执行既有工单、权限、一次操作、本人复核、一个时点一个任务及实际人员／工具占用。母条件私有参数、外生时钟、名义设备、服务需求和原始观测机会逐字节对账。S0 只同步修改明确签发的维护时长字段。V** 与其消融使用上轮冻结的同一份源码，只在新设置专用的公开参数副本中替换表中的容量和额外恢复期。B_cost 仅需该设置的公开间隔与工单上的时长。策略均收不到设置编号、条件键、原始场景、评价端标签或未来事件时刻。

每个设置逐行单独构造合法全知计划并在同一设施实际执行，检查其确实达到数值下界且有实际执行及本人复核身份。纯恒等写入背景可用数值化的既有保护轨迹及结构条件认证。新的合法见证未达到界时保留观测、状态和原分母，该行的最小值登记未决。全知差距以 Σ(L(V**)−L*) / Σ(L(P)−L*) 计算。P 无人工写入，因此三个设置下的 P 路径与原 v3 相同；同源 P 原件用作分母。若有未决或分母非正，则全板比率未定义。

## 统计与失效证据

72 行主表的方向为 B_cost 减 V**、V**−probe、B、PA。计算 L、U、人员秒、工具秒和费用的配对差、10,000 次族内配对重抽区间及服务差方向。沿用 T4c 的 PCG64 种子、族内原登记顺序与线性百分位，分族及各个实际四位层也单列；另列原工单维护时长分层。透明规则取得的服务收益份额为 Σ(L(B)−L(B_cost)) / Σ(L(B)−L(V**))。保留负值和超过 100% 的值。分母非正时标为未定义。该分解描述开发面板各方法的均值，不能单独识别算法各组成部分的因果贡献。

36 条敏感性条件以与原 T4c 一致的登记顺序进行配对，每一族内部按键序。用同一组重抽索引报告 V** 分别减 B、B_cost、V**−probe 的均值与区间。核查价值的符号取 V**−V**−probe 的平均服务差，并另看区间是否跨零。S0 既报告整体均差，也逐行保留 V** 比 B 多损失的场景与幅度。三个设置使用同一抽出的 36 条，另以 T4c 保存的原设置 V**、消融、B 和全知，以及这次 72 行中的 B_cost 提供同条件参照。

指定九条失效全部读取原 T4c 私有轨迹、原评分与决策审计。逐行区分当时可见记录的来源、到达和截止时刻，实际动作或暂缓，当时的候选价值以及评价端事后出现的物理事件。T5 输入仅记录行为和失效机制。封存研究输入及结果维持零访问。

六族各一条的 B_cost 为首批研究试点，计入 72 行。最大完整试点墙时乘 1.20 加 8 秒作为每位置投影；按每核两个连续位置，加每批 6 秒再上取整到 Slurm 整分钟。加上预先列出的输入生成、零设施隔离、六行试点、旧失效只读核对和最终统计额度。超过 45 作业或 36 预留 CPU 小时即停止后缀。各失败保留唯一的作业和位置记录。
