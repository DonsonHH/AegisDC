# 39c-21：按实例授权接受风险，不能冒充证据关闭

新增v2实例关闭声明，旧v1与closure_program=None保持原行为。本片在公开选择接口做一次红/绿，不运行设施、推理或研究试验。基础是20真实公开帧与明确合成的新实例线索；新增一条明确合成的、5.5秒已到达的管理处置记录。

管理授权须绑定来源、有限具体question-ID、允许处置和半开有效区间。审查通道还须指定唯一record_id，避免同一资产上一个实例的管理记录作用到另一个实例。记录必须当前、reported、非复制、无当前冲突／来源问题，观察不得早于本实例打开，且授权在观察时及当前时刻均有效。缺失、迟到、过期及越权记录不能关闭问题。

本片声明的授权仅覆盖cooling-direct/question-1的ACCEPT_RISK。5.5秒调用一次choose_work后：question-0仍VERIFIED_CLOSED；question-1为RISK_ACCEPTED、question_closed=True、risk_closed=False、physical_restoration_claim=False，保留实际处置记录ID。新实例没有自己的行动／复检，不能生成物理核验支持；接受风险只抑制该实例后续未发出的任务，不取消已在执行的作业或改变设施。

v2适配原24的管理处置语义：ESCALATE优先于ACCEPT_RISK；误报审查另需明确原记录、支持证据和理由，并在审查观察时及当前两次核对原有条件/服务样本、跨度、有效性与反证。行政误报审查不改写私有初始故障真值、诊断误报分母或现场故障原因。授权、证据与其他处置的负例须在后续资格独立验证，本片通过不替代这些资格或整39c验收。
