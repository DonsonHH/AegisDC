# 主线物性参考：一致EOS与受限适用域

相变运行器将使用固定容积M/U闭合所需的一致纯工质物性。当前冻结CoolProp 8.0.0、HEOS/R134a、DEF参考态的512点饱和表，压力域0.1–3.0MPa。R134a只作具名热力学研究替身，郑州实际冷媒身份仍未知；这不是实际设备选材或现场模型校准。

数据位于[参考表](../../configs/materials/reference-r134a-saturation.json)，来源/作者程序/有限验证位于[工程参考记录](../../evidence/mainline/engineering/property-reference/README.md)。运行器可只读冻结JSON，不将CoolProp变成项目运行依赖。

表在ln(p)下对T、两相比容v及比内能u插值，再派生ρ=1/v、h=u+pv；这样相变质量/内能/焓保持同一边界。固定压力的ṁh_fg近似不能直接代替固定容积ΔU。超出两相表域应明确切换已验证的模型或报告域外，不能裁剪干度掩盖残差。

有限数值参考检查包括543个离网压力点、25个由外部EOS构造的M/U/V初值及独立输入形式flash。它们只核对表/算法与同一参考EOS的一致性，不是独立经验验证，也不说明完整设施已运行。其余八域模型、配置和效果研究仍按主线票据逐项实现。
