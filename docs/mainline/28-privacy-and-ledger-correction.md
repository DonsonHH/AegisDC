# 第28项：调度只收到报告，不收到评估器标签

第三版没有运行。独立规格与规范审查指出，误报工单的备注和来源身份、共享审查档案的文字会把评估者已知的健康状态透露给调度。规范审查另发现准备和汇总失败不一定进入完整的尝试账。两份原结论和封存清单以原字节保留，仍是未通过。

本修订把工单写成中性描述，身份和审查档案只说明要核对哪条疑点。布尔报告、来源关联、到达时刻、四条支持记录及第 7 秒到达的授权审查结果不变；审查允许的分类不等于已到达的结论。最后两处授权说明也改为中性，授权范围未改。

实际公共接口夹具通过：6 个公开框架、4 次公开选择、1 次独立关闭评估，0 设施调用。两例第 1 秒的框架相同；第 3 秒误报例提议检查；第 7 秒仅有声明审查且没有实测支持，仍保持 OPEN_UNCONFIRMED。通过的四场景风险声明验证与此证据夹具分别保留，物理输入和字面预期仍与原件一致。

案例账在准备前记录 STARTED，整包账单独记录初始化、汇总、来源守卫及终态；整包失败不另加一个案例。迟到闭合评估的输入和返回逐项保存。四例仍只允许各一次，共 21.5 秒；首轮失败计入，累计上限 5 次／28.75 秒。第四版须两轴固定源复核通过才可运行。
