## 本稿的科学落点

两个面板分开。dev19 的 18 个合规条件中，I 相对 D 的服务缺额较小／相同／较大为 **0／10／8**；ext35 的 34 个合规条件为 **1／28／5**。ext35.B01 的 0／7／0 显示核查避免不必要隔离；G05/G06 解释提交早／同刻截止与未核验状态；F01/F02 说明 UPS 恰好支撑至 H20 时，窗内零缺额可以与后备失败、端点 OFF 及恢复右删失并存。

R5 只作静态结论：在原六项目录、双面板和逐行晋级偏好下，D01 的合法关闭与 A02 的资源条件各自排除非 I 项，正常完整选择必保留 I。H1／H2 的 7／8 秒是书面配方推导，不是运行结果。没有改写成 I 普遍最优、普通改进无效或 RSI 一般不可能。

正文以固定 GitHub 材料为基础，外部参考核对官方事故页、出版者记录及作者／会议机构原文。方法、文献和图文进行了同一工作流内的分工复核；这不等于外部独立审稿或独立保管。文稿修正了无停机与右删失的区分、图中分段重建标签、引用显示及数学符号字体。

## 复建出版物

在具备现有依赖的出版环境中，从本目录执行：

```bash
python tools/build_figures.py
python tools/build_preview.py
python tools/typeset_pdf.py
```

`build_figures.py` 使用已交付 `data/figure-data.json`；重新提取该数据时按图表映射提供三份哈希锁定原件并运行 `tools/extract_figure_data.py`。这些脚本不导入 AegisDC 设施、策略或评分模块，不生成研究条件。实际 Python／Matplotlib／Pandoc／ReportLab 等版本由本包回执固定；不以写作工具版本替代历史研究解释器。

本包止于中文工作稿 review，未向外投稿、未替用户验收最终文稿，也未启动新的普通改进、RSI、独立确认、荷兰或 RESP 活动。
