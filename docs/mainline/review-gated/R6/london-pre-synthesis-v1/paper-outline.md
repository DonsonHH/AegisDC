# 论文论证提纲

**工作题目**　《维护降级条件下，事前核查何时值得等待？伦敦式合成实例中的服务、工时与合法关闭》

**拟回答的两个问题。** 第一，当核查可以取得有效否定证据，但也会占用处置窗口时，固定 I 相对合法直接修订 D 在哪些条件下减少或增加服务缺额？第二，观察到这种条件差异之后，R5 v1 允许的任何一个全局策略是否具有严格晋级的可能？第一问用两份有限配对研究作答，第二问用必要条件证明作答。全文以[主张—证据—适用域矩阵](README.md)的编号约束结论。

**摘要拟稿。** 维护期的备用路径状态决定了哪些核查有信息价值，取得这些信息又会消耗实施处置的时间。我们采用一个伦敦式合成 PRE 实例，在相同外生条件下比较按证据核查、合法直接修订和既有保护。原开发清单 18 个合规条件中，核查相对直接修订没有较低缺额行。扩展清单 34 个合规条件中有 1 行较低、28 行相同、5 行较高。在唯一较低行，有效位置记录使核查者避免了带隔离副作用的作业。在截断边界，增加读取则可能使提交过晚。另把已见面板与六项后继策略目录对照，发现合法关闭义务和分别计量的两种资源各自给出不可晋级的见证。结论限于两份有限清单及指定晋级规则。[实1–实6、推3–推5](README.md)

## 7　讨论、原目标的续接条件与结论

**普通受限改进**需要一个由实际任务提出、在决策时可用合法材料区分的选择。至少有一个替代动作或策略能保留所要求的目标关闭和资源约束，并且无法仅凭已知两行或其他必要条件排除。还需要对尚不确定的服务与成本后果作事前定义的公平比较。如果区别只在评价端的隐藏状态，按条件编号选最优处理仍不可部署。[推2–推4、假1](README.md)

**RSI 增量**还需要同一策略、同一已付反馈与相同预算下，不同改进程序给出可验证的不同下一决策，并且验证这次分歧之后仍有后续的非平凡选择可观察其作用。固定 U0 应正常利用反馈，强搜索应享有相同资源和候选，最终判据不能先验地把各组映成同一输出。新的任务来源与评估隔离需另行证明。若要声称外部独立确认，还需对应的真实独立证据。这些条件供另立任务时审查。本轮没有增加候选、调整晋级标准、降低强搜索配额或扩展研究场景。[推5、假2](README.md)

**结论落点。** 对当前伦敦式 PRE 实例，已接受的结果同时给出了避免不必要处置和提交过晚的条件。服务缺额、工时与关闭状态各需证据。对 R5 v1，已有材料已经确定普通晋级的终局，不能由此登记普通自改进总目标或 RSI 获得验证。识别现场可避免性仍需要当时实际到达的资料、真实权限与服务后果记录，独立确认义务未成立、未豁免。本文至此收束，待用户审阅。
