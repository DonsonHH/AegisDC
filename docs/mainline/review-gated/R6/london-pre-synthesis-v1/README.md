**维护降级时，核查有时能避开不必要的作业，有时会耗掉合法处置机会。** B01 和 G05 给出相反方向的实测例子。D01 与 A02 还约束了策略选择。在 R5 v1 的逐行晋级偏好下，普通选择器的终局只能是 I。前者来自两种行为的实际配对，后者来自对书面规则的证明。[35 行配对表][35表] · [R5 追加判定][判定] · [具体论文提纲](paper-outline.md)

## 哪些条件改变 I、D、P 的服务与成本

I 依到时证据核查后决定是否处置，D 依公共许可直接申请同一修订，P 保留原保护。I 与 D 共享审批、执行、退出及复核机制。P 作为背景。L 是对冻结需求归一化的服务缺额积分，U 是未服务量，均覆盖 [0,20)。外生需求恒为 1 时两者数值相同。主差值为 L_D−L_I，背景差为 L_I−L_P。人员秒与工具秒各自计入实际占用。[固定分析及三处理][协议]
