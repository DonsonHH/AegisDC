## 遗漏的透明规则能走到哪里

**只在初态分支一次。** 审查对象是新鲜、开放、没有在途请求、没有已有关闭或终态失败的 PRE 初态。用该决策者自己的 v2 公开帧，先查 DIRECT 的完整链是否准入。通过则立即申请一次，后续沿同一修订、退出和绑定复核链推进。未通过则从同一未动过的初态锁定固定 I，按 I 实际可做的读取得证和关闭，材料齐全且合法可行时才用 EVIDENCE 申请。此后不会反复试探 DIRECT。实际已发请求若遭拒、执行失败或逾时，遵守原单次处置与安全退出规则，不能凭回复免费切换分支再申请。这只是一个规则形态，没有加入目录、实现、计分或购票。[固定 I／D 和公开准入源码](../../../../../src/aegis_dc/london_treatments.py) · [原请求与回执契约](../../R2/extensions/e1-e4-v2/relations.md)

## 唯一建议的下一项决定

**先判定“拟议修订对带载设备的隔离要求”能否成为申请前合法可得的一项资料，再决定是否值得立新任务。** 已有 I、D、P、C早止、同预算强搜索，以及本次核对的直接申请／核查回退逻辑，足以作为当前材料下的透明参照。复杂选择器没有显示独有终局收益。是否能用既有信息覆盖所有有价值的策略仍是开放问题。
