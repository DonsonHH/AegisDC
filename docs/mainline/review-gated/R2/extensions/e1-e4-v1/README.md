## 1. 唯一范围及通过含义

仅一个伦敦式 PRE 问题 `q-1`、一个控制器目标 `ctrl-1`、一项幂等受限修订 `FIX_CTRL`、一个聚合关键服务 L。允许顺序只读核查、一次修订申请、一次实施及一次复核；没有故障后的策略、现场设备操作、通用规划器、荷兰或 RSI。审批、保护、已批准安全退出和既有自动恢复是固定环境规则，不是事中策略。

资格目标：正确执行本包定义的观察、授权／实施／复核、时间与资源关系，并按供能和服务定义产生可复算后果。即使将来通过，也只支持这些**明确合成条件**；不识别 Google 历史可避免性、真实概率或现场服务收益。

Q11 的升级、修订实施、复核义务在本包获得规格位置，但资格状态仍为 **DEFERRED_UNCOVERED**。编写了关系／预期不等于执行或验收。其映射和剩余范围见覆盖表。

## 4. 本轮固定的推荐选择

推荐保守的 D3 证据域：只接受**公开计划恒等证书**，不提供风险仍未知时的非恒等后果支配证书。原因是目前没有经资格核验的公开后果界能覆盖未知、拒绝、中止、有害隔离等所有分支；比较两个最坏上界不能补这个缺口。

因此在本包定义的所有合法决策输入中，**M0 与 B1 的执行动作相同**，只有审计理由可不同。此为规则定义的静态等价结论，不是运行测得的效果，也不是削弱基线后的改进。D3 仍有触发和不触发见证，但不能据它主张方法增量。若要非恒等 D3，必须另有公开、适用且独立核验的支配证据，另立版本交审；本包不为制造增量增设它。

服务后果目标继续保留：本包提供将来检验合法 PRE 链及核查／直接处置条件价值的能力，不能据静态等价结论自动改掉 R3 主比较。是否调整后续研究问题由用户另行决定；不启动一个注定动作等价的 M0优于B1 收益试验。
