## 4. 统一评分与主要分析

主对比为每条件`ΔL=L_D−L_I`，P是背景参照。L是完整[0,H)的需求归一化服务缺额积分；D=0处损失率0，U总未服务量另记。包含事前隔离、故障、启动和恢复。恢复时长右删失不会使完整窗L/U缺失；轨迹本身不完整则L/U=null并保留失败。

成本向量分别报告人员秒、工具秒、按动作／阶段的实耗、资源排队、审批决定等待、未开工请求至观察停止的等待、停止时刻和请求／策略／模型调用数。等待指标可能互相包含，不相加成工时或费用；未知货币成本不填零。计算资源单列，不从合成时钟推断端到端实时表现。

先报告每组硬约束和实际阶段，再报告L/U与成本。完整且合规的I/D可按ΔL的正／零／负描述该合成条件下的缺额减少／相同／增加；这不是实用收益或统计显著性判定。若资源超额、预算、权限、状态隔离或评分不一致，保留该行及真实后果，标NONCOMPLIANT，不计为有效获益；若轨迹不完整，标UNIDENTIFIED_INCOMPLETE_TRACE，不填零或排除。未复核的实际改变照实影响物理后果，但不得标为流程关闭。
