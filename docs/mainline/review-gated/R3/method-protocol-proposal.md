# R3 候选方案：证据驱动的伦敦 PRE 核查与合法修订

2026-11-14，**PROPOSAL_AWAITING_USER_REVIEW**。本轮只登记有限 R2 验收并设计方法／协议，没有新增实现、资格检查或研究实验。本文是候选方案，不是已冻结的数值试验协议，也不授权 R2 扩展、R4 或 R5。

## 1. 目标与已接受底座

主要研究问题保持为：在相同外生扰动、需求和运维资源下，PRE 核查及其促成的合法处置，能否减少**服务缺额**，同时满足设备保护、权限和数据完整性约束。发现更多疑点、改变某个逻辑位或少做一次检查均不单独构成方法收益。

用户接受的 R2 仅覆盖 `747f1678` v2 所声明的定性机械关系、只读观察生命周期、信息／材料边界和连续离线挑战。实际执行版本 `d57b19b8`、冻结输入 `f2186fae`、发布 `487f180c` 的关系见[验收登记](../R2/execution/acceptance-20261114.json)。97单位及9组配对的既有结果不重跑、不重标为研究试验。

**T-LON/T-REF 在 e0 前预置不同 profile。** 它们证明声明关系及状态链的工程行为；没有方法申请、审批、准备、实施和复核，所以不能把两条路线的不同结果当成已测干预收益。新比较必须让各方法从同一个初态开始，任何 profile 变化都有实际执行链。

范围仍为伦敦式、受限合成 PRE。外部故障由评估器固定，方法不知道其具体未来到达时刻。故障后只有同一套既有自动控制与保护，没有新增事中策略。荷兰、全场风险覆盖、通用规划器和 RSI 本轮均不展开。

## 2. 候选 M0：可见输入、规则与输出

### 2.1 决策材料与时点

M0 是固定规则方法，不训练、不自改代码。它只在下列事件触发时重新决定：PRE 开始、合法核查结果到达、审批／实施／复核回执到达、公开许可／资源／维护状态改变、相关记录失效。请求仍在进行时保持等待，不在中间步骤不断探测隐状态。

每次输入限定为：当前公开时刻；带版本、来源组、适用工况与有效期的维护／路径资料；已合法到达的观察；批准动作目录；可信角色、许可、资源与剩余预算；公开的作业窗口截止；自身请求历史。**作业截止不等于未来故障时刻。** 缺失、陈旧、冲突和未知分别标记，不用私有评估器修补。

现有两种读取只取得 cB 或 vB，不能证明控制配置有缺陷。因此拟新增一个受权限和成本约束的只读配置证据渠道，报告适用版本的“是否将上游有电作为电源可用的充分判断／是否考虑实际连接”等限定属性。它必须经下一段 R2 资格，不能直接公开私有 `profile` 或事后根因作为免费初始知识。若研究条件事先提供同类有效配置资料，则所有比较组同样可用。

### 2.2 固定规则草案

本候选的问题谓词先限为 `R=(B连接为断开) AND (B上游有电) AND (适用控制依赖K仅按上游有电判可用)`。K 必须来自合法取得的、版本适用的公开配置证据，其观察机制待 E1 资格；M0 不直接读取私有 profile。三值判断为：任一有效条件明确为假则 R 为假；全部明确为真则 R 为真；其他为未知。同一对象／版本／适用时点无法对齐或记录冲突的条件按未知处理。R 是一个限定机制疑点，不是故障概率或整个设施保障状态。

本候选只处理一个声明的备用链问题实例，不生成全场问题清单。已有失败终态先按 D7 停止或处理明确获准的重启；否则先 D0，继而 D1 规范化证据，再按 D2–D6 判定。所有判断来自公开证据，不得调用 `PhysicalWorld.audit()`、私有 `mechanics()` 或失败真值来筛动作。

| 规则 | 当前公开条件 | M0 输出／处理 |
|---|---|---|
| D0 | 当前有未完成的合法请求或等待审批／实施／复核 | `WAIT_PENDING`；保留占用，不重复发相同请求 |
| D1 | 收到新材料或记录发生失效 | 规范化来源、有效期与冲突，将无效／缺失条件标为未知，再进入后续分支；不在这里强迫补齐所有资料，也不把未知判为正常 |
| D2 | 有效证据已覆盖本实例的判断条件，表明本项感知／连接问题不存在，或本次修订已被适用的复核证据确认 | `NO_ACTION_CURRENT_SCOPE`；只表示本项无需新增动作，不宣称全站安全、后备设备必定就绪或未来无事故 |
| D3 | 直接路径在共同公开证据允许的每个条件、合法观察结果和审批分支上，完成时间、资源占用和服务后果均不劣于先核查方案，且通过下述可提出性筛查 | 提出该直接路径，保留审批与实施约束；必须涵盖“检查后无需处置”的分支。也可采用足以证明逐项支配的直接方案上界不大于核查方案下界；仅比较双方最坏上界不成立。缺乏已取得资格的公开后果模型／界时不触发D3 |
| D4 | 需要判断风险条件，但证据尚不足 | 按固定依赖顺序补当前缺项：B连接状态 → 上游电压 → 控制依赖／版本证据；已有有效记录则复用，同源副本不增加独立证据。某分支已足以回答本实例问题时不再读无关项 |
| D5 | 上述 R 的全部条件获有效证据支持，且有通过可提出性筛查的兼容修订链 | 提出该方案；没有可行链则进入D6或资料不足，不先发请求再忽略约束。不将R解释为整个设施必定失效 |
| D6 | 判断所需信息齐全，但所有候选链违反已知权限、资源或公开窗口约束 | `INFEASIBLE`，记录具体公开约束。若障碍是条件未知，仍用资料不足而非证明不可行 |
| D7 | 实施被拒、未实施、复核无结论／未通过或公开窗口已过 | 保留对应未解决状态和已发生成本；不自动关闭、重试或改用另一路径，除非冻结预算和公开触发规则明确允许 |

D4 只补当前分支的缺项，不是无预算的补资料循环。若风险条件已获支持，转 D5；若必需资料没有合法获取路径，或行动所需时间／资源界未知，输出 `INSUFFICIENT_INFORMATION`。只有条件齐全且已知所有合法候选不可行时才进入 D6。待 R3 正式冻结时逐分支写明判断谓词及最小证据集，尤其不能仅凭 cB=0/vB=1 就断言 PLC 缺陷。对于同等级多个可行补证／方案，拟按**公开最迟完成时刻、公开资源占用、固定动作ID**依次排序；必要排序参数未知时同样输出资料不足，不编数、不用隐藏成功率排序。

**所有实际请求发出前统一做可提出性筛查**，包括 D3/D4/D5：依据公开资料，核对本动作及当前可描述后续链的许可、版本兼容、资源、窗口和必要参数；通过才提出。资料齐全而所有合法链均被约束排除时输出 INFEASIBLE；必要参数或条件未知且无合法补证路径时输出 INSUFFICIENT_INFORMATION。审批或观察结果尚未发生，不当作预知真值：允许申请不保证获批，已声明的拒绝／观察分支按其规则保留。D3 的支配证明也只能使用公开允许条件域与已取得资格的公开模型，不能读取实际私有世界或仅比较实施过程停机而遗漏最终服务后果。

候选输出包含动作或终止类别、依据记录ID、尚缺条件、所需授权及成本来源。`INSUFFICIENT_INFORMATION`、`INFEASIBLE`、`NO_ACTION_CURRENT_SCOPE` 都是合法结果，分别统计。M0 规则本身尚未实现或验证，D2/D3 的充分公开证据和可比较目录必须在下一段资格与协议冻结前逐项具体化。

M0 在此阶段是透明固定候选，不宣称算法新颖性；若与有能力的透明基线产生相同行动，应如实报告没有相应决策增量。

## 3. 最小合法 PRE 动作链（拟新增能力）

只提议一类限定修订：**经批准的控制依赖修订**，使合成控制关系在声明范围内区分实际供电路径。它不能修复电缆、解除维修隔离、强制关闭断路器、取消联锁或恢复未就绪发电设备。本方案不把读取结果或一份申请当作物理干预。

| 阶段／记录 | 必要条件与成本 | 实际状态影响／失败分支 |
|---|---|---|
| 提出 `PROPOSED` | 引用已到达证据或合法直接处置目录，明确目标版本与适用工况 | 只产生请求；profile 不变；依据缺失、冲突或不兼容可被公开流程拒绝 |
| 授权 `APPROVED/DENIED` | 有权审批者，公开可检查的授权范围和有效期；计入审批等待／处理成本 | 授权不是执行。拒绝、超期、撤销均保留；审批者也不能免费读取评估器真值替方法完成诊断 |
| 准备 `PREPARING/NOT_IMPLEMENTED` | 合格人员、工具、访问和安全作业条件，声明准备期／资源预留及必要服务影响 | 尚未改变配置；资源竞争、窗口不足、许可撤销或本地安全保护可阻止实施，计已耗成本 |
| 实施 `EXECUTED_UNVERIFIED/NOT_IMPLEMENTED` | 在授权有效且安全条件成立时完成声明作业；版本和执行身份可追溯 | 只有成功完成时，执行器才按批准变更将目标控制关系更新。失败保留旧状态；若允许部分修改，需另立模型与资格，本最小候选不默许部分成功 |
| 复核 `VERIFIED_FOR_TARGET/VERIFY_FAILED/INCONCLUSIVE` | 独立取得的到时复核记录，声明方法、适用工况、延迟与成本；不能仅转抄实施回执 | 复核不直接改变设施；失败／无结论不关闭。通过仅证明目标控制条件，不证明后备其他条件或服务结果必定成功 |

配置改变必须出现在同一连续运行的版本化执行轨迹中，与请求、授权、资源占用和实际完成时刻绑定。**不能把候选组初态直接设为 PATH_REF、对照组设为 LINE_ONLY，也不能在已知故障结果后补插成功修订。** T-REF 只可作受标记的资格参照，不能作为方法已经实施的证据。

本地保护可以依据真实状态阻止危险执行，但公开反馈只在声明处理／观察完成后，以获准粒度发布；不得通过可选动作列表、即时拒绝原因或不同错误路径免费透露隐藏配置。失败和拒绝也保留占用与反馈时标。

候选 PRE 边界：到固定外生故障开始时，停止所有新的方法决策及尚未完成的配置提交，未完成申请／作业记为“未完成／来不及”；已完成修订保持实际状态。**已造成的停机、隔离、资源占用或其他物理影响不因截断瞬间消失**：按事前批准且冻结的安全退出／保护规则继续，退出延迟、占用和服务影响均进入评价；没有合法退出路径就保留残余状态和损失。这里不生成故障后的新策略，只执行原已定义安全行为。此截断与退出规则需独立资格；若选择无物理副作用的原子准备假设，也须明确其适用限制和独立反例，不能默用。方法事前只知道公开作业窗口，不知道真实故障到达时刻。

审批和资料获取规则必须跨组相同；不能让候选免费知道缺陷、让基线承担额外审批成本，或只给 M0 有效动作。不同组的内生排队、资源使用和后果可以不同，必须真实记账。

## 5. 服务后果、硬约束与成本

拟主对象先限于同一合成聚合关键服务 L，保持服务后果目标，不将布尔 `effective_support` 当作服务交付量。需要独立取得资格的映射：供电／后备及有限保障 → 实际可供能 → 设备保护／停机 → 服务交付与恢复。不得默认有电立即全服务或恢复电力即恢复全部服务。

拟主指标为需求归一化服务缺额时间：

\[
L_\pi(\omega)=\int_{t_0}^{t_H} u_\pi(t,\omega)\,dt,\qquad
u_\pi=\begin{cases}(D_\omega-S_{\pi,\omega})/D_\omega,&D_\omega>0\\0,&D_\omega=0\end{cases}
\]

其中 D 是固定外生需求，实际服务 S 满足 `0 ≤ S ≤ D`；单位为秒。观测窗从 PRE 决策前开始，包含准备／实施造成的计划服务影响、故障期与恢复期。不能删除降载／停机期间的需求，也不能只从故障时开始积分而漏掉事前处置代价。若未恢复到窗口末，标记删失并报告未完成状态，不借延长窗口改变比较。

配对差异拟定义为 `Δ=L_baseline−L_M0`，正值才表示缺额减少。主张实际有意义的改善，还需在正式协议中确定实用门槛 Δ_min、置信区间方法和样本量依据。本轮均不赋数值。另报告总未服务量、避免／部分减轻／无改变／有害的分类，不与主指标混用。

硬约束单列：权限及版本合法、维护隔离和安全保护有效、人员／工具不可冲突占用、能量／容量不超支、数据完整性与必要停机保护不被绕过。违反硬约束的收益不能算成功；分母保留违规场景和失败，不能只报告合规幸存者。

成本分别报告：读取与等待时间、审批时间、人员工时、工具占用、准备／实施／复核时间、被拒或未完成已消耗的资源、服务中断，以及算法计算资源。费用只有在具有来源和币种时才报告；未知不填零，不把异量纲拼成任意总分。相同预算下先看服务与硬约束，再报告成本向量和支配关系。

## 6. 正常、失败与否定条件

候选条件至少包含：正常且保障条件有证据；维护隔离但已有适用控制关系；声明的感知／连接缺口；无可行动信息、陈旧／相关记录；后备真正不可用；许可拒绝或撤销；准备或实施未完成；实施失败；复核未通过／无结论；资源竞争；动作完成过晚；核查占用导致更差后果；合法直接处置更有利。它们是未来设计要求，不是本轮已生成或执行的新样本。

保留三类不同否定：

- **方法无增益／被支配**：公平且有资格的比较中未达到冻结门槛，或强基线更好。
- **机制不可行**：有充分资料表明没有合法动作能在公开约束下完成；不因实现了复杂策略改变这一结论。
- **效果未识别**：关键时间、后果或干预因果关系缺依据，或模型自由度决定结果。不能以任意参数区间代替识别。
