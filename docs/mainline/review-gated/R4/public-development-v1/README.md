主要限制来自核查链消耗了时间或预算：C01、C06b/c、C10b在10秒截断前未提交；C07b及C08b在补齐证据后已无法满足公开资源／窗口；C08a排队后连审批都未形成。C06a、C07b、C08a/b虽少用工时，却伴随更大服务缺额，不能只用工时较小宣布更好。

真实后备不可用、审批拒绝、提交失败和联锁限制使某些行即使控制流程改变也不能降低服务损失。配置复核通过、实际物理改善、流程关闭是三个不同判断。C09a/b还说明处置本身可以有害；退出失败的正原始ΔL必须与非合规标志一起保留。

上述结论只限于声明合成模型、H=20、固定公开整数秒时钟、共同输入与合法目录。不证明真实事故可避免性、现场运维收益或一般最优策略。当前没有依据报告总体置信区间、p值、发生率加权收益或实用收益阈值。
