# 静态选择与资格承接

以原19开发包C01共同配置为起点，选择器只做公共动作配方与外生时标的算术。保留公开确定顺序和整组拒绝日志。每组的自由字段、成组主因素、候选域、处理顺序及操作上限已在编制最终清单前固定。[选择规则](selection.json)

读取从上一合法资料到达的整数时点排入人员／工具共同空档，累计实耗按已完成读取工作计。每项记录保留来源、接收角色、问题／目标、采样、可用、失效时刻与版本。否定证据在相应决策且仍开放时生效。若资料无结论、未到或时窗已关，报告对应分界。静态名义链假定正常审批和执行，仅用于检查到达某个分支之前的公开条件。另记隐藏挑战、失败因素、预期应检验的阶段及实际覆盖的判据。

语义比较采用保守投影。先比较在截断前、预算及预约下真正有行动机会的读取／修订时点、到达的证据类型和必要父条件，再比较明确外生边界和已可达的失败机制。剩余资源较多但没有改变准入、无作用预约、没有实施机会的后续配方、未放电背景的能量差均不单独计入。全部维度用原整数秒、公共同一 H 和 τG／τB 对齐。旧定性／接口单位若不含可执行的H20完整配置，保留其来源身份，不能作为新的运行行占位。逐项记录最接近的已披露配置、实际使用的差异字段和配方证书。另须读完整案例解释语义差异。

每个槽位只继承其用到的关系。正常及短路查E01/E03、I11和X01/X02，观察失败查E04，权限否定查E08和C4/C7，操作失败查E05–E07与X03/X04，后备父条件查E16、C05和X05/X06。截断查T01–T03、T09及E02/E14/E15。预算、窗口与预约查T10、C4/C7、E09/E10/E15及X07。已声明的整秒组合须逐行推导最小预算、合法窗口、时标排序和适用的父状态。轨迹／评分承接E13和G01–G04。声明的支持是这些已有有限见证加上参数代入的解析依据。最终输入的研究输出待授权后观测。

完整槽位名单、共享背景关系、逐行静态前提、去重差异和资格承接随manifest交审。若模板上限用尽，记录完整拒绝轨迹、保留该槽和其配对组并交审。模板未找到只证明本次有界搜索的状态。若发现新关系或接口缺乏承接，登记具体依赖与最小补充建议并关闭该槽的运行条件。
