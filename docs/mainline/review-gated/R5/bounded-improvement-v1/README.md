**建议推进普通受限策略改进。v1 对“修改改进器能带来额外终局收益”的 RSI 试验作 NO-GO 判断。** 决策点在合法取得一项或两项诊断材料之后。策略可以继续补证、停止，或依据已有的直接处置权限申请 DIRECT。下表限定的六个可选策略能在同预算内全部评价。修改提案程序可以改变下一次询问哪个策略。完整评价后，各组面对同一张表、同一选择规则，会锁定同一策略。这是空间大小与算法定义的推论，新策略收益尚待实测。

**可证伪的问题。** 开发期能否找到至少一个允许的策略，在固定两套面板上满足晋级规则？锁定后，它对 π0 的这种关系能否在另行冻结的有限面板再现？它相对人工 H1a、合法直接 D 和背景 P 的逐行服务与成本又如何？允许出现“保留 π0”“仅修复约束”“服务与成本有取舍”以及“开发晋级、评估退化”。观察到换序、提示词变更、记忆累积、某一公开条件上获胜或命中人工建议，都不足以识别递归增量。

本次 review 的决定是是否采用这个六项目录、逐条件晋级偏好和同预算完整搜索，作为普通受限改进的实施依据。21 个评估槽位及预算属于提案。新候选结果为零，历史一次执行授权已消费，后续实现、资格和研究执行各需明确授权。原独立确认义务仍未成立、未豁免。
