# 39r · UPS 辅助断供的盈亏边界

**可写入正文的条件结论：** 对同一负载，若直接恢复已获授权、满足截止与人时约束、不会增加断供，且其及时成功概率不低于检查方案的有效恢复概率，则检查没有严格胜区。若直接恢复会打扰本已投入的设备，检查可能在一段先验区间内优于所有合法不查动作。

[Stage 3 定理与现场证据清单](39r-ups-a1-stage3-theorem.md)给出空胜区的充要条件，并区分对照不可行与检查落败。本页 v1 数值和冻结原件保持原样。

## 口径与四类动作

依据 [B1 契约](39r-backup-support-consequence.md)，分别对主控制器、内循环泵、取水泵取第2–30秒的实际零供电时长。每个负载的投入叶子约0.20秒、未投入叶子28秒，差记为 `G_j`。主服务缺额沿用原指标，不与辅助秒数、人秒或原180次结果相加。输入见[冻结规范 v1](39r-ups-a1-stage2-breakeven-v1.json)，精确区间和执行记录见[单一结果](../../evidence/mainline/engineering/39r-ups-a1-stage2-breakeven-v1/result.json)。

| 动作 | 获得投入叶子的条件（初始未投入时） | 初始已投入时 |
|---|---|---|
| 暂缓 | 保持未投入叶子 | 保持投入叶子 |
| 升级 | 允许提交升级；有效的授权及时后续处置乘以其成功概率 | v1 假定升级不扰动设备 |
| 直接授权恢复 | 独立授权、截止前可完成、符合人时预算；给定成功概率 `q` | 声明的直接恢复扰动 `d_R`，以 `G_j` 为单位 |
| 检查后恢复 | 仅在报未投入、另有授权且能在截止前完成时尝试；给定同一条件成功率 `q` | 误报触发处置时可有额外断供 `d_FP`，同单位 |

先验为 `p=P(未投入)`。已解决报告的灵敏度为 `s`、特异度为 `t`；两状态未解决概率分别为 `u_0,u_1>0`。未投入时报未投入的概率 `a=(1−u_0)s`，已投入时的误报概率 `b=(1−u_1)(1−t)`。未解决或报已投入均暂缓。查后有效恢复概率 `r_I=a·q` 仅在授权与时间门通过时成立；未通过取0。已投入时检查的期望扰动 `d_I=b·d_FP` 也只在误报处置获准且及时的情形计入。失败、拒绝、未解决或超时保留原叶子；没有把同一损失重复计入。成功提前恢复等同 B1 投入叶子，是声明的映射，不是现场验证。

每个负载的物理期望断供为 `L_1,j + G_j·[p(1−r_a)+(1−p)d_a]`，其中 `r_a` 是初始未投入时的有效恢复概率，`d_a` 是初始已投入时的期望扰动比例。相对合法动作 `a` 的检查胜区满足：

```text
p·(r_I − r_a) + (1−p)·(d_a − d_I) > k
```

`k` 是要求抵偿的同负载、同口径代价 `C_j/G_j`，是压力扫参的门槛，不追加到观测断供时长。人时单列：查后最大分支用工 `h_check+h_restore` 不得超过声明预算，期望用工为 `h_check+[p·a+(1−p)·b]h_restore`（只在查后有可执行恢复分支时加后一项）。出发、取证、回传等延迟进入相对截止门，不换算成断供秒数。冷却的服务缺额和人秒未作为这里的参数。

## 赢、输与平手的区域

以下均为声明的合成条件：`s=t=0.9`、`u_0=u_1=0.1`、升级及时后续比例0.5；参考行 `q=0.75, k=0.02`，查后另有授权且时间与人时均可行。扰动行设 `d_R=d_FP=0.10`，表示对已投入叶子施加假设扰动，并非 B1 或 A2 观测。该窗内三个负载的两叶及叶子差相同，相对代价也相同；下表是一组归一化区间，分别映射到三个负载。它不提供三次独立计算或负载异质性的证据。

| 参考情形 | 检查胜暂缓 | 检查胜升级 | 检查胜直接恢复 | 检查胜全部合法不查动作 |
|---|---|---|---|---|
| 直接合法、无扰动 | `p > 8/243` | `p > 8/93` | 无 | 无，整个 `[0,1]` 输给直接恢复 |
| 直接合法、有扰动 | `p > 58/1233` | `p > 58/483` | `p < 142/467` | `(58/483,142/467)`，约12.01%–30.41% |
| 直接未获授权 | `p > 58/1233` | `p > 58/483` | 不在合法集 | `(58/483,1]` |

每个列出的临界点与相应动作平手。有扰动参考行在下界以下输给升级、上界以上输给直接恢复；两个端点对最佳合法不查动作平手。无扰动的支配结论来自 `d_R=0`、`d_I≥0`、`r_R≥r_I` 与 `k≥0`，可容许平手；参考行的正 `k` 使比较成为严格劣势。

有扰动、直接合法时，改变成功率和同口径代价所得的**全胜区**（均为严格开区间；“无”仍可有平手，精确状态见结果）：

| 条件成功率 `q` | `k=0` | `k=0.02` | `k=0.10` | `k=0.25` |
|---:|---|---|---|---|
| 0 | 无 | 无 | 无 | 无 |
| 0.25 | `(18/173,182/277)` | `(58/173,142/277)` | 无 | 无 |
| 0.50 | `(9/164,91/186)` | `(29/164,71/186)` | 无 | 无 |
| 0.75 | `(6/161,182/467)` | `(58/483,142/467)` | 无 | 无 |
| 1 | `(9/319,91/281)` | `(1/11,71/281)` | 无 | 无 |

独立改变一项参数可见：额外检查时长从可用时间的0.59到0.60时，总时长由0.99到1，失去提前复役资格；撤掉查后独立授权同样无全胜区。检查用工占预算0.50仍可行，0.51加恢复用工0.50超过预算，策略不可行。误报扰动比例从0升到0.20时，全胜区从 `(8/93,32/97)` 收窄到 `(76/501,124/449)`。未投入状态的未解决概率升到0.50时无全胜区；灵敏度与特异度的扫描均改变边界，不能概括为不敏感。

这些是单因子更换输入的记录，不是独立机制计数。在固定其余量和逐分支预算时，断供边界的观测部分只依赖 `(a, b·d_FP)`；不同输入行得到相同组合就得到同一边界。期望人时还单独依赖 `b`，不能用这两个组合代替用工模型。

**完成范围。** 一次远端精确算术，83组参数、每组 `p=0,0.01,…,1` 共101点，8,383个参数–先验点的分支和与解析边界一致；区域由精确根给出，表中的百分数是显示近似。零设施、策略、模型和注册研究运行。这个结果只回答固定查后规则在声明条件下何时胜出；没有估计现场先验或证明检查净收益。父问题仍 `UNMODELED`，本轮交审即停。
