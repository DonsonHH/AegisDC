# 39r · 风险子问题模板

从八域目录挑一个可否证的子问题，交付一份问题与后果契约、一组匹配证据和一张判决记录。UPS 的[后果](39r-backup-support-consequence.md)、[定理](39r-ups-a1-stage3-theorem.md)、[可执行核验](../../evidence/mainline/engineering/39r-ups-a1-stage3-verification-v1/README.md)和[现场比较](39r-ups-field-tool.md)提供范例。复用以下步骤，每个域重新声明后果、证据和资格。

| 步骤 | 写入可审阅记录的内容 |
|---|---|
| 1. 限定状态 | 给出父问题、子问题 ID、同一资产和依赖服务。把潜在状态限定为互斥的两个或有限个叶子，写清适用工况和不能分类的情形。调度者只见决策时已到达的记录；真值仅用于后果复核。 |
| 2. 定后果 | 冻结外生需求、观察窗、主服务缺额的单位和积分口径。分别记录辅助连续性、人员/工具占用和硬约束。明确零、未知和右删失；人秒不能直接加到断供秒数。 |
| 3. 留一组匹配证据 | 冻结仅改变的状态、其余共同输入、读数、预算和失败口径；给出源版本及原件身份。优先使用一个匹配对照。若借用旧工程对照，核对实际输入差分并标明原用途；只有预先冻结并执行的新试验才记为新证据。 |
| 4. 列四动作树 | 同一根列 `defer` 暂缓、`escalate` 升级、`direct` 直接处置、`inspect` 检查后再决策。逐个声明授权、人员、工具、截止与资源门；检查改变信息，处置才改变设施状态。报告不确定、拒绝、过期时也要有叶子。 |
| 5. 算边界并独立验算 | 在可比域内按状态和分支列条件损失，给出相对每个合法不查动作的优势、胜区和平手；再用原条件叶子独立重算。合成设定、历史核验和现场估计分别登记。 |
| 6. 给记录与翻转条件 | 记录资产/服务/窗、证据原始来源与同源关系、采样/到达/失效、许可和截止、条件量及单位。未知留 `null`。只缺一项且其余条件固定时，给出该项使结论翻转的范围及适用域；多项未知先补输入。 |

## 判决与边界

先判资格，再判损失能否按同资产、同窗、同单位比较。资料不足、不可比和模型域外分别标 `INSUFFICIENT_INPUT`、`NOT_COMPARABLE` 和 `OUTSIDE_MODEL`。授权和时钟未核实的动作不参加排序；可能合法的参照资格未决时，不能宣告胜全部。

在二状态、合法集与条件损失固定的区段，令 `p` 为异常状态的先验概率。对某个合法不查动作 `A`，检查的优势是 `(1−p)α_A+pβ_A`，两个端点已扣掉同口径的代价。整个 `[0,1]` 可比时，`max(α_A,β_A)>0` 等价于**某处**有严格胜点；击败最佳合法不查动作还要对各胜区取交集。已有观测先验时检验该 `p`，不拿存在性判据代替现场判断。若合法集随 `p` 变，先分段；若条件损失仍随 `p` 变，重建模型。需要归一化时先核对同窗叶子差为正。

独立验算从条件叶子重算期望损失，核对两端、区间内一点评价和实际平手根。单缺项的“无胜区范围”在**该参数轴**上，表示对可比域内所有先验都无严格胜点。按[三档判据](39r-coverage-criteria.md)分别报告结构、有限工程资格和现场就绪；前两档不等待现场先验。旧有限量化计数只在主问题的条件律或价值模型实际交付并验收后更新，不能用模板或空参数代替。
