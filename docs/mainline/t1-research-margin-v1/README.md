# T1　现有任务的研究余量诊断

## 一页结论

**有可改善的条件，位置取决于瓶颈和时标。** 伦敦两批既有合规处理已经在部分行减少了 P 的损失。V6 首片虽每行都有正损失，能做的清滤在 H10 内触不到网络、存储及整流瓶颈。冷态允许受权网络修订后，24 行中有 13 行相对 P 存在可达余量，但原 J 和 B 各自只在 7 行还有余量。13 行是知道私有真值且仍须合法作业时的上限，公开证据能否及时区分原因须另查。

**首要缺口是可改变的瓶颈与足够的提前量，其次是公共信息与作业机会。** 冷态新 P 的 16 个正损失中，3 个没有硬许可余量，分别是 C02 的整流限制、C04 的存储限制和 C05 的写窗硬截止。其余 13 行的上界也不保证存在能同时改善它们的公共规则。 首片 C05 的确缺服务，却没有准许处理整流器的工单。冷态 B01 中 J、B 的 L 都为 12，合法的网络直处置能降至 1.75；同一公开根的 B02 则无需处置。一个能读真值的排程可以区分它们，在线方法不能免费区分。单纯增加工单数会增加审计负担，却不能创造服务余量。旧一小时热工见证表明，滤阻在长窗内确实能触及热保护；其故障族、初态与数值资格不能推广到全部八域或 6 小时运行。

**建议 T2 首批采用 48 个一小时条件、2–4 个工单、三种现状参照。** 用保护基线是否受损、全知上限是否可达、合法前兆是否来得及区分三项分层，再决定是否值得研究方法。第四阶段 v1 作为未冻结、零执行原稿保留，当前停止点为 T1 交审。

L 是归一化服务缺额秒，U 是未交付服务单位·秒。P 只保留原生自动保护。本文以“处理的实际 L 减合法最小 L”衡量该有限设置尚可避免的损失。正差只说明物理与作业上存在余量。供评价端使用的全知排程可以读取私有真值，必须另有实际合法轨迹达到独立下界才登记最优。它没有部署资格，结果不回流到在线方法。[诊断数据与逐条件证据](diagnostic-data.json.gz) · [作业账与简要回执](receipt.json)

## 2　合法动作能消除多少损失

**下界与可达见证。** 对每个时段，先允许计算侧运行、放松辅助负载及上游缺电限制，保留整流器功率和效率上限。按原生规则把可用直流功率按需求分给计算、网络、存储，再取需求与三项有效服务能力的最小值。若计算保护闭锁，共同服务为零。如此得到任意合法排程的交付率上界，积分后得到 L 的下界。首片的清滤不能写网络、存储或整流器。P 的冻结曲线达到这个界，零人工作业就是合法最优见证。[原电力分配](../../../src/aegis_dc/power.py) · [共同服务方程](../../../src/aegis_dc/plant.py) · [冻结求解器](bounds.py)

冷态中只有 N.A 能改变网络配置，其专属人员和工具起点就在现场。移除冷却作业竞争、放松热许可均不会把最低可能损失算高。枚举 0.25 秒公共时钟上的所有网络初检、发行与本人复检时刻，保留开题、工作及门禁时长、班次、读写窗、回执到达、真实付费阳性证据、有效期及强制本人复检的人／具／费预留，另含保持原状的可行选择。随后用合规原生轨迹证明可达，包括完整准入、本人回执、实际作用、守恒与全窗积分。即使投影中的具体排程不满足完整约束，只要其界由另一份完整合法轨迹达到，最优值仍成立。数据中的 projected_chain 是放松投影，witness.stages 才是真实合法见证。两套积分及见证与下界两条曲线的积分绝对差均在 1e−8 内，名义解析值与二进制原分数分别保存。[读回核对](collect_saved.py) · [原生完整作业约束](../../../src/aegis_dc/joint_resources.py)

每个冷态 P 只把该行原 J 的令牌换成已存在的 HOLD，独立构造真实设施，必须有 49 次公开决定，零人工发行、零人／具／费、零人工写入。先比较 T1-P 和同条件旧合规轨迹。仍缺可达见证时，只允许使用预先固定的既有 N_DIRECT／N_PROBE 再取得一份原生诊断回执。这个离线选择不向原生入口传私有真值，所有作业经本臂实际的合法证据和原有资源门。本轮没有实现新策略。[输入和求解器冻结](freeze.json) · [诊断入口](diagnose.py)
