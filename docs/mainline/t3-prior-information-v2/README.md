## C　伦敦式与荷兰式事故

伦敦式双馈线分别记录上游电压、维护隔离和连接位置。双控制器共享一个有版本的判断和输入来源，电气请求、准许、就绪和实际接管分别记账。附属终端组按 1 kW 实际消耗有限 UPS，设备失电后重新获得供电还有 120 秒启动。参考 P 在 1500 秒进入 UPS、1680 秒失电、2100 秒复电、2220 秒恢复服务。其独立缺额为 540 秒。真实完成的控制修正、获准预启动及经移交的路径恢复均有成功见证；受阻接管同样有原件。
