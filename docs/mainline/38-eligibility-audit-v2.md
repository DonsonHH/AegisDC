# 智能体与RSI进入条件：可检验性与已测效果分别判断

依据[会后决策](../meetings/2026-11-03-research-reset.md)、[固定主线](../MAINLINE.md)、[M6验收](evidence/M6.json)与[180次结果报告](../../paper/mainline-report-20261108/report.md)，本项只判断下一轮问题能否独立检验，不新增试验，也不判断AI优劣。

**修订结论：现有基准具备比较一个窄的结构化AI决策因素的条件；AI、语言理解及RSI效果均未测。** 第39项可以先设计该因素的新协议，不得继承原180次结果作为未见确认。语言理解、任务发现和递归改进还需要各自的任务与评价定义。

## 原提案为何修订

原提交`9948d55d`提议`NOT_ELIGIBLE_CURRENT_STUDY`，理由是尚无单独的语言/智能体增量任务。独立Spec复核指出：原第39项也允许结构化选单或求解器替换；已有任务及后果足以设计这种比较。**“还没有选择新假设”不等于“不具备科学资格”。** 本次接受该发现，撤回原否决。原提案与原审查失败保留，见[修订记录](38-eligibility-revision.json)。

原候选未达收益门槛、现场尚未标定、原180次预算已用完，或尚未写好未来协议，都不单独否决AI可检验性。此处的“具备条件”也不等于已经证明AI有用。

## 下一轮怎样独立比较

第39项先冻结一个结构化求解器因素、明确的模型/提示/候选规则和透明参照；保持证据、工具、权限与实际动作预算一致。模型调用、失败、令牌、时间和人工帮助另计。确认须使用未参与本轮开发、确认、消融或解释的新条件，不能在已见180次上挑规则后再称独立确认。

语言理解和任务发现需另有可核对的输入、答案或执行后果。研究RSI时，还需将静态方法、普通反馈及递归改进过程分开，匹配预算和确认条件。代码助手修bug、修改报告或多个提交不属于RSI实验。

按用户先展示现有成果、在35或40附近收束供复核的要求，本次以38后的阅读检查点交付模型、报告和全部原定结果；不在本次增加新试验。39保持`ready-for-agent`、实验未运行，40–42保持依赖，不标`deferred-by-gate`，不宣称42或总目标完成。误报/漏报、提前预防、注册比较的验证关闭及现场校准仍未测。
