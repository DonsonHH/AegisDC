# 39r · Stage 3：检查的严格胜区与现场判决表

本页为 [B1 后果契约](39r-backup-support-consequence.md) 和[冻结 v1 边界](39r-ups-a1-stage2-breakeven.md)给出解析证明。沿用每个负载的零供电秒数；人时另设可行门，主服务指标与原180次比较保持原口径。

## 定义与比较域

固定一个负载和观察窗。`X=0` 为未投入，`X=1` 为已投入，`p=P(X=0)`；B1 两叶为 `L_0,L_1`，`G=L_0−L_1>0`。候选动作 $A$ 在未投入时的有效恢复概率为 $r_A$，在已投入时的期望额外断供比例为 $d_A$（以 $G$ 为单位）。恢复只在截止前成功时取投入叶子；v1 未给迟到、拒绝和失败另设改善。对已获授权、可在截止前完成并满足人时上限的直接恢复 $R$，记 $q_R=r_R$。

检查策略 $I$ 收到“未投入”报告才提出恢复；未解决或报已投入则暂缓。设 $g$ 为查后独立授权与提前完工门（v1 为0或1），$q_I$ 为未投入状态下及时、获授权尝试的条件成功率。于是 $r_I=g a q_I$、$d_I=g b d_{FP}$，其中 $a=(1-u_0)s$、$b=(1-u_1)(1-t)$；$s,t$ 在已解决报告上定义，$u_x$ 是状态 $x$ 下的未解决率。报告不产生授权。要求抵偿的同一负载代价为 $C=kG$，$k\ge0$；人秒和工具秒另记。

归一化优势为 $M_A(p)=(D_A-D_I-C)/G$，其中 $D_A=L_1+G[p(1-r_A)+(1-p)d_A]$ 是动作 $A$ 的期望断供秒数。所以

```text
M_A(p) = p·(r_I−r_A) + (1−p)·(d_A−d_I) − k.
```

只有两种策略都合法且可行时才比较；正、零、负分别为严格胜、平手、输。以下全区间结论固定比较动作、检查的报告处理规则、条件成功率、扰动、代价和可行性，符合 v1 的逐分支人时上限。不同状态的条件报告概率仍可不同。

## 定理 1：无扰动且及时成功率不低时，直接恢复弱支配检查

若 $I$ 与 $R$ 均可行，且 $d_R=0$、$d_I\ge0$、$q_R\ge r_I$、$k\ge0$，则 $M_R(p)\le0$ 对所有 $p\in[0,1]$ 成立。因为未投入项 $p(r_I-q_R)\le0$、已投入项 $-(1-p)d_I\le0$，再减非负代价。$d_R=d_{FP}=0$ 是特例；即使误报造成非负扰动，结论仍成立。这里允许平手，也允许检查严格更差。

## 定理 2：严格胜区存在的充要条件

当 $I$ 与 $R$ 在整个 $[0,1]$ 上可比时，记已经扣除代价的端点值

$$
\alpha=M_R(0)=d_R-d_I-k,\qquad \beta=M_R(1)=r_I-q_R-k.
$$

则

$$
\mathcal W_R=\{p\in[0,1]:M_R(p)>0\}\ne\varnothing
\quad\Longleftrightarrow\quad \max(\alpha,\beta)>0.
$$

**证明。** $M_R(p)=(1-p)\alpha+p\beta$ 是两端点的凸组合。若两端均非正，整个区间非正；若一端为正，该端就是一个严格胜点。两端都正时胜区为全集；两端都非正时为空。若 $\alpha>0\ge\beta$，胜区为 $[0,\alpha/(\alpha-\beta))$；若 $\beta>0\ge\alpha$，胜区为 $(\alpha/(\alpha-\beta),1]$。根落在可比域时是平手。

任一固定、合法且可比的动作 $A$ 同理使用 $\alpha_A=d_A-d_I-k$、$\beta_A=r_I-r_A-k$。对于非空的合法不查集 $\mathcal A_0\subseteq\{D,E,R\}$，击败**最佳**合法不查动作的严格胜区为 $\bigcap_{A\in\mathcal A_0}\{p:M_A(p)>0\}$，前提是 $I$ 本身可行。交集非空才有全胜区；一个对照被排除不算击败它。

**可比域会变时。** 仅改变 $R$ 的可行域，并不改变固定参数下 $M_R$ 的公式；变化的是哪些点可以比较。若合法动作集与条件参数在有限个区段内固定，分别在各段计算胜区、与该段可比域求交，再取并集。逐点选最佳合法参照时，优势在这些区段上是分段仿射的，胜区可不连通。若成功率、报告规则或代价在区段内仍随 $p$ 变化，优势可以是非线性的，不能仅凭端点判断。

**可执行核对。** [检验包](../../evidence/mainline/engineering/39r-ups-a1-stage3-verification-v1/README.md)对冻结 v1 的 83 组、每组 101 个先验点以及精确分界点复算逐分支损失。参考行得到 $\alpha=71/1000$、$\beta=-13/80$、斜率 $-467/2000$ 和胜 $R$ 的区间 `[0,142/467)`。分段例将逆序反例的 $R$ 可比域限定为 `[0,1/4]` 与 `[3/4,1]`，得到 `(0,1/4]` 与 `[3/4,1]` 两段严格胜区；中段不可比较。这些核对不替代解析证明。

| 前提变化 | 能支持的结论与来源 |
|---|---|
| `R` 有扰动 | v1 有扰动参考行胜 `R` 为 `[0,142/467)`，胜全部合法不查动作才是 `(58/483,142/467)`；扰动存在本身不保证胜，仍要超过有效误报扰动和代价。 |
| `R` 未获授权 | v1 在剩余暂缓、升级中得 `(58/483,1]`；这是比较集改变，不能视为胜过 `R`。`R` 的时间或人时门不满足也同样先排除。 |
| 检查的额外时长0.60、检查用工占比0.51 | 两行改变的是 `I`，不是 `R`。前者令查后复役错过截止，仍可能胜过有扰动的 `R`，但输给暂缓；后者使查后最大分支超预算，`I` 不可行。 |
| `q_R<r_I` | 手推例：两者可行，`q_R=1/2`，取 `g=1, a=3/4, q_I=1` 得 `r_I=3/4`，两状态扰动及 `k` 取0，则 `M_R(p)=p/4`，胜 `R` 为 `(0,1]`。若 `k=1/4`，该概率差不足以给出严格胜点。这两个例子独立于 v1 的同成功率扫参，仅作算术核对。 |

授权与可行性决定能否比较。定理 1 无需 `d_FP=0`：误报扰动增加 $d_I$，只会使 $M_R$ 不增；直接恢复的扰动 $d_R$ 则提高 $p=0$ 的检查优势。扰动差或成功率差仍可能被代价抵消。

## 叶子与观测的等价关系

- B1 的主控制器、内循环泵、取水泵在该窗有相同的两叶，`G` 均为 `1389999999999999991/50000000000000000` 秒；v1 用相同相对代价。一份归一化区间映射到三个分别报告的负载，并非三次独立计算或异质性证据。
- 固定门、成本及其他参数时，断供胜区的观测部分只经 $(a,b d_{FP})$ 进入。v1 中 `u_0=1/20` 与 `s=19/20` 两行同得 `a=171/200`，全胜区均为 `(116/1101,284/799)`；`t=4/5` 与 `d_FP=1/5` 两行同得 `b·d_FP=9/500`，全胜区均为 `(76/501,124/449)`。这些是等价参数组合，不是独立机制证据。
- 期望检查用工仍含 $h_{check}+g[p a+(1-p)b]h_{restore}$。第二对的 `b` 不同，虽然断供胜区相同，期望人时可不同。该坍缩只适用于当前损失与逐分支可行门，不是整棵树的全局自由度计数。

## 现场证据清单

用下表决定是沿用定理 1、重算定理 2，还是先更正可比域或损失模型。

| 现场发现 | 怎么判 | 需要的记录 |
|---|---|---|
| 直接恢复未获有效授权、来不及或超人时上限 | 对该动作标记不可比较。检查策略超预算时也不能判胜。查后错过截止可使处置分支回到暂缓。 | 许可规则、适用设备、签发／失效时点、到场至复检时戳，各分支人秒、工具占用与上限。 |
| 已投入设备在直接恢复时产生额外断供，`d_R>0` | 定理 1 的无扰动条件不满足。若仍能使用两叶模型，重算定理 2；正扰动未必超过误报扰动与代价。 | 同负载、同失电窗、同初态的处置／未处置功率记录，区分直接恢复扰动和误报处置扰动。 |
| 查后授权经常拒绝或晚到 | 按有效许可和截止分层。若可用同一个固定门因子描述两状态，门因子降低会同时降低有效恢复 $r_I$ 和误报扰动 $d_I$，胜区不保证单向缩小。状态或先验相关的拒绝率不能用一个总体比例代替。 | 按初始状态和报告结果配对的许可、拒绝、作业及完成时戳；分别统计两状态下实际获准且及时的分支。 |
| `q_R<r_I` | 成功率排序反转。若 $r_I-q_R>k$，则 $p=1$ 严格胜；否则仍要看另一端点。 | 同截止、同条件的策略入口工单，保留失败、未解决、拒绝及过期，以实际供能确认恢复。 |
| 未投入时未解决率 `u_0` 上升 | 在其他条件固定时，$a$ 和 $r_I$ 不增，重算后胜区不会扩张。未解决不是“已投入”报告。 | 独立初态依据、到时证据、已解决报告与未解决记录；检查前先验按可用证据分层。 |
| 可比动作随先验或时限变化 | 区段内参数固定时分段计算。若同一区段内的条件参数仍随先验变化，不能套用全区间端点判据。 | 分层后的合法动作集及报告、许可、成功率记录；给出切换边界和边界点能否比较。 |
| 成功、失败或迟到的实际后果不能映射到所声明的叶子 | 先修改条件损失模型。若叶子差 $G$ 不为正，原归一化也不适用。 | 逐负载断供轨迹、共同观察窗、初始状态和分支结果；核对 $L_0,L_1,G$。 |
| 代价来自人秒、工具秒或另一个服务指标 | 这些量分开报告。只有同负载断供口径的代价或决策门槛才能用于 $C=kG$，已入叶子的损失不重复收取。 | 代价定义及测量，另留人秒、工具占用和到场成本。 |

现场观测检验的是这些前提和后果映射。用户已报告独立验证定理 2；本次[算术结果](../../evidence/mainline/engineering/39r-ups-a1-stage3-verification-v1/result.json)只复核冻结输入和解析例，没有估计现场参数。
