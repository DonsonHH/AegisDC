# 39r · Stage 3：直接恢复的支配定理与现场证据清单

本页为 [B1 后果契约](39r-backup-support-consequence.md) 和[冻结 v1 边界](39r-ups-a1-stage2-breakeven.md)给出解析证明。沿用每个负载的零供电秒数；人时另设可行门，主服务指标与原180次比较保持原口径。

## 定义与比较域

固定一个负载和观察窗。`X=0` 为未投入，`X=1` 为已投入，`p=P(X=0)`；B1 两叶为 `L_0,L_1`，`G=L_0−L_1>0`。候选动作 $A$ 在未投入时的有效恢复概率为 $r_A$，在已投入时的期望额外断供比例为 $d_A$（以 $G$ 为单位）。恢复只在截止前成功时取投入叶子；v1 未给迟到、拒绝和失败另设改善。对已获授权、可在截止前完成并满足人时上限的直接恢复 $R$，记 $q_R=r_R$。

检查策略 $I$ 收到“未投入”报告才提出恢复；未解决或报已投入则暂缓。设 $g$ 为查后独立授权与提前完工门（v1 为0或1），$q_I$ 为未投入状态下及时、获授权尝试的条件成功率。于是 $r_I=g a q_I$、$d_I=g b d_{FP}$，其中 $a=(1-u_0)s$、$b=(1-u_1)(1-t)$；$s,t$ 在已解决报告上定义，$u_x$ 是状态 $x$ 下的未解决率。报告不产生授权。要求抵偿的同一负载代价为 $C=kG$，$k\ge0$；人秒和工具秒另记。

归一化优势为 $M_A(p)=(D_A-D_I-C)/G$，其中 $D_A=L_1+G[p(1-r_A)+(1-p)d_A]$ 是动作 $A$ 的期望断供秒数。所以

```text
M_A(p) = p·(r_I−r_A) + (1−p)·(d_A−d_I) − k.
```

只有两种策略都可行时才比较；正、零、负分别为严格胜、平手、输。以下全区间结论要求两者的可行性和条件参数在 `p∈[0,1]` 上固定，符合 v1 的逐分支人时上限。若可行集随 `p` 变动，先限定可比区间，不能直接用整个 `[0,1]` 的端点。

## 定理 1：无扰动且及时成功率不低时，直接恢复弱支配检查

若 $I$ 与 $R$ 均可行，且 $d_R=0$、$d_I\ge0$、$q_R\ge r_I$、$k\ge0$，则 $M_R(p)\le0$ 对所有 $p\in[0,1]$ 成立。因为未投入项 $p(r_I-q_R)\le0$、已投入项 $-(1-p)d_I\le0$，再减非负代价。$d_R=d_{FP}=0$ 是特例；即使误报造成非负扰动，结论仍成立。这里允许平手，也允许检查严格更差。

## 定理 2：严格胜区存在的充要条件

在同一可比域内，记 $A_0=d_R-d_I$，$A_1=r_I-q_R$。则

$$
\mathcal W_R=\{p\in[0,1]:M_R(p)>0\}\ne\varnothing
\quad\Longleftrightarrow\quad \max(A_0,A_1)>k.
$$

**证明。** $M_R(p)=(1-p)(A_0-k)+p(A_1-k)$ 是两端点的凸组合。若两端均非正，整个区间非正；若一端为正，该端就是一个严格胜点。故空胜区的充要条件是 $A_0\le k$ 且 $A_1\le k$。当 $A_1>A_0$ 时胜区为 $p>(k-A_0)/(A_1-A_0)$ 与 `[0,1]` 的交；反向斜率改为 `<`；两者相等时，按 $A_0>k$ 决定全集或空集。根落在可比域时是平手。

对于非空的合法不查集 $\mathcal A_0\subseteq\{D,E,R\}$，击败**最佳**合法不查动作的严格胜区为 $\bigcap_{A\in\mathcal A_0}\{p:M_A(p)>0\}$，前提是 $I$ 本身可行。交集非空才有全胜区；一个对照被排除不算击败它。

| 前提变化 | 能支持的结论与来源 |
|---|---|
| `R` 有扰动 | v1 有扰动参考行胜 `R` 为 `[0,142/467)`，胜全部合法不查动作才是 `(58/483,142/467)`；扰动存在本身不保证胜，仍要超过有效误报扰动和代价。 |
| `R` 未获授权 | v1 在剩余暂缓、升级中得 `(58/483,1]`；这是比较集改变，不能视为胜过 `R`。`R` 的时间或人时门不满足也同样先排除。 |
| 检查的额外时长0.60、检查用工占比0.51 | 两行改变的是 `I`，不是 `R`。前者令查后复役错过截止，仍可能胜过有扰动的 `R`，但输给暂缓；后者使查后最大分支超预算，`I` 不可行。 |
| `q_R<r_I` | 手推例：两者可行，`q_R=1/2`，取 `g=1, a=3/4, q_I=1` 得 `r_I=3/4`，两状态扰动及 `k` 取0，则 `M_R(p)=p/4`，胜 `R` 为 `(0,1]`。若 `k=1/4`，该概率差不足以给出严格胜点。v1 用同一条件成功率，未生成这个反例；这里没有新增运行。 |

因此不能把充分条件说成“四条缺一不可”：授权与可行性决定能否比较，`d_FP=0` 可放宽，正扰动或成功率排序改变也可能被代价抵消。

## 叶子与观测的等价关系

- B1 的主控制器、内循环泵、取水泵在该窗有相同的两叶，`G` 均为 `1389999999999999991/50000000000000000` 秒；v1 用相同相对代价。一份归一化区间映射到三个分别报告的负载，并非三次独立计算或异质性证据。
- 固定门、成本及其他参数时，断供胜区的观测部分只经 $(a,b d_{FP})$ 进入。v1 中 `u_0=1/20` 与 `s=19/20` 两行同得 `a=171/200`，全胜区均为 `(116/1101,284/799)`；`t=4/5` 与 `d_FP=1/5` 两行同得 `b·d_FP=9/500`，全胜区均为 `(76/501,124/449)`。这些是等价参数组合，不是独立机制证据。
- 期望检查用工仍含 $h_{check}+g[p a+(1-p)b]h_{restore}$。第二对的 `b` 不同，虽然断供胜区相同，期望人时可不同。该坍缩只适用于当前损失与逐分支可行门，不是整棵树的全局自由度计数。

## 现场证据清单

| 要核对的量 | 所需记录 | 什么会改变适用判断 |
|---|---|---|
| 合法动作集 | 许可释放规则、直接复役是否须先核验、独立授权的适用设备、签发／失效时点，以及检查和升级被拒记录。 | 无当前有效授权即移出对应动作；不能凭面板报告补齐权限。 |
| 截止、人时与工具 | 共同起点、截止、到场、测量、报告到达、授权、作业开始／结束及复检时戳；记录各分支人秒、工具占用和上限。 | 错过截止不计及时复役，查后可落回暂缓；分支超预算则该策略不可行。墙钟秒、人秒、工具秒分别留存。 |
| `L_0,L_1,G` 与扰动 `d_R,d_FP` | 每个负载的时序功率、共同失电窗与初始状态；已投入状态下可比的处置／未处置记录，分开直接恢复与误报后的处置。 | 逐负载核对正叶子差与相对代价后再决定能否共用区间；直接处置若产生可归因的额外断供，无扰动前提失效。 |
| `q_R,r_I,r_E` | 同类初始未投入工单的合法直接、检查后与升级路径，从策略入口记录；有实际供能的恢复证据，并留失败、未解决、拒绝和过期。 | 比较同一截止前产生恢复的概率，不能只统计已完成的作业。状态置位不足以证明供能恢复；若 `q_R<r_I`，须回到充要边界。 |
| `p,a,b,u_0,u_1` | 同类工单的独立复役状态依据，与当时可用证据、检查报告配对；分开记未解决、取证拒绝与授权拒绝。先验按检查前证据分层。 | 对照状态不能由同一条检查报告反推。记录不足就保留未知，不能把未解决当作“已投入”。 |
| `C` 与 `k` | 若有同负载断供口径的额外代价，给出其测量或明确的决策门槛；另报人时、工具与到场成本。 | 不能用人秒、工具秒或冷却的服务缺额秒直接填 `C`，也不重复收取已计入扰动或截止的损失。 |

现场记录检验的是前提与叶子映射的适用性。若观测与预测相反，应核查可行集、时点、扰动或成功率定义，再判断模型是否适用。**本轮只交证明、清单与论文修订，沿用 v1 原件，未新增运行。**
