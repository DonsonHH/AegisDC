# 39c：公开状态判定与私有事件评价

已授权接口为同一设施运行`simulate_scenario`。新增公开运行声明`aegisdc-policy-run-program-v4`保留v3字段并增加`diagnostic_profile`；私有`business_program`新增`aegisdc-business-diagnostic-evaluation-v1`。原版本保持原字段及行为，新程序先校验再运行，私有真值/机会/参考字段不进入PolicySession或决策帧。

公开程序`aegisdc-public-condition-profile-v1`以设施/名义知识身份、合成来源、SI秒及有限`rules`声明条件。每条规则绑定唯一ID、目标、数值observable、单位、已声明固定或手持测量source_ids、`comparison=below`及有限阈值。不使用任意字段路径或调用者提供的状态标签。

每次实际公开决策同时记录`condition_assessment`：UNKNOWN、ABNORMAL或NORMAL，以及可用时刻、观察时刻、支持/阻断记录和外部提示记录。外部工单只是未确认上下文。只使用当前、非复制、无来源/同刻冲突且有有限误差界的数值测量；取最新合格观察时刻，不将旧、不同观察时刻的真实变化当同刻冲突。整个误差区间在阈值以下才为ABNORMAL，整个区间不低于阈值才为NORMAL，跨界/缺测/不适用质量为UNKNOWN。结论限于采样标量状态，不诊断根因、不保证连续当前状态。

私有业务程序声明唯一事件ID、`condition_id`、开启时刻、真实状态判据和参考取证机会。真实状态取同一运行私有轨迹的精确时点、仅限既有命名物理signal及目标/单位；不插值、不读未来。初始真值在事件开启时确定为FAULT/NORMAL，显式未建模的判据为UNKNOWN，未知不能填零；缺失必需轨迹或错误绑定应拒绝而非伪装未知。

参考机会在运行前固定，包含任务、开始、最早报告和截止时刻及来源。程序对完整情景、边界输入、公开名义知识/初始证据、人员资源和检查声明给SHA256，验证与当次输入一致；这些是策略选择之外的共同参考。仅改变policy不改变机会。实际不派人或占用工具不能删分母；参考不可用和未知机会仍保留完整事件，不宣称已证明全设施绝对不可检测。

事件初始FAULT、参考ELIGIBLE且截止已观察到时进入“按时故障确认”分母；截至截止没有得到与私有观察时点真值相符的ABNORMAL采样确认，计未按时确认，另区分未知/无读数、错误正常和迟到确认。它是确认端点，不意味着直接处置一定有害。初始NORMAL且窗口完整的事件构成错误确定异常的事件分母；错误异常要用对应观察时点的私有状态核对。重复判断/同源记录不能增加事件数。未成熟/未知/参考不可用分别留表，分母为零时率为null并给原因。

每条公开确定判断保留其观察时点；到达后的历史异常不能冒充此刻异常。确认可用时刻和观察时刻分开，按可用时刻是否不晚于声明截止判定及时性。新事件和窗口不能事后依结果挑选。此版本先评价状态事件，不将确认率等同服务收益、预防因果效应或现场诊断准确率，原180次指标不重标。

首个切片为2秒网络工况，检查实际1.25秒完成、1.75秒到达。0秒有工单但无测量，公开判定UNKNOWN；1.75秒取得0.25容量读数，公开判定ABNORMAL。真实初始容量0.25小于独立声明需求1；同一记录在2秒再次判断仍只计一个事件。预计事件总数1、已知初始FAULT1、可取证且截止完整1、按时确认1、未按时确认0；正常分母0，错误异常事件率null。完整资格还需正常/未知/不派人、错误证据、迟到/来源、隐态隔离及动态实例等后续切片，整39c不接受。
