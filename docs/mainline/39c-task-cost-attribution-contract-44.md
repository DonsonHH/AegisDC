# 39c-44：按实际活动归属中止和未完成成本

新增私有`aegisdc-business-cost-evaluation-v2`，声明字段同v1；v1输出和42／43原件保持。v2在已有整体成本之上，从**完整实际trace相邻时刻的左端活动状态**积分，按worker.request_id及tool.reserved_by归属任务；不得把计划路径、scheduled_completion或预算当作已发生成本。

每个实际任务均有归属记录，保留窗口结束状态和实际人员／工具分项。拒绝、中止和未完成任务不从分母删除；没有归属活动时的0只来自完整活动轨迹上的空和，不用于缺字段。门禁／集合／队列是等待子项，工具工作是占用子项。若空闲人员同时等待多个未开始任务，其队列等待形成带任务成员的共享成本，不能重复分给每项或平均编造责任；按任务量＋共享队列量与整体八项实际积分逐项核对，差异保持为明确失败状态。

发出费用按实际选择记录的declared_resource_reservation与work_intention.id归属，并保留合成单位。中止不退回已经发出的费用或累计准入包络。没有该费用通道时保持不适用／未记录；任务归属不能推断米制路径、实际货币、未插桩调用或预防收益。

首个具体工况来自42：2秒完整八域运行、0／1.75／2秒决策；检查0.25秒开始工作，私有it_access_permit在0.75秒撤销，实际现场保护中止。固定手算：移动0，工作0.5人秒，门禁／等待0.25人秒，人员互斥总量0.75人秒；工具占用0.75工具秒、工作0.5工具秒。任务在0.75秒aborted，发出费用仍1、准入人／工具包络各10。单一任务没有共享队列，八项归属均应对上整体实耗。它检验中止成本不消失，不是比较方法收益。

先在原成本实现上观察v2拒绝，再实现归属并用同一冻结输入绿测。通过后仍需正常完成、窗口内未完成、无人工、拒绝、队列共享和输入边界资格；完整成本与整项39c验收不因首片通过而完成。
