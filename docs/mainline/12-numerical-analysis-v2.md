# 数值轨迹比较的显式分析修订 v2

原始 88 档、317 项回归（315 执行、2 旧可选 Torch 跳过）、全部 ZIP／原 manifest／负结果保持。原 v1 分析使用各轨迹独立的八 ULP forward peek。组合案例 65.7 s 附近，UPS 切换仅差约 7 ULP，却在某查询点得到一边切换前、一边切换后的 2.345 MW 差。独立 0→2 MW 手定跳变复制了这一非传递问题。旧输出标为 **legacy forward-peek 分析缺陷**，不能改称严格 raw L∞。

v2 作为新的工程分析协议，分别报告：

1. **因果 raw**：不向前看，连续状态按保存点分段线性，积分中保持的热流按精确时间左保持，在两条保存时轴的并集上取最大差异。
2. **epoch-consistent**：先要求按时间排列的事件身份／模式序列完全一致，并用对应发生序号唯一配对。仅当同一配对的实际时刻差不超过两端最大 ULP 的八倍，才把其两个实际时刻之间的闭区间作为同一数值时刻；common anchor 固定为这两个时刻的较小值，绝不滚动合并。
3. **独立时间／积分**：实际事件时差、序列一致性、归一缺额、未服务单位秒及每种人员／工具／供能持续时间保留原单位和原限。真实一秒的切换差不属于数值同刻。

同一实际／参考坐标对中的多个事件属于一个处理批次。配对区间中若出现另一个坐标对的事件，则本组不允许对齐；事件错序、缺失、身份／模式不同或超过八 ULP 均不对齐。区间之外保留全部因果比较点，区间内部仅替换为显式的两侧极限比较：热流使用实际事件前一积分段的左值和事件后的右值，连续温压在事件行连续。每组记录原始两时刻、固定 anchor、区间宽、移除的并集点数以及两侧误差。没有周边容差窗口，没有把另一真正事件的瞬态抹去，也没有插值二进制状态。

0.05 K、1000 Pa、25 kW、各自单位下的 0.001 积分／时刻界保持不变。**数值资格的值误差门槛施加于 epoch-consistent 视图；实际事件时差仍独立受 0.001 s 原限约束。** 同时报出因果 raw 最大值，读者可以看清短时跳变与平滑区数值误差。参考分辨率仍要求 0.005 对 0.0025 s 的差异占对应界不超过 25%；候选最大步长预先改为 0.01 s。原 0.025 候选及其 NO-GO 不追认。

所有外生边界变化（参数、值及发生次序）也进入配对事件账，避免只配保护／备用而漏掉热流跳变。另有七个独立代数测试，覆盖八／九 ULP、0／8／16 ULP 链、近邻但真正不同事件的临时异值、错序、错身份以及真实一秒延迟。代数夹具只校验读回器，不证明完整设施可信；实际资格仍来自同一完整 V6 的保存轨迹和更细参考。

一级文献说明，混合轨迹的点对点比较会因数值求解或 jitter 的微小时移出现较大差异，时间与值需要分别表达，并保持事件顺序：[Deshmukh、Majumdar、Prabhu，CAV 2015 全文，第 2 页](https://arxiv.org/pdf/1505.05832)。[Majumdar、Prabhu 的多边形轨迹论文](https://arxiv.org/abs/1410.6075)也显式区分时间与值误差。本文有限推论是需要修正上述 matcher；本实现不是一般 Skorokhod 优化算法，不援引其定理作为本设施的保证，不从文献改变任何门槛或现场校准状态。
