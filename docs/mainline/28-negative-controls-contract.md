# 第 28 项：完整设施的四类负例

状态：已认领，待独立审查和冻结；无设施运行、策略选择或注册试验。基于第 27 项验收后的同一郑州启发 V6 合成设施，保持八个行为域、共用实体和四类独立关系。有限工程核验用于检验失败边界；不做方法优劣比较，也不把本项结果加入第 30 项效果预算。

| 情景 | 固定的初值及事件 | 独立预期 |
| --- | --- | --- |
| 正常 | 需求 0.5、满容量网络和存储、洁净滤网，稳定供电，无异常工单；7.25 秒 | 已提供与需求同为 29/8 服务单位·秒；缺额、人工工作、走动、门禁占用和处置均为零。 |
| 误报 | 与正常情景共享物理输入，操作员工单在 1.5 秒观察、3 秒到达，错误怀疑湖水低流量；7.25 秒 | 专业检查在 3.25–4.25 秒工作；4.75 秒才到达正常流量记录。消耗 1 人·秒工作及 0.25 人·秒门禁，设备未被处置；需求、交付、缺额仍为 29/8、29/8、0。 |
| 直接保护 | 初始需求 0.75，电网及 UPS 在役；内环阀 0.75 秒关闭、1.25 秒外生重开；3 秒，无人工任务 | 硬接线联锁立即停内环泵；本地 PLC 第 1 秒因流量低锁止计算；1.25 秒恢复流量仍不恢复计算。第 2 秒的下一次合法本地采样满足原温度与流量门槛时解除锁止。按该有限工况预期，需求 9/4、交付 3/2 服务单位·秒、归一化缺额 1 秒。 |
| 太晚／失败 | 初始需求 1，网络容量仅 1/4；工单 0 秒观察、1 秒到达，从控制区派同处一名合格 IT 人员和工具。IT 门禁第 3 秒因外生安全条件关闭并保持；4 秒 | 1 秒行走，0.25 秒门禁，2.25 秒开始工作，理论最早 3.25 秒完工；第 3 秒中止，已做 0.75 人·秒工作，3.5 秒才收到 NO_EFFECT。没有网络处置或恢复；需求 4、交付 1 服务单位·秒、归一化缺额 3 秒。 |

正常与误报使用同一个既有透明有限候选及其预测模型。误报发出后，公开先验、工单和手持规则沿用第 27 项，工单似然按固定有理数把坏态从 1/100 提至 25/124；健康的实测负结果使该质量回到 50/941。正常与误报在工单到达之前拥有相同证据，不能提前派工。读数约 0.1 m³/s，超过 0.08 的低流量确认阈值；不以一次正常读数自动关闭。

误报另有**声明的人工审查**，并非模拟人员推理。稀疏流量计与实际交付计数器分别在第 5、6 秒采样，第 5.5、6.5 秒到达；在第 6.75 秒审查上述四条记录，第 7 秒发布。预期在审查到达前保留 OPEN_UNCONFIRMED；仅在两项实际条件、样本数和来源都满足后成为 FALSE_ALARM_REVIEWED，关闭疑点但不标记物理恢复或 VERIFIED_CLOSED。错误报告、真实读数和授权意见保持各自时标及来源。

直接保护案例使用既有公用运行接口，人员调度关闭，保持本地物理、供电和安全逻辑。第 2 秒复位是预先声明的有限预测，实际轨迹若不满足门槛，保留失败并停止；不改阀位、阈值或时钟来追求通过。

太晚案例使用明确人工工单和一次授权任务，不拿派单基线同候选比较。公共准备框架只含名义拓扑、资质及工单到时信息，私有门禁未来状态不进入计划。闭合评估使用 3.25 秒尚未收到的反馈状态与 4 秒已到达的实际反馈，分别应为 OPEN_UNCONFIRMED 和 OPEN_ACTION_FAILED；检查输入不得补入不存在的真实采样。失败不抹去工时和损失。

拟冻结预算：每情景一次，总 4 次设施调用、21.5 秒模拟、最大步长 0.01 秒；前两情景各 7 次预定公开决策，其余无策略选择。太晚案例另有 3 个公开准备框架与 2 次只读闭合评估。失败即停并保留其已产生成果；无自动重试。全场能量/质量、需求和服务账、公开证据到达、执行记录、失败原因及有限边界均须核实后才能关闭本票。技术安排与数值以将来固定协议为准，本页不授权执行。

准备修订（未运行）：太晚案例为 0、1、3.25、4 秒的四个准备框架，包含两次闭合评估。正常与误报的预测需求都明确为 0.5；在所有好态容量≥0.5、坏态为0时，归一化缺额和第27项有理数价值预期不变。初稿仅改了关闭风险表的首段需求；静态检查发现其遗留旧第二段，原稿和检查观察保留，新输入统一为同一完整公共风险表。
