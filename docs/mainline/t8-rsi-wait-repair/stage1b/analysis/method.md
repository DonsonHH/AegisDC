# 阶段 1c 读回口径

对象为 `59fe7b1c` 封存的共享父、8 份轮账、32 个候选槽，以及同一 FIT 面板上的已保存评分。编制本文时，轮级汇总和双锁结果均已公开。以下口径在读取本次逐条件比较之前写定，属于开发结果的事后分析。

1. 候选按完整描述符和策略 ID 去重，同时保留每臂每轮四槽及实际付费次数。对照共享父，分别数缺额和人秒均严格下降、缺额严格下降且人秒不增、以及缺额严格下降但增加工时。逐轮列出每种已付的（平均缺额，平均人秒）和频数，选优规则取实际执行版。
2. 分族使用 r1 登记的五整数十二行块签名。另列构成该签名的逐行五个指示量的频数。每个签名都附覆盖条件数。机会窗口采用封存输入与空闲人员条件下的静态许可算法。聚类特征由评价端事后核对，无须启动设施、生成条件或调用研究评分器。
3. 只在实际付费的不同单坐标编辑中比较。对每行保留达到最小缺额的**全部**编辑，取 48 个最优集合的交集。交集非空表示至少一个统一编辑在这 48 行、这份编辑菜单上逐行达到缺额最小值。工作成本另按（缺额，人秒）字典序计算交集。分别报告最佳固定编辑、逐行事后最小值、锁定编辑未取到最小值的行数、锁定编辑未改善但别的编辑能改善的行数。共享父另作可以保留原策略的参照。私有条件和反事实优者只用于描述，不能充当现场选择信号。
4. 从同一条件 R 与共享父的原始十进制评分构造配对差，每 12 条组成一块，每族两块等权。Q1 用荷兰缺额，单侧 95% 上界严格小于零。Q2 用伦敦缺额，上界至多 +5 秒。Q3 对两族人秒分开，两个上界都至多 +5 人秒，并须全部合规。FIT 报两块均差、样本方差及可判的两块上界。DEV 情景假设 38 个独立块的均差和样本方差复现 FIT，使用自由度 37 的单侧 t 上界。方差为零时沿用 r0 退化规则。没有覆盖该族全部允许输入的独立等价证明时，保留未建立。另列 r1 的描述性结构簇上界；实际 DEV 的结构数未知。两块重复写 19 次无法增加独立信息。
5. 输出只含 FIT 聚合结果、结构频数及版本来源。评分读回检查行序、实际入口输入哈希、已保存评分、签名计量回执与轮账聚合。用于统计的数值取评分原文，整数微秒舍入仅用于与旧账对账。原始逐行分数和明文输入继续由评价端保留。PI 对代签委托来源的异议在本轮单独登记。
