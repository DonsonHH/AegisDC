Data and code availability

The facility, rules, measurement and plotting code are public. Each results table and figure can be traced to a public aggregate at a specified commit. Study seeds, native per-position trajectories and private access records remain under their existing custody arrangements. Public verification can reconstruct table values and check implementation identity and figures. Rerunning the facility is a separate operation. No new experiment was conducted for this manuscript.
