# 智能体与RSI进入条件：当前证据空间暂不进入

本页是基线完成后的研究进入决策，不是AI效果实验，也不是事先冻结的定量优劣判据。依据为[固定主线](../MAINLINE.md)、[M6验收](evidence/M6.json)、[导师阅读报告](../../paper/mainline-report-20261108/report.md)和180次原定运行。决策提案为 **NOT_ELIGIBLE_CURRENT_STUDY**，须经独立复核接受后，才按原依赖规则处理39/40。

## 当前具备什么

|进入条件|已知证据|判断|
|---|---|---|
|工程、信息和执行边界可信|八域耦合、到时证据、资质/工具/成本和实际处置有有限验证；180次原件完整|通过有限工程门槛|
|存在可比较的实际选择|主要确认中12个工况在相同历史下出现不同意图，涉及3个故障族且至少2个共同可用付费任务|存在；不能说“没有选择空间”|
|独立的语言理解/智能体因素有明确任务|正式输入是结构化数值/布尔记录，任务由人工预设为两个候选；没有带可核对语义真值的自由工单、任务发现或多作业分解评价|当前未形成独立增量问题|
|经验与递归改进有可分离的研究过程|已有方法在确认前冻结；本轮没有学习器、版本生成过程或普通反馈/递归反馈对照|当前没有可评价的RSI过程|
|能隔离模型假设与求解机制|稳健性显示共同预测改变可同时改变两法；依赖/团队消融也有服务与成本反向作用|需先定义具体瓶颈，不能把模型或任务空间改动归给AI|

## 为什么本轮延期

当前基准可以比较检查、处置和暂缓，已经足以否定“没有可比较选择”的说法。但在这个人工编制的两任务、结构化信息空间中，直接接入LLM只能得到另一种策略输出；它不能单凭结果说明语言理解、全场任务发现、多人协调或递归经验发挥了什么独立作用。

本轮尚未提出一个与这些能力对应、能用当前数据分别判对错的增量假设。此时增加模型与提示词尝试，会扩大方法自由度而不回答明确问题。主要候选未达到收益门槛**不是**资格否决条件；现场未标定或尚无新协议也**不单独**构成否决。延期依据是当前增量问题、输入任务与归因单位尚未对齐。

RSI还需要把“改进了策略”与“改进了改进过程”区分。人工/代码助手修bug、调整报告、保留反馈日志或出现多个提交，都不是RSI实验；本轮未测，不能报告NO-GO或无增益。

## 重新进入时需要什么

1. 先确定一个因素：例如真实工单语义转为带来源的风险问题，或多任务资源竞争中的选单；给出独立答案/执行后果与失败定义。
2. 保留相同证据、工具、权限和实际动作预算，设置透明非AI参照；新增LLM调用/失败、令牌/时间及人工帮助单独计账。
3. 用未参与现有180次开发、确认、消融和解释的条件进行新确认。现有结果可用于提出假设，不能再充当该改进的未见确认。
4. 若研究RSI，另设静态、普通反馈与递归过程对照，预算匹配；开发与确认分开。

这些是未来新研究的进入资料与协议要求，本页不创建试验、不生成候选、不读取新nonce，也不以“缺少已写好的未来协议”替代科学判断。原180次预算已经完整使用；任何新运行须另立明确协议。
