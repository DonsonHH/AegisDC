# 补充协议 v1.1：合规资格与树内观测

本页与 v1 三件规范合并，构成送 PI 审阅的冻结版本。版本入口为 [protocol-freeze.json](protocol-freeze.json)。v1 已在 `0a97b43a` 公开，三组风险频率先于其加权结果固定。下面的裁定只影响尚未执行的补充对照及耗时解释；输入、对比方向、频率、研究位置和预算沿用原锁。与 v1 P2、P3、P5、P6 有交集时，按本页执行。

### 1　不同规划器使用完全相同的自选动作掩码

在真实根及模拟节点都先处理 R/X、等待本人在途的初检以及不受支持的公开根信念。自选主体必须是 **primary 且有仍有效的公开原始工单**。根动作须通过共同的 `Gate.admit` 和公共日历。对某对象，已发行 A 即从两种新方法的菜单中删除 I，即使其 R 已完成且 I 从未发行；已发行的同阶段不可再发行。检查或写入的剩余时间窗、可用人／工具及后续成功分支强制复核必须可排入。WAIT 永远是安全退出。短视策略与树节点均用这一掩码，树内不能借假设真值排除候选。研究前用“先发 A 并完成 R、I 尚空、预算尚足”的同一公共夹具：两新臂及历史 V\*\* 都不得再发该 I。[冻结根候选生成](https://github.com/DonsonHH/AegisDC/blob/c5ecb743d4ce0ee6ffaba1ad564bf05d82ff9fc5/src/aegis_action_cost/planning.py#L144-L160)

### 2　未模拟的免费消息不形成负证据

真实决策点使用冻结后验，包括在可观测有效窗口内真正未见消息的似然。规划树从这个根分布条件化向前推进，**只按树内实际生成的行动结果／到达报告更新模拟历史和粒子支持**。没有生成的未来外生免费通道被视为未观测，不得因为合成历史里没有该记录，重新调用真实后验的静默项来剔除粒子。旧记录自然过期仍可改变许可证书和节点准入。例：在根部仍可能的 early 报警有 20／45／80 秒等候选到时，模拟至 120 秒时不能用人工空白免费历史消灭该世界；真实根在 120 秒观察到的静默照常按原模型更新。每个实际节点的行动在可见历史上共享。[静默和时效的算法出处](https://github.com/DonsonHH/AegisDC/blob/c5ecb743d4ce0ee6ffaba1ad564bf05d82ff9fc5/src/aegis_risk_dispatch/belief.py#L55-L105)

### 3　硬违规、正常拒绝和缺失分别计量

只要某臂执行了已证实的硬违规、合法性仍未决，或必要位置缺分，受影响臂／范围的**合规主比较不可判**，不发布其主点估计或主区间。立即停止新提交，保全正在执行作业的真实终态和未执行后缀。已发生调用、已知实际 L 和实耗按非合规或未决另列，原分母为 72；违规则不能靠低 L 改善“合规算法”主均差。若展示包含违规的实际算术，必须单列为 as-run 诊断。对合规反事实未知的一臂，即使违规执行有得分，也按未知的合规 L 进入 $[0,3600]$ 界。由执行器**合法拒绝**、超窗或无可行行动后完成的合规运行，仍保留真实服务和成本进入主比较。该规则逐预定对比、逐预定范围应用。

### 4　树搜索叶点评价另计

2,248,704 是四层树内公开转移上限。每条模拟另有至多一次叶续排／窗末评价，全板不超过 $72\times61\times128=562,176$ 次。冻结的 2–20 ms／树步是把叶计分摊入四步后的未测规划假设。试点同时记录转移数、叶次数、树耗时和叶耗时；首批投影和 63 作业／229,800 预留 CPU 秒上限继续约束总开销。若试点超限即停交审，不能通过少算叶成本或减少模拟数让后续批次通过。
