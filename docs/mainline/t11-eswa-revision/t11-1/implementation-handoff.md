# T11-1 implementation and execution handoff

The accepted source of scientific rules is the parent v1.1 protocol lock. The PI authorized T11-1 only. The following divisions describe implementation interfaces. Qualification and scientific computations run exclusively under Slurm.

| Work unit | Files in this directory | Dependency and interface |
|---|---|---|
| Public policy and witnesses | `baselines.py`, `worker.py`, `qualification.py` | Supply the myopic rule, eight OAT bindings and shared admissible menu. `baselines.elective_menu(pub, view, gate)` returns an ordered or sortable dict keyed by None (WAIT) or (public subject ID, phase), with values original public request dicts or None. Uses the common primary/live/once mask, gate and success-branch review calendar. `baselines.guard(pub, view, gate, has_support=True)` returns (reason, request, refusals), reason VALUE when elective, otherwise mandatory, waiting or unsupported. `worker.py ROLE` is copied into a read-only public bundle alongside frozen public modules, baselines.py and pomcp.py. Public protocol: send {"public": u} once, get {"ready": true, "role": ROLE}. Send {"view": h} and get {"decision": original decision-shaped dict, "timing": metric dictionary}. Send {"close":true} for clean exit. Root guards retain V3 semantics. |
| History tree | `pomcp.py` | Exposes `search(pub,view,weights,price,settings,gate)` returning (request, refusals, branches, winning_first, metrics). Uses the shared menu and guard at simulated public histories and the frozen knowledge/calendar/scoring primitives. Metrics use ns: `tree_ns` exclusive of `leaf_ns`, `leaf_ns`, `tree_steps`, `leaf_evaluations`, `simulations`, `nodes`, `max_depth`. The policy worker also measures `worker_wall_ns` and `worker_cpu_ns` per call and reports `reason`. Snapshot scientific decisions must not depend on timing. |
| Readback and analysis | `analysis.py` | Reads only committed pre-run registration, archived development baseline scores and persisted new unit outputs. Receives `--activity ABSOLUTE_ROOT` and produces immutable public tables and a JSON analysis under `ACT/analysis/`. Per-unit paths `ACT/positions/ROLE/KEY/{entry.json,native-entry.json,score.json,timing.jsonl,failure.json}`. Scores use frozen T4c field names (L/U/person/tool/fee/requests/refusals/first/checkpoints/work), plus `key,role,input_sha256,conformant,clocks`. Call records contain `time,reason,ipc_wall_ns,worker_cpu_ns,worker_wall_ns,tree_ns,leaf_ns,tree_steps,leaf_evaluations,simulations,nodes,max_depth`. Center timing source `ACT/center-timing/measurements.jsonl` contains `key,time,reason,ipc_wall_ns` and validated identities. Missing and noncompliant rows use the v1.1 rule. |
| Execution and integration | Other files | Controller owns identity checking, isolated public-process bridge, frozen native adapter, output custody, accounting, timing-only replay, submission/stop gates and independent delivery checkout. Only the controller submits jobs. |

Role IDs: `MYOPIC`, `POMCP`, `lambda_low`, `lambda_high`, `kappa_low`, `kappa_high`, `match_low`, `match_high`, `unknown_low`, `unknown_high`. The first two are compared as archived V_COST minus comparator; OAT uses variant minus archived V_COST. Allowlisted inputs are the 72 previously consumed T4c development cases only. No scientific retries. Read the pre-run interpretation table before interpreting any new result.
