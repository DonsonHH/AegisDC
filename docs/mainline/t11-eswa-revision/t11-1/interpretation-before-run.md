# T11-1 · 运行前解读表

本表在首次 T11-1 设施调用前发布。正式样本是已消耗的开发面板，以下措辞一律标为“事后补充、非确认”。短视 VoI 与 POMCP 各自对已归档的 V\*\* 计算，不在两种基线中择优。主比较按原定义取 Δ = L(V\*\*) − L(基线)，负值表示 V\*\* 服务缺额较低。每行 72 个预定位置，使用族内整条件配对重抽的双侧 95% 边际区间。点估计、区间、实际分母、资源及关闭证据均须同时呈现。

| 相对 V\*\* 的情况 | 短视 VoI 可用正文措辞 | POMCP 可用正文措辞 | 主张表建议 |
|---|---|---|---|
| 基线更差，合规全板区间上端 < 0 | 本开发面板上，完整续排的平均缺额低于允许一次自选写入的短视规则，报告绝对量与人时。 | 在本预算、固定随机实现和四步树深下，V\*\* 的平均缺额低于该在线树规划器。 | C1 增列该特定基线的描述性比较，部分成立的等级沿用。不能以此重新解释 H2 的信息获取效应。C2–C4 原判沿用。 |
| 无方向性差别，包括区间含 0／端点为 0 | 两规则在此比较中未分出明确方向。若所有行原始 L 逐项相同，另注明本板服务同值并核对动作或费用差异。 | 同样报告不确定或全板逐行同值。树样本量、叶开销和对无证据分支的处理照常披露。 | C1 记“本对照未显示额外服务优势”。区间含零不推出等效；相同服务也不能推出相同决策或成本。C2–C4 原判沿用。 |
| 基线更优，合规全板区间下端 > 0 | 该单步规则在此开发面板平均缺额更低；保留完整策略表现较差的条件。 | 在限定资源与公开接口下，该有限预算树搜索平均缺额更低；不能推断增加搜索预算后的名次。 | C1 增列对“更复杂规划必然更好”的反例；保留原 H1–H3 与原等级。C2–C4 原判沿用。 |
