# T11-0 自审回执

**交付给 PI 的问题**是是否接受这个方法定位及 v1.1 对照协议。形式化、文献整理和公开开发结果的情景加权已完成。两种新策略没有得到实验评价；正式重写和 T11-1 均待审。

## Standards｜规范与数据

- 固定点为 T10 发布 `abc8ff50`。历史中文和英文包以及此前所有已跟踪路径都在新目录之外，由逐路径 Git 差分核查保护。新文书与数值使用公开提交；没有进行私服登录或模型调用。
- 独立核对按每个条件直接乘权，与程序的“先求族均、后加权”不同。对 3 组情景 × 5 个角色 × 5 项绝对后果和相应差值，共 150 个发布数，逐项在六位小数舍入误差内一致。
- 初次审查发现读表程序的身份断言可能被 Python 优化模式关闭，已用显式检查替代。用正常模式与优化模式都重现两张表；改变 manifest 字节或 B_cost 的单行输入哈希时，程序拒绝继续。
- 计时回执中的整位置墙时覆盖设施推进、记录和计分。逐决策延迟仍须来自同一调用的真实时钟，或单列获授权的公共工人重放。作业预留时间、实耗 CPU、模拟时间三个量分别登记。

## Spec｜方法与推断

- 初审发现共用底层准入函数尚不能保证候选一致：V\*\* 的根生成器另行禁止已发 A 后再买 I。POMCP 树中人工缺失的免费观测还可能被误作静默证据。两项均在 v1.1 固定，并增加了不会触碰原生设施的公共资格见证设计。
- 对已证实的硬违规，即使有完整数值，合规主比较也不可判。实耗、as-run 诊断和全部 72 个预定位置继续留存。叶点评价显式计入首批投影。两路复核已逐项复查这些改动。
- C1 和 C2 仍为部分成立，C3 的登记迁移命题不成立，C4 的独立增量未建立。维护时长分层是描述性，原确认分母和负方向见证保留。经 DOI 注册记录及解析去向核对的 50 篇均为候选文献；核验层级是书目身份，重点近邻的研究内容另据原文核对。
