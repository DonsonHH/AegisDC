# Data and code availability

The public implementation, study protocols, versioned aggregate results, and program used to typeset and verify this manuscript are available through the AegisDC repository. Supplement A identifies the scientific worker, native facility core and protocol versions. Supplement B includes the full public tables and an index with file-level digests. These materials support inspection of the reported results without executing the simulator. Native per-position trajectories and sealed randomization material are separately held under their recorded access arrangements.

The author-facing public source is the [AegisDC study repository](https://github.com/DonsonHH/AegisDC/tree/donson/mainline-39c-endpoints/docs/mainline/t11-eswa-revision). The corresponding author can provide the review copy of the public supplements through the journal portal.
