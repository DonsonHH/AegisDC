# 39c首个行为：在实际设施运行中记录验证关闭端点

接口为已授权的`simulate_scenario(..., business_program=PROGRAM)`。可选参数仅在私有评价阶段使用，不进入`PolicySession`、选单或公开决策帧。旧调用没有该参数时，返回结构与执行行为保持原契约。

首版程序`aegisdc-business-closure-evaluation-v1`只定义关闭时序端点：`id`、`facility_id`、`basis=synthetic_assumption`、`time_unit=s`、`source_note`和`episodes`。每个事件声明唯一`id`、`question_id`、`task_id`、`opened_at_s`与`source_note`。事件绑定当前运行中真实公开关闭规则及实际行动，不接受调用者直接给出的成功状态。重复事件身份、错误设施身份、非有限/负时间、窗口外时刻、未知字段及没有执行关闭程序的输入须拒绝。程序应在设施计算开始前校验，避免坏输入消耗物理运行后才失败。

输出位于私有运行结果的`business_evaluation`中。每个事件保留各次实际公开关闭评估的时刻、状态、支持和阻断记录；分别记录实际作业完成、APPLIED报告到达、首次VERIFIED_CLOSED及从事件开启起的时间。不存在关闭事件时，首次关闭与延迟为null，另报截至窗口的右删失；未知不填零。

关闭端点使用现有24规则：至少两次真实的处置后设备条件与服务样本、明确采样跨度、到达和当前有效性。动作完成、症状退去、风险接受、升级与证据核验关闭保持各自状态。不得为本切片减少样本数、使用未来记录，或将直接清滤/自动恢复服务当成问题已经关闭。

离散评估只证明声明采样时刻的状态。若最后一次公开评估在8.5秒而运行窗口到10秒，报告最后评估8.5秒及其状态，10秒状态为未评估，不外推连续恢复或持续关闭。首次关闭8.5秒仍是已观察到的事件。

首个输入是从已接受27工程参考独立复制的新39c夹具，保留原参考不改；同一完整V6设施运行10秒。冻结预期：实际清滤作业6秒完成，报告6.5秒到达；7/8秒的处置后采样分别7.5/8.5秒到达，首次可核验关闭8.5秒。服务在4秒的自动恢复与人工清滤分开归因。输入复制和预期整理不调用设施或选择器。

本切片不是39c全部范围。动态实例适配、故障/正常/未知真值、机会分母、提前/删失及匹配反事实、完整成本仍须逐个后续行为验证；首版输出对诊断和预防端点明确标未定义，不冒充0误报/漏报/预防收益。原180次、旧关闭程序、失败和研究结论保持，新增注册研究样本为0。
