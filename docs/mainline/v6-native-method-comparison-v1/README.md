## 研究问题与可支持的主张

在同一工单、同一合法信息机会、同一资源约束和同一外生设施条件下，当前证据价值策略 V，相较允许不查而直接处置或暂缓的强规则 D，能否减少真实服务损失？在服务相同的条件中，它能否节省人员、工具或发行费，同时保有比较对象已经实现的合法关闭？**V 对 D 是唯一主比较。** V 对固定条件核查 K 是预定的次比较，用来区分“选择何时查”和“见 LOW 就动”；P 给出完全依赖本地保护时的全窗背景；H 与 V 的输出一致性是归因前置条件。所有处理使用相同的工单生成方式，因此比较只识别同一问题开题后的选择差异。

| 证据等级 | 判定对象 | 足以报告的证据 |
|---|---|---|
| 机制 | 计划是否完整、本人结果是否到时、真实阶段、动作能否写入、共享能力是否双派 | 规则推导与有限工程见证分列；实际公开及私有日志证明到达过的阶段。可行分支的预测数值继续注明模型假设。 |
| 合法关闭 | 每个预声明工单是否获得当时有效的本人闭环证据 | 同一实例的 APPLIED、工作完成回执、本人复检及规定的多时点状态／服务记录。首次关闭时间与指定时点的当前状态分别报告。 |
| 同服务下的资源改善 | 一对合规完整臂的两项真实服务指标均相同；在保有规定关闭的前提下比较三项资源 | 人员秒、工具秒与发行费各自不增，至少一项严格减少。单项省工时但失去合法关闭的行，保留“等服务、节省何种资源、损失何种关闭”三项事实。 |
| 有限面板的实际服务改善 | 固定比较双方在全部预定行上的实际同窗服务与义务 | 预定成对结论和否决条件见下。预测领先、动作成功和流量恢复分别只能支持其各自端点。 |

等级描述各类证据的依赖关系。工程见证、未服务量的预测、现场效果和真实政策递归收益各有独立证据门。本版状态没有执行研究或取得上述主比较结论。

## 评价的单位、方向与量纲

**配对单位**为一份共同条件，从本组 0 秒空历史开始，所有组都积分至 H=10 秒。每个条件独立生成 V、D、K、H、P 五份原生轨迹。条件 C17 的两张独立工单只增加实例级分母。按全部预定工单数，17 行每臂有 18 个实例机会（C17 占 2）；缺少实际开题的机会按“未开题／删失”保留。5 组共 90 个预定实例槽记录。按同一物理场景和外生事件计有 5 个物理背景，各背景条件数量不同。两套报告都保留，公开假设的变化不能增加独立物理样本数。

**主服务指标**。对原生余额记录中的每个正时长段，用该段外生服务需求 d、实际交付 y 和时长 Δt 计量。全窗相对缺额时间 L=Σ[(d−y)/d]Δt（d=0 贡献 0，单位秒）；未服务量 U=Σ(d−y)Δt（服务单位·秒）。U 同时核对 demand_service_unit_s 与 delivered_service_unit_s 之差。禁止把组件分别短缺相加，也不能以已完成服务为分母。本表所有行 d=1，因而 L 和 U 数值相等；保留字段与量纲，并列相等不增加一个独立证据。表中正向差统一定义为“比较臂减 V”，正值表示 V 较低。[物理分配、服务最小值与余额积分](../../../src/aegis_dc/plant.py)

**算术约定**。对已保存、有限的 JSON 整数／binary64 标量，作为其确切解码数，以精确有理数求和、相减和比较。L 最终分类用逐段 service_deficit_time_s 贡献，U 用逐段 demand_service_unit_s 减 delivered_service_unit_s。另列原生摘要与独立逐段和的差、时间网格、物理交付率变化时刻。若轨迹完全覆盖、d 与 y 的分段常值历程在双方网格并集相同，只因分段乘法／累计产生微小差，则用共同网格对 d、y 原始有限标量与端点精确积分，两臂归为同服务。若两种口径同号且严格才列严格差；一为零或方向矛盾且无法由相同历程解释时标为“数值未决”，保留原数字。资源同理对人员／工具占用等级与到时区间交叉核对。无跨条件的实用阈值或场地统计采样依据；不据单个浮点尾差给出实际改善。这些是数值一致性规则，完整源轨迹及 raw/delta 始终归档。这两种积分使用同一条 binary64 轨迹，可能共享上游积分误差；严格差只指固定版本、0.01 秒最大步长下的离散设施输出差，不据此声称数值已收敛或达到实用效应。对两条有效臂的各服务量，逐段余额差与共同网格原始率差皆为零或整段率历程完全相同则判同，两者同号且非零判该方向，其余为数值未决。人员、工具、费用的“相同／严格下降”同样按原生字段和区间回算的符号判，发行费使用精确整数／有理声明。[余额与实际占用字段](../../../src/aegis_dc/cost_endpoints.py)

**资源及义务**。人员实耗为移动＋专业工作＋等待人秒，门禁／会合等是等待分项，避免重复计量。工具用 tool_occupation_tool_s，另列 tool_work_tool_s。声明费用逐次实际发行计数，未发行的计划分支不收费；另列额度、spent_or_reserved、remaining，累计发行包络不退款。失败与拒绝消耗的费用和已走过的时长都保留。在公开时钟 5、7.5、H10 秒分别报告每个预声明实例当前是否 risk_closed / question_closed、状态与引用；同时报告首次 VERIFIED_CLOSED 的决策时刻、本人复检发行／完成次数、本人行动与回执身份。若从未关闭，首次时刻为 null，配 terminal open／右删失 H 或已止的失败说明。曾关闭而 H10 待验证保留这两个端点；从未开题填 NOT_OPENED。尚未清滤／无效果／行动完成但无有效复检／复检过期／刚好在 H10 待处理，各列保留。一次清滤后的复检义务从实际成功、工作回执可用起按本组记录计，等待、未取得证据和越权冒领分栏。[关闭评估](../../../src/aegis_dc/problem_closure.py) · [实际到时与期满的验收](../v6-intake-expiry-closeout-v1/README.md)

**条件性预测**。在 V/H 的实际公开根，保存各变体的联合质量、三种计划的可行性、预测起工／完成／报告时刻、共同续表以及各自 ([8,10) 预测未服务量、预计人员、工具、费用) 向量；具体计划时间以该臂日志为准。D 保存直申／暂缓谓词与贯穿复检的可行性，K 保存阈值、本人实际读数／状态与行动门，P 保存无人工意向。无需这些值的处理列 NA 并说明。预测不得代填真实 L/U，物理设施中的恢复只能按同外生配对解释。[结构不等式及合成预测](treatments.md)

## 有限面板如何裁决

1. 原表固定 17 条件 × 5 个处理。每个 V–D、V–K、V–P、V–H 对照均有 17 个预定配对位置。输出行表同时给出预定数、启动数、物理完结数、有效合规成对数及各类缺失。三项探索性解释保持分层呈现：五种物理背景内部、决定前真实可得的公开条件、缺失／竞争等实际机制。公开材料内的条件虽可重复使用，所有处理的本次轨迹须单独实际取得，禁止用旧 19 行或 T1–T4 输出填表。
2. 按每行先判完整与合规。越权或超额发行、用未来信息、借别组测量、无身份关闭、复检义务被跳过却伪称关闭，列为硬约束违规；设施依法拦住尝试、未知报告、低值未改善物理状态、窗末开放，在如实执行与记录时均可合规。记录 D 的合法关闭所覆盖的实例：若 D 曾合法关闭，V 也须在 H 内曾关闭；在固定 5、7.5、10 秒 D 已合法关闭的实例，V 同时须有真实合法关闭。各比较对照同样适用。以选择策略导致少做工作来减少合法关闭，须明列权益取舍。
3. 面板级“实际服务改善”要求所有 17 个 V–D 位置可判、V/H 一致、无新增违规或上述关闭退化；逐行 L_V≤L_D 且 U_V≤U_D，并至少一行两项均严格下降。为零的改善行、反向行和不可判分别报告。部分可判时只发布逐行证据和全分母，暂不授予面板主张。V–K 同一规则、单列次要解释；V–P 提供背景。跨臂差异从来不识别真实事故可避免性。
   面板同时输出两个指示列：纯物理服务方向（只按 L/U 判）与“服务改善且关闭保有”的联合主张。C02 是预先可知的压力点：如果正常读数使 V 停止人工处置，而 D 依配方在 7.5 秒合法关闭，那么 C02 单行就能否决全板联合服务主张；若该行服务相同，它也能否决等服务子集上的联合资源主张。另一行的真实服务下降／上升方向、C02 自身实耗差和关闭差都继续报告。这是由关闭保有判据推得的条件性限制；C02 的实际处理轨迹和实际服务积分仍须独立取得。
4. 在两项服务相同的合规行上分别给出 Δ人员、Δ工具、Δ费及关闭情况。若声称“等服务下的有限面板资源改善”，须在全部预定 V–D 行都可判，披露等服务子集的分子／分母，且该子集中均满足关闭保有、三项不增，并至少一行严格节省；其余不等服务行列出权衡。这项结论的适用域只限有记录的等服务子集。单行有取舍照实给值。服务优势与资源优势不汇成加权总分。
5. 失败保留原结果；技术异常、设施退出不完整、隔离或输入身份失败、预算超限、缺必要输出，已启动行标 FAILED／PARTIAL，不能推断的数值为 null，标出最后可核阶段及未执行后缀。合法未到达、未能开工或无效果保留实际物理全窗值。硬限制／对账错误导致停止时，剩余臂和行以 NOT_EXECUTED 占原分母。V/H 对逐时公开记录、去除处理标签／目录／墙钟后的意向和结局不一致即中止：这是等价与隔离异常，未锁定数据不继续分析。没有实际收益的结果及所有反例按原顺序发布。没有总体统计功效、置信区间或独立确认推断。
