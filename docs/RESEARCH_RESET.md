# 当前研究定义：设施风险与按需检查

依据[会后确认](meetings/2026-11-03-research-reset.md)。先确定工程对象和量化依据，再检验检查机制，智能体与RSI后置。

## 研究问题

在固定测点稀疏、资料可能陈旧的算力设施中，如何把资产/服务依赖、历史与人工记录、可用固定测点及现场结果组合起来，选择值得核查的风险问题，并评价检查及后续处置的价值？

按需检查的目标不是每次必须阳性，而是在同等信息与资源条件下改善风险决策、及时确认和服务保障。没有可执行的风险问题时不自动启动全场轮巡；高风险但检查无信息价值时，也需要考虑直接升级/处置或补充资料。

## 对象与信息边界

建立三套不同关系：资产/空间台账、服务依赖图、行走可达图。供配电、HVDC、UPS/电池、应急电源、冷冻/冷却、泵/过滤/换热、CDU/设备液冷、IT/网络/存储、控制及房间环境均进入候选模块目录；是否在某站实例化，以原始工程证据为准。

设施后台可运行控制/故障模型，但决策者只看到当时可用的证据。固定测点是可选补充，不能假设覆盖所有资产；历史与现场检查结果也可能漏检、过期或互相冲突。隐藏故障发生和未来标签不能直接触发已知问题。

## 风险量化与方法主张

FEMA提供危险源、资产、情景、影响、脆弱性和能力复盘的过程参照；DHS的NIPP资产/系统/依赖框架（FEMA培训托管）作为补充。它们不等于某个已校准的设备评分公式，详见[FEMA原意与改编](research/20261103/fema-risk-framework.md)。

1. **定义风险情景。** 先给工况、时间窗H、资产与服务依赖、可观察证据及处置选项。
2. **计算有单位的风险。** 对互斥损失情景，以R_H＝Σ p_s(H|I)·E[L|s,H,I]作为候选量；概率、频次与条件损失不能混用，损失账目去重。
3. **分别保存后果维度。** 经济、服务中断、算力服务量和人员安全分别报告。没有可审查换算时，不任意把“元＋小时＋人”合成一个分数。
4. **计算检查价值。** 检查只改变信息；价值来自它如何改变可执行处置。比较无检查时的最佳行动成本，与“检查结果→选择行动”的期望总成本，再扣检查费用。没有处置增量时，不把信息更新写成已避免损失。
5. **保留不确定性。** 真实参数未知时给出缺口、区间或补证任务，不把缺测当0风险；合成数值与现场校准参数分别登记。
6. **独立验证。** 预先冻结信息条件、阈值、评价窗和资源；用时间/设施分离数据检查概率校准、漏检/误报、成本及服务结果，保留低风险独立复核以识别选择偏差。

“风险高→一定先检查”不是本阶段已证明的方法；后续将比较风险排序与净信息价值/处置决策的差别。原机柜温度风险代理分与本方法的概率/损失对象分开。

## 验证顺序

|阶段|要产出什么|通过后才研究什么|
|---|---|---|
|A 设施结构|三种工程参照的模块/依赖/来源、已知未知参数、合成结构验证|耦合状态与情景模型|
|B 风险基线|统一时间窗与损失账目、参数依据、可复算风险和检查价值|问题触发与动作闭环|
|C 检查闭环|观察/确认/处置/验证关闭分离，资质/工时/访问/任务期限|策略效果与成本|
|D 独立比较|在相同信息与预算下比较按需方法、透明启发式及传统定周期对照|智能体模块独立增量|
|E 智能体与RSI|单独改变理解、排序、反馈或改进过程，保留版本与回退|递归改进归因|

当前推进A—B的结构与数学原型。真实拓扑、故障率、检查性能及处置效果仍需工程资料和数据标定；旧v11报告为会前实验快照。
