# 可用稀疏测点，不能依赖全覆盖实时遥测

状态：accepted，2026-11-03，依据用户补充确认。

已有固定传感器、人工工单、历史资料与现场手持仪器结果都可成为可用证据，前提是来源、时刻和质量明确。新方法在缺少固定测点时仍有定义；后台真实状态与未来标签留给评价，不能用它们隐式生成风险问题。资产服务依赖和行走可达关系分别建立，默认不生成固定全场巡回。

2026-11-05 用户再次明确：固定传感器肯定存在，但受成本等条件限制，无法覆盖每个位置；允许历史巡检/资产资料、人工报障或工单、到场手持仪器结果。主研究场景因此包含稀疏固定测点。缺测、停用和无该类输入的检查用于检验方法在这些条件下是否仍有定义，不能把主场景表述为没有固定传感器，也不能据此假设全场实时可见。
