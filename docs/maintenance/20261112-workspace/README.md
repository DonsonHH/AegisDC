## 研究怎样继续

建议以“**哪些可行条件使核查改变后续动作与服务后果**”作为可证伪问题，保持八域合成设施作为共同背景。已有[论文结构](../../../paper/conditional-inspection-value-structure-20261111.md)与这个方向相符。下面是建议顺序，未执行新试验，也未改动已冻结票的状态。

| 顺序 | 下一份可验收结果 | 为什么先做 |
|---|---|---|
| 1. 对齐评价含义 | 处置 39c 五项审查发现：稳定事件身份、移动距离的已测／未测口径、成功 CLI 原始提交绑定、管理接受与物理关闭术语、有限前置授权；然后再固定整票回归和 fresh 清单。 | 指标与来源先可信，否则更多样本只增加解释负担。是否增加米制距离应由票面要求决定，不用零替代未测。 |
| 2. 对齐决定顺序的时尺度 | 经用户授权后完成 39t／39d：人员移动、作业、证据延迟、保护、备用与服务损失窗口共同对账；报告哪些区间会改变可行顺序。 | 现有 30 秒工作点仅获有限执行器核验；不能把压缩时间算例升级为现场排程。 |
| 3. 冻结最小机制比较 | 在同一八域设施、同一外生条件和资源下，对照合法暂缓、直接授权处置、检查后处置及透明基线。先规定无收益／有代价／不可行条件，再定种子、预算、实际门槛及失败规则。 | 检查获得信息不自动意味着更好的行动；参照必须包含合法的直接处置。新的比较独立于原 180 次，不借旧确认结果调参。 |
| 4. 量化共享资源的作用 | 在有资格、工具、许可和截止记录的条件下，比较两问题竞争与不竞争；先验证可行性，再比较服务后果及人时。 | 现有 A/B 顺序演示证明有限可行性，尚未识别服务收益。不能用更好看的排程图代替结果。 |
| 5. 形成有边界的论文证据 | 保留负结果，报告收益出现／消失的条件、成本和失败；Frontier 实测作为外部量级参照，同站检查—处置—服务记录另行配对。 | 真实遥测不能单独提供“未检查会怎样”的反事实。合成机制、外部量级和现场收益是不同证据。 |
| 6. 条件式 AI／RSI | 只有上述评价可信且任务有实际决策空间后，再以独立协议评价决策求解器或经验增量。 | 当前没有 AI／RSI 效果证据；加模型不能补齐机会分母、时标和现场授权。 |

优先停止条件也应预先写清：如果多种合法策略在声明条件下产生相同动作，或检查总是晚于可挽救窗口，应保留这个负结果，修订问题或条件的协议，而不是追加模型复杂度。
