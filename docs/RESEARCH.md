# 研究目标与边界

## 1. 导师要求和研究基础

仓库归档的导师原话是：“在这个PDF论文基础上优化，嵌入RSI的思想即可”。后续场景要求包括供电、液冷、自控的耦合，异质专业能力，以及根据风险决定谁在何时去哪里、检查什么，避免长期盲区和无意义重复。

指定论文：Samuel Yanes Luis 等，*Variational model-based Deep Reinforcement Learning for Non-Homogeneous Patrolling aquatic environments with multiple unmanned surface vehicles*，Expert Systems with Applications 270 (2025), 126483。[DOI](https://doi.org/10.1016/j.eswa.2025.126483)。

要求来源及其优先级保存在[原目标归档](https://github.com/DonsonHH/Zhinengti-RSI/blob/f2c20b3a642ff1df9426e523614d3da9a5cf1129/research/2026-10-28-m12-alignment/目标与导师要求.md)。其中有导师原话的记录、用户后续选择和项目实验约定，三者不混作同一种要求。

## 2. 两个需要分别回答的问题

**任务流程是否变好？** 在相同观测、工具、合法动作和巡检资源下，运行经验是否帮助改进技能或工作流程，并把效果保持到新实例？

**产生改进的方法是否变好？** 更新改进器的诊断和提案方式后，它能否在相同总预算下，更有效地找到有用修改？这才是本项目单独检验的递归改进问题。

流程能被修改、实际动作改变、任务结果改善、改进器能力提高，是四个不同的结论。每一层都需要自己的证据。

## 3. 与原论文的关系

| 原论文思想 | 当前继承 | 当前变化与证据边界 |
|---|---|---|
| 部分观测与状态估计 | 区分过程真值、公开遥测、专业测量和估计 | 水域重要度改为机房专业状态；默认使用名义估计，CVAE为可选工具 |
| 多执行者持续巡检 | 多专业执行者、任务和持续重访义务 | 加入资格、服务耗时、固定任务所属和返回计划 |
| 学习型策略 | 保留学习工具及历史实验的身份与结论 | 最新局部诊断主要由Tour和规则产生动作；PPO没有接入默认调度 |
| 事件确认机制 | 例行重访与风险确认分别记账，插入后返回检查 | 在预定合成热—冷耦合条件中已获跨过程任务收益支持，FIFO研究基线冻结 |
| 经验驱动改进 | 受限流程修改与改进器更新 | 事件机制上的反馈增量及改进器递归增量仍待验证 |

当前属于思想继承与领域适配，不能称完整复现或超越原论文。具体历史对照见[原论文与当前贡献对照](https://github.com/DonsonHH/Zhinengti-RSI/blob/f2c20b3a642ff1df9426e523614d3da9a5cf1129/research/2026-10-30-m12c1b4b2-alignment/原论文与当前贡献对照.md)。

原论文的VAE-UNet从部分观测估计区域重要度，合作调度采用多智能体Double DQN；当前保留的PPO不是该算法的复现。该信息已核对[大学机构库提供的论文摘要](https://idus.us.es/server/api/core/bitstreams/79e88506-ca7f-48f1-86b8-5504d9cb3e39/content)，尚未完成本轮逐节模型与指标核对。

重新开展研究时，先用一个跨系统案例解释“已有信息怎样改变检查决定”。连续遥测可能早已提示异常，本项目的有效现场确认时间不能直接称为首次发现故障；现有固定任务所属与局部换序也不等同于跨专业自由协作。共享信息、改变安排、确认更早和递归改进分别验证。

## 4. 本轮维护的研究范围

- 合成降阶机房；供电、液冷和自控共同产生设备状态。
- 已知设备清单、静态通道、确定移动及服务时间；执行者所属任务固定。
- 热、电气、制冷、自控的专业资格与有效测量条件。
- 受保护Tour作为基线。已结束的后果反馈试验只允许当前最多三项义务换序；该限制不描述后来的事件响应接口。
- 事件响应研究另设风险确认账本：公开风险上升沿产生确认义务，固定FIFO从合法事件中派单，每次完成后重规划。非例行头的额外访问不推进例行游标，插入与返回需要重新验证资格、预约和重访约束。
- 决策只使用公开信息；隐藏状态用于仿真和离线评价。
- 巡检改变信息和确认时机，不模拟维修或物理故障消除。

风险分数是合成严重度代理，不是校准故障概率或经济损失。返回计划的保障依赖上述假设，不覆盖未知设备、随机服务、动态封路、碰撞和排队。

事件生命周期保持一次连续正风险期间的单次响应：正常测量也关闭事件；持续正风险不会因到期或测量关闭而自动重开。120秒TTL限制待派事件的有效期，不保证120秒内完成；在途任务可晚完成。专业测量同刻揭示并关闭的事件，需要与提前公开提示后的响应分开报告。

2026-11-02修复过期清理顺序：先清除严格超过TTL的旧事件，再接收新的上升沿，避免新事件被旧记录吞掉。到期时刻本身仍有效。该修复不改写旧实验轨迹；对旧结果是否有影响尚未做重放验证。

两批预实验分别为12/16→13/16和4/15→11/15段有效确认；各批只有两个复合故障条件贡献评价异常。异常段不是独立样本。新优先级在第二批与FIFO派单相同。现有结果支持有限条件下的事件机制收益，尚未分离正确风险信息、额外访问权限与巡回相位改变的贡献。

后续[有限归因验证](../evidence/event-validation/final/README.md)已在12个预定复合故障过程完成：Tour/FIFO/同专业位置置乱分别确认28/70/25段（89段）。预定收益、成本和安全门槛通过，支持正确风险位置在此在线机制及适用域中的价值。置乱同时影响路程、可行性和后续观测，因此不是严格等成本、固定事件流的信息消融；此前两批结论仍按历史范围保留。当前可冻结FIFO研究基线，不能将本包提升归因于模型、反馈或RSI。

## 5. 后续工作的取舍

唯一下一主动实验问题见 [NEXT.md](NEXT.md)。论文结构与现有证据正文已进入[写作工作区](../paper/README.md)，可以与反馈研究准备同步推进。当前不扩展完整数字孪生、网络架构搜索、开放代码进化或没有明确问题的场景规模；岭回归诊断不成为新的研究主线。

不把“PPO先赢过Tour”“CVAE先有独立收益”或“所有预测视野通过”设为研究RSI的统一前提。若论文要主张某模块有贡献，就为该主张安排相应对照。

维护约定：每个新模块必须对应[架构中的一项职责](ARCHITECTURE.md)；每次只保持一个活动研究问题。结束后更新 [EVIDENCE.md](EVIDENCE.md)，不要叠加新的“当前状态”文件。失败证据和适用范围与正向结果一同保留。
